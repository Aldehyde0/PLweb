## 通俗直觉 {#intuition}

:::field{path="explanation" type="text"}
人知道“猫是动物，动物需要呼吸”。知识表示把这些事实整理成机器能查询和推理的图或规则。
:::


## 核心原理 {#core-principle}

:::field{path="principle" type="text"}
语义网络用节点表示实体或概念，用有方向的边表示关系；规则系统则通过前提推出结论。
:::


## 数学公式 {#formulas}

:::field{path="formula.expression" type="math"}
$$
Cat(x) → Animal(x)
$$
:::

:::field{path="formula.description" type="text"}
若 x 是猫，则可以推出 x 是动物。
:::

:::


## 代码示例 {#code}

:::field{path="code.language" type="text"}
Python
:::

:::field{path="code.source" type="code" trailing="0"}
```Python
facts = {"猫": {"is_a": "动物"}, "动物": {"needs": "呼吸"}}

def inherit(entity, relation):
    current = entity
    while current in facts:
        if relation in facts[current]:
            return facts[current][relation]
        current = facts[current].get("is_a")

print(inherit("猫", "needs"))
```
:::

:::field{path="code.highlights" type="list"}
- 沿 is\_a 关系继承属性
- 字典模拟一个最小知识图谱
:::

:::field{path="codeExplanation" type="text"}
程序沿着类别层级向上查找属性，体现了知识继承。工业知识图谱会提供更严格的模式、查询语言和一致性约束。
:::
