## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
最终答案不足以解释错在模型、工具、路由、权限还是状态。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Tracing 用层级 span 还原一次 Agent 运行发生了什么；可观测性再结合指标与日志判断质量、成本和异常。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
像快递轨迹，每次交接、处理和异常都有时间与责任节点。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
OpenAI Agents SDK 当前默认追踪 run、agent、turn、generation、function、guardrail 与 handoff 等事件。

敏感输入输出应可选择不进入追踪。

trace id、工具调用 id 和业务幂等键应能关联。
:::


## 理解与实践步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}

4. 脱敏敏感字段
5. 用失败案例回放
:::
