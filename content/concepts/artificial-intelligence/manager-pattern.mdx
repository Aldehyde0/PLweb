## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
统一责任有利于结果一致性，但主管可能成为上下文、成本和错误聚合瓶颈。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Manager Pattern 是 Agents as Tools 的系统级使用方式，主管集中施加格式、护栏和汇总策略。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
总编分派记者调查不同主题，最后自己核对并编辑成一篇文章。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
主管需知道每个专家的能力边界。

专家结果必须带证据和失败状态。

共享护栏不能替代每个高风险工具自己的校验。
:::


## 理解与实践步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 主管拆分任务
2. 选择一个或多个专家
3. 收集结构化结果
4. 检查冲突与证据
5. 输出最终答案
:::
