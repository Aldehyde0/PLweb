## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
盲目重试会重复副作用，吞掉错误会让 Agent 用缺失结果继续生成。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Agent 错误处理是从模型、工具、网络、权限和验证失败中恢复或安全停止的策略。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先判断是临时堵车、地址填错、权限不足还是道路永久关闭，再决定重试、改参、请人或停止。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
错误必须结构化分类并保留原始原因。

只对瞬时且幂等的操作做有限退避重试。

写操作重试需要幂等键或执行前查重。
:::


## 理解与实践步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 捕获错误
2. 分类瞬时/输入/权限/业务/未知
3. 决定重试、修正、审批或停止
4. 记录次数与最终原因
:::
