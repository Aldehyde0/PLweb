## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
无限累积完整对话会增加成本和冲突，也可能长期保存不应保留的敏感信息。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
状态是一次决策需要的当前数据；记忆是跨步骤或跨会话保留并可检索的信息。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
状态像工作台，短期记忆像本次任务笔记，长期记忆像经过筛选的档案库。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
每类状态必须有所有者、生命周期和删除策略。

摘要会丢信息，关键事实需结构化保存并带来源。

记忆写入比读取风险更高，应验证内容与授权。
:::


## 理解与实践步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 定义状态 Schema
2. 确定保存周期
3. 写入前验证和去敏
4. 检索时按任务过滤
5. 完成后清理临时状态
:::


## 实际应用 {#applications}

:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把聊天历史等同于记忆
- 保存敏感信息无过期策略
:::
