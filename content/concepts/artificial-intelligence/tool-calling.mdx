## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
模型本身不能因为输出了一段 JSON 就自动拥有文件、网络或业务系统权限。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
工具调用是一种控制循环：模型依据工具描述生成名称与参数，宿主应用执行真实函数，再把结果返回模型。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
模型填写申请单，应用检查申请、执行操作并给回执；申请单不是操作本身。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
模型选择工具与参数，应用保留最终执行权。

Schema 约束形状，业务验证约束语义和权限。

工具结果要有成功、失败和可重试状态，避免自然语言猜测。
:::


## 理解与实践步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 向模型暴露最小工具描述
2. 接收名称与参数
3. 验证 Schema 和业务权限
4. 必要时请求审批
5. 执行并记录幂等键
6. 返回结构化结果
7. 由 Agent 使用结果继续
:::


## 实际应用 {#applications}

:::field{path="applications" type="list"}
- 读取文件
- 查询数据
- 受控业务操作
:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 Schema 当授权
- 无幂等性地重试写操作
- 把错误字符串当成功结果
:::
