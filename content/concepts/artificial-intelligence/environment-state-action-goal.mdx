- 能解释为什么“状态缺失关键信息”是误区。
:::

## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
如果没有清楚状态和目标，Agent 可能重复动作、误判完成或把中间结果当成最终结果。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
环境是 Agent 可观察并可能改变的外部世界；状态是当前决策所需信息；动作是允许执行的操作；目标定义成功。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
像导航：地图与道路是环境，当前位置是状态，转弯是动作，到达地址是目标。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
状态应包含决策所需且允许保存的信息。

动作集合同时是能力边界和安全边界。

目标必须可检查，最好有明确的完成谓词和失败条件。
:::


## 理解与实践步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 列出环境中的对象
2. 定义可观察字段
3. 定义允许动作及副作用
4. 写出完成、失败与停止条件
:::
