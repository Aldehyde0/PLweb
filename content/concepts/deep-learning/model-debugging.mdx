## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
模型不学习时，一次更换多个超参数会让原因更难定位。先把任务缩小到一批可检查样本，逐层验证数据、目标、梯度和更新，可以更快区分实现错误与泛化问题。
:::

## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先确认发动机能在台架上转起来，再去讨论长途油耗。一个连固定小批都无法拟合的模型，不适合立即扩大训练。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
首先打印输入范围、shape、dtype、标签集合与样本图像，核对是否缺少归一化、类别映射或目标对齐。对分类可检查初始损失是否与近似均匀预测的 log(C) 同量级，但这只是线索，不是通用断言。

然后检查 loss 是否有限、参数 grad 是否为 None 或异常大、step 前后参数是否改变。detach、错误优化器参数组、忘记 zero_grad 或 step 都能造成不同症状，应该用证据分别排除。

固定 8–32 条样本、关闭不必要增强和正则，尝试过拟合，是综合检查。即使成功，也只说明局部训练链可用；数据泄漏、分布差异和评估错误仍需单独排查。
:::

### 同一训练步检查四个诊断信号

若梯度为 None，应先检查损失是否依赖该参数，而不是立刻调大学习率；若梯度存在但权重不动，应检查优化器参数组、学习率和是否调用 step。

本例不需要循环训练，因为目标是定位一次更新链是否连通。实际调试可继续固定这两条样本直到拟合，再逐步恢复完整数据与正则。

:::field{path="codeExamples.0.language" type="text"}

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对同一训练步检查四个诊断信号，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
model = nn.Linear(1, 1, bias=False)
with torch.no_grad():
    model.weight.zero_()
x, y = torch.tensor([[1.], [2.]]), torch.tensor([[2.], [4.]])
opt = torch.optim.SGD(model.parameters(), lr=0.1)
opt.zero_grad(set_to_none=True)
pred = model(x)
assert pred.shape == y.shape
loss = (pred - y).square().mean()
loss.backward()
grad = model.weight.grad.item()
before = model.weight.item()
opt.step()
print(f"finite={bool(torch.isfinite(loss))} loss={loss.item():.1f} grad={grad:.1f}")
print(f"weight_before={before:.1f} weight_after={model.weight.item():.1f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 手算梯度为 -10，可直接交叉核对。
- 只做明确的一步诊断，不虚构训练效果。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
finite=True loss=10.0 grad=-10.0
weight_before=0.0 weight_after=1.0
```
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 损失下降但准确率不变一定是 bug 吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不一定。概率可能改善却尚未跨越 argmax 或阈值边界；也可能类别不平衡掩盖进步，应检查概率、混淆矩阵与目标定义。
:::

:::field{path="commonQuestions.1.question" type="text"}
### 这个示例能说明什么边界？
:::

:::field{path="commonQuestions.1.answer" type="text"}
