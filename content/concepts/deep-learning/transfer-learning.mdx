## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
新任务标注少时，从随机权重训练大型网络可能效率低。迁移学习复用已有表示，但需要验证源任务特征是否适合目标数据，而不是默认所有预训练模型都有效。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
迁移学习将预训练参数用于新任务，常见策略是冻结骨干训练新头，再以较小学习率微调部分或全部骨干。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先使用已经学会的视觉或语言基础，再学习当前任务的输出规则；如果领域变化很大，旧知识也可能成为偏见。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
冻结参数通过 requires_grad=False 阻止梯度，但新替换的任务头需要训练，优化器必须包含它。若后来解冻骨干，应同时更新参数组；只改变 requires_grad 不会修改优化器持有的参数列表。

任务头通常使用较大学习率，预训练骨干较小。BatchNorm 的运行统计不受 requires_grad 冻结控制，所以冻结骨干还需决定其 train/eval 策略。预训练输入尺寸、通道和均值方差也属于资产。

微调结果应与冻结特征和小模型基线比较。目标域与源域差异、标签语义或输入模态变化都可能造成负迁移，不能把“使用预训练”直接当效果保证。
:::

### 冻结骨干只让任务头接收梯度

新头包含 2×4 个权重和 2 个偏置，所以总计 10 个可训练参数。代码没有下载预训练权重，只演示冻结与参数组机制，不把随机骨干称为有效预训练模型。

若要继续微调，应显式解冻目标层并将其加入优化器，选择较小学习率。真实迁移效果需要在目标验证集上衡量。

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对冻结骨干只让任务头接收梯度，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
torch.manual_seed(7)
backbone = nn.Sequential(nn.Linear(3, 4), nn.ReLU())
head = nn.Linear(4, 2)
for p in backbone.parameters():
    p.requires_grad_(False)
opt = torch.optim.AdamW(head.parameters(), lr=1e-3)
x = torch.ones(2, 3)
loss = nn.CrossEntropyLoss()(head(backbone(x)), torch.tensor([0, 1]))
opt.zero_grad(set_to_none=True)
loss.backward()
print("backbone frozen:", all(p.grad is None for p in backbone.parameters()))
print("head gradients:", all(p.grad is not None for p in head.parameters()))
print("trainable:", sum(p.numel() for p in head.parameters()))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 随机骨干仅用于机制检查，不冒充预训练。
- 优化器明确只包含任务头。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
backbone frozen: True
head gradients: True
trainable: 10
```

- 预处理不匹配
- BN 统计未管理

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 冻结骨干后为什么输出仍会随训练改变？
:::

:::field{path="commonQuestions.0.answer" type="text"}
训练模式的 BatchNorm 会继续更新统计，Dropout 也会随机；冻结参数只阻止梯度更新，不等于冻结全部前向行为。
:::

:::field{path="commonQuestions.1.question" type="text"}
### 这个示例能说明什么边界？
:::

:::field{path="commonQuestions.1.answer" type="text"}
示例验证冻结机制，不证明随机骨干具有可迁移知识或能达到真实任务性能。
:::
