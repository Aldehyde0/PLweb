## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
多数 CNN 报错来自通道衔接和 Linear in\_features 计算错误。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
普通层通常保留 N；Conv 改 C 和空间；池化改空间；Flatten 合并 C/H/W。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
每经过一层都记账：N 看输入，C 看 out\_channels，H/W 用公式。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
Conv 参数与 H/W 无关，Linear 参数与展平维度强相关。

手算后必须用随机张量、打印和 assert 验证。
:::

### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
params_{conv}=C_{out}(C_{in}K_hK_w+1)
$$
:::

:::field{path="formulas.0.description" type="text"}
bias=True 的普通卷积。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 保留 N
2. 更新 C
3. 计算 H/W
4. 池化
5. Flatten 相乘
6. Linear 输出
:::
