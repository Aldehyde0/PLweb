## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
激活大小像流水线当前占用的工作台，参数量像固定安装的工具数量。换大图会占更多工作台，却不一定增加工具。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
普通卷积输出空间长度按输入、padding、dilation、核、stride 计算并向下取整。batch 通常保持，通道变为 out_channels；池化一般保留通道，只改变空间。Flatten(start_dim=1) 合并非 batch 维，避免误把样本拼在一起。

带偏置普通卷积参数为 C_out×(C_in×K_h×K_w+1)，groups 不为 1 时需把每核输入通道除以 groups。线性层参数为 out_features×(in_features+1)。BatchNorm 另有缩放和偏移参数，running stats 是 buffer。

参数少不代表运行快：高分辨率卷积会在很多位置重复计算。训练显存还包括激活、梯度和优化器状态，因此应分别记录参数、输出形状和实际内存测量。
:::

### 同一卷积处理两种图像大小

空间边长翻倍，输出元素数变为四倍，但核仍是同一组 224 个参数。若之后接展平全连接，输入特征数也变为四倍，分类头参数才会跟着增加。

这解释了为什么一张高分辨率图片可能耗尽显存，即使模型文件没有变大。估算资源时，只报模型参数数量会遗漏主要的激活成本。

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 同一卷积处理两种图像大小的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对同一卷积处理两种图像大小，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
conv = nn.Conv2d(3, 8, 3, stride=2, padding=1)
for size in [32, 64]:
    y = conv(torch.zeros(2, 3, size, size))
    print(f"input={size} output={tuple(y.shape)}")
print("parameters:", sum(p.numel() for p in conv.parameters()))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}

- 显式包含偏置参数。
:::

```text
input=64 output=(2, 8, 32, 32)
parameters: 224
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 为什么 Flatten 后容易出现 Linear 维度错误？
:::

:::field{path="commonQuestions.0.answer" type="text"}
in_features 必须等于实际通道×高×宽。任何池化、步长或输入分辨率变化都会改变这个乘积，需重新核对或使用自适应池化。
:::
