## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
从纯噪声一次生成复杂样本很困难。扩散模型把问题拆成许多噪声等级上的去噪任务，再用匹配的逆向过程逐步生成。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
扩散模型规定前向加噪过程，训练网络在给定噪声等级或时间条件下预测噪声、干净样本或其他等价参数化，再按相应采样规则逆向求样本。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先知道图片如何被逐渐弄模糊，再学习不同损坏程度下怎样修复。训练中的单步修复和完整生成的多步采样不是同一段程序。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
常用封闭式前向写为 x_t=sqrt(alpha_bar_t)×x0+sqrt(1−alpha_bar_t)×epsilon。alpha_bar 是累计保留系数，不是单步 alpha；每条样本可随机选择不同 t，并把对应系数广播到图像维。

预测噪声时，网络输入 x_t 和 t，目标为本次使用的 epsilon，常用均方误差。时间条件不可省略，因为相同观测值在不同噪声水平下含义不同。噪声预测与 x0 预测有不同尺度，不能随意切换而不改公式。

采样需要与训练一致的调度、参数化、数据缩放和起始分布。仅按公式把预测噪声减掉不是完整 DDPM 或 DDIM 采样器；最后一步、中间随机性和步长都有明确规则。
:::

### 已知噪声时反解一个加噪样本

真实生成时没有可直接读取的 x0 和本次真实噪声，所以必须依靠训练网络估计。即使某一步估计准确，完整采样的分布也依赖整套逆向规则。

alpha_bar 接近零时反解中除以很小的平方根会放大误差，显示参数化与采样调度的重要性。代码选择 0.25 便于手算，不代表推荐的训练调度。

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 已知噪声时反解一个加噪样本的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对已知噪声时反解一个加噪样本，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
x0 = torch.tensor([2., -2.])
noise = torch.tensor([1., -1.])
a = torch.tensor(0.25)
xt = a.sqrt() * x0 + (1 - a).sqrt() * noise
recovered = (xt - (1 - a).sqrt() * noise) / a.sqrt()
print("noisy:", [round(v, 6) for v in xt.tolist()])
print("recovered:", recovered.tolist())
print(f"max_error={(recovered - x0).abs().max().item():.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 噪声与累计系数全部显式给定。
- 没有引入不存在的 denoiser 或虚构生成图像。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
noisy: [1.866025, -1.866025]
recovered: [2.0, -2.0]
max_error=0.000000
```
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### alpha_bar 和单步 alpha 是同一个量吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是，alpha_bar 通常是到 t 为止各步 alpha 的乘积；封闭式从 x0 直接构造 x_t 时需要累计量。
:::

### 这个示例能说明什么边界？
:::

:::field{path="commonQuestions.1.answer" type="text"}

:::
