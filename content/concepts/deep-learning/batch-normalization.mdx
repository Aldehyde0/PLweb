## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
中间激活尺度变化会让优化不稳定。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
BatchNorm 在训练用当前 batch 统计，评估用 running stats，再学习 γ/β。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
每个通道用当前训练群体校准，再允许模型重新缩放和平移。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
BatchNorm2d 对 \[N,C,H,W\] 每通道跨 N/H/W 统计；小 batch 统计噪声大。

冻结 γ/β 不等于冻结 running stats；每次 model.train 后可能需重新设 BN eval。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
\hat{x}=\frac{x-\mu_c}{\sqrt{\sigma_c^2+\varepsilon}},\ y=\gamma_c\hat{x}+\beta_c
$$
:::

:::field{path="formulas.0.description" type="text"}
每个通道独立统计。
:::
