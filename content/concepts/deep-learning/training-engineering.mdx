## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
长训练可能中断，实验也需要复查。只有权重而没有优化器、随机状态和数据进度，通常只能重新开始一个相近实验，不能保证接着原轨迹走。
:::

:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
断点像游戏存档：只存角色位置而不存背包、任务进度和随机状态，继续游戏就可能发生不同结果。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
用于恢复的检查点通常包含模型、优化器、调度器、AMP scaler、当前进度、最佳指标及配置。随机采样还依赖 Python、NumPy、PyTorch 和设备随机状态，数据加载器或采样器进度也可能需要保存。

指标记录应带样本计数和步骤定义，非有限损失或梯度应及时暴露。保存时注意 state_dict 引用当前张量；如果把“最佳状态”仅留在内存，需深拷贝或立即序列化，避免后续训练继续改动它。

恢复一致性最好用“连续两步”和“第一步保存、恢复后第二步”比较。分布式算子、工作进程和设备差异仍可能带来不确定性，因此不要从设置 seed 就宣称所有环境位级复现。
:::

:::field{path="numericalExample.title" type="text"}
### 带动量 SGD 的断点恢复核对
:::

:::field{path="numericalExample.given" type="list"}
- 参数初值 1，学习率 0.1，momentum=0.9
- 每步梯度固定为 1
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 第一步参数变为 0.9，动量 buffer 为 1。
2. 第二步方向为 0.9×1+1=1.9，参数变为 0.71。
3. 保存第一步的参数和优化器状态，恢复后重复第二步。
:::

:::field{path="numericalExample.result" type="text"}
连续与恢复路径均得到 0.7100。
:::

:::field{path="numericalExample.comparison" type="list"}
- 本例证明优化器状态的重要性，不承诺跨硬件或分布式训练完全确定。
:::

### 带动量 SGD 的断点恢复核对

若只恢复参数 0.9 而没有动量，第二步只减去 0.1，会得到 0.8。代码通过内存序列化快照保存真正的第一步状态，避免被第二步覆盖。

真实任务还有数据顺序与随机增强，因此这个确定性例子只隔离优化器状态。需要精确续训时，应扩展到完整数据与随机状态检查。

## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 带动量 SGD 的断点恢复核对的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对带动量 SGD 的断点恢复核对，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import io
import torch
p = torch.nn.Parameter(torch.tensor(1.))
opt = torch.optim.SGD([p], lr=0.1, momentum=0.9)
p.grad = torch.ones_like(p)
opt.step()
buffer = io.BytesIO()
torch.save({"parameter": p.detach().clone(), "optimizer": opt.state_dict()}, buffer)
p.grad = torch.ones_like(p)
opt.step()
buffer.seek(0)
state = torch.load(buffer, weights_only=True)
q = torch.nn.Parameter(state["parameter"].clone())
resumed = torch.optim.SGD([q], lr=0.1, momentum=0.9)
resumed.load_state_dict(state["optimizer"])
q.grad = torch.ones_like(q)
resumed.step()
print(f"continuous={p.item():.4f} resumed={q.item():.4f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 保存真实序列化快照而非可变引用。
- 固定梯度排除随机数据影响。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
continuous=0.7100 resumed=0.7100
```
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 只保存 model.state_dict 能精确续训吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
通常不能，优化器矩、调度位置、scaler 和随机数据进度都会影响后续更新；仅推理则通常不需要这些训练状态。
