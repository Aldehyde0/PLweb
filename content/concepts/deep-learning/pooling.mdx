## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
局部特征提取后，网络常需要缩小空间网格，以降低计算并聚合邻近响应。池化提供不含可学习核的局部汇总，但它也会丢失细节。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
池化按窗口对特征图取最大值、平均值等统计，通常独立作用于每个样本和每个通道。全局或自适应池化则直接约定输出空间尺寸。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
最大池化回答“这一片有没有强响应”，平均池化回答“这一片整体响应多强”。两个问题在孤立尖峰和均匀纹理上会给出不同结果。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
MaxPool 把窗口中的最大元素传到下一层，反向梯度主要流向被选中的位置。AvgPool 将响应平均，梯度也按参与元素分配。窗口、stride、padding 和是否计入 padding 会影响数值及输出尺寸。

普通池化不混合不同通道，不改变通道数。2×2、stride=2 通常把偶数高宽减半；奇数尺寸和 ceil_mode 需要单独计算。自适应平均池化到 1×1 可把任意空间网格压成每通道一个数。

池化提供有限的局部位置鲁棒性，但不保证全局平移不变。下采样可能移走细小目标，分割等任务常需跳接或高分辨率分支保留位置证据。
:::

### 同一窗口的最大值与平均值

若一个窗口只有一个异常亮点，MaxPool 会完全保留它；AvgPool 会把它和周围值一起平均。这可能有助于找强边缘，也可能放大噪声，需要按任务验证。

输出只剩一个数，无法从它唯一恢复原来四个位置。上采样可以增大网格，却不会凭空补回被池化删除的信息。

### 同一窗口的最大值与平均值的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对同一窗口的最大值与平均值，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
x = torch.tensor([[[[1., 3.], [2., 0.]]]])
for name, pool in [("max", nn.MaxPool2d(2)), ("avg", nn.AvgPool2d(2))]:
    y = pool(x)
    print(f"{name}: value={y.item():.1f} shape={tuple(y.shape)}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 两个算子使用完全相同的窗口。
- 示例核对的是聚合定义。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
max: value=3.0 shape=(1, 1, 1, 1)
avg: value=1.5 shape=(1, 1, 1, 1)
```
