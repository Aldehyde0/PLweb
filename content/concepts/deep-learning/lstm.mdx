## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
普通 RNN 不容易稳定地把信息传过很多时间步。LSTM 通过可控制的细胞状态通路，分别决定保留旧内容、写入新内容和暴露哪些内容。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
LSTM 维护隐藏状态 h 与细胞状态 c，使用遗忘门 f、输入门 i、输出门 o 和候选内容 g 更新。门通常经 sigmoid，候选内容经 tanh。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
细胞状态像长期笔记，遗忘门擦去一部分，输入门写入一部分，输出门决定本步向外展示多少。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
更新 c_t=f_t×c_prev+i_t×g_t，再计算 h_t=o_t×tanh(c_t)。门是 0 到 1 的连续向量，不是人工写好的二元开关。加法通路能减轻反复矩阵相乘造成的梯度问题，但遗忘门持续很小仍会快速抹去历史。

四组变换各自读取当前输入和前一隐藏状态，因此标准 LSTM 通常比相同 hidden size 的普通 RNN 有更多参数。细胞状态也不等于原始历史；它是由目标训练出来的压缩表示。

PyTorch 返回 output 和 (h_n,c_n)。多层或双向时，最终状态首轴包含层与方向；最后时间位置不等于所有方向的最终摘要。变长序列需要正确处理 padding，在线跨片段时还应明确状态携带与 detach。
:::

:::field{path="formulas.0.expression" type="math"}
$$

### 手算一次 LSTM 的状态写入

本例门值是人为给定，用于隔离更新公式，不是从真实网络拟合得到。c 可以超过 1，h 经 tanh 与输出门后仍被限制，这解释了两种状态为何不能互换。

若把遗忘门改为 0，旧细胞状态的直接贡献消失；若输入门为 0，则没有新内容写入。真实门向量由输入和历史动态计算，不会固定采用此处比例。

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 手算一次 LSTM 的状态写入的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对手算一次 LSTM 的状态写入，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
c_prev = torch.tensor(2.)
f, i, g, o = [torch.tensor(v) for v in [0.5, 0.25, 0.8, 0.75]]
c = f * c_prev + i * g
h = o * torch.tanh(c)
print(f"cell={c.item():.6f} hidden={h.item():.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 门值为构造条件，不假装网络训练结果。
- 分别打印 c 与 h，展示不同的数值范围。
:::

```text
cell=1.200000 hidden=0.625241
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### LSTM 的细胞状态和隐藏状态为什么不同？
:::

:::field{path="commonQuestions.0.answer" type="text"}
细胞状态用于内部累加和保留信息，隐藏状态是经 tanh 与输出门暴露的表示；两者形状可能相同，但运算角色不同。
:::
