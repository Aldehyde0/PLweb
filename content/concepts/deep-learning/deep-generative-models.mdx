## 为什么需要这个概念 {#importance}

:::field{path="importance" type="paragraphs"}
深度生成模型学习数据分布或与其相关的采样机制。VAE 用潜变量与变分目标，GAN 用对抗反馈，扩散模型用分步加噪与逆向去噪；它们的训练损失不能直接横向比较。
:::

## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
分类模型给已有样本分配标签，生成模型则要产生新的内容。仅能重构训练输入的压缩网络，并不自动拥有可以随机采样的合理潜在分布。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
深度生成模型学习数据分布或与其相关的采样机制。VAE 用潜变量与变分目标，GAN 用对抗反馈，扩散模型用分步加噪与逆向去噪；它们的训练损失不能直接横向比较。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
重构像按原稿复写，生成像从指定规则中创作新稿。复写得好并不保证任意随机起点都会变成合理作品。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
普通自编码器把输入压到 latent 再重构，主要约束见过输入的编码位置。若直接从标准正态采样 latent，可能落在解码器从未学习过的区域；需要额外分布建模或其他生成机制。

VAE 对近似后验施加先验约束，GAN 让生成样本接受判别器反馈，扩散模型学习各噪声级别的去噪目标。各家损失的意义、尺度与采样步骤都不同，不能只挑一个更小的数就宣布生成更好。

评价要兼顾质量、多样性、条件一致性与记忆训练样本的风险。固定随机输入有助于比较训练阶段，仍需独立样本和明确协议；精选几张好图不能说明模型覆盖了完整分布。
:::

### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
z=E_\phi(x),\quad \widehat x=D_\theta(z),\quad L_{recon}=\frac{1}{ND}\sum_{n,d}(x_{nd}-\widehat x_{nd})^2
$$
:::

:::field{path="formulas.0.description" type="text"}
这是普通自编码器的重构目标，用于说明瓶颈；VAE、GAN 和扩散模型各有额外或不同目标，不能把此式作为统一生成损失。
:::

:::field{path="numericalExample.comparison" type="list"}

### 相同 latent 导致无法区分的重构

这个构造用固定权重展示瓶颈丢失信息，没有训练过程。只看 latent shape=(2,1)，无法知道它是否保留了所需结构；必须把具体输入与重构对应起来。

若现在任意采样一个 latent=10，解码器会输出 (5,5)，但它是否属于真实数据分布毫无保证。这正是“会重构”和“会生成”之间需要额外机制的地方。

## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 相同 latent 导致无法区分的重构的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对相同 latent 导致无法区分的重构，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
encoder, decoder = nn.Linear(2, 1, bias=False), nn.Linear(1, 2, bias=False)
with torch.no_grad():
    encoder.weight.fill_(1.)
    decoder.weight.fill_(0.5)
x = torch.tensor([[1., 0.], [0., 1.]])
z = encoder(x)
reconstruction = decoder(z)
print("latent:", z.detach().flatten().tolist())
print("reconstruction:", reconstruction.detach().tolist())
print(f"mse={(reconstruction - x).square().mean().item():.2f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 固定简单编码器和解码器。
- 不把自编码器重构误差包装为生成质量指标。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
latent: [1.0, 1.0]
reconstruction: [[0.5, 0.5], [0.5, 0.5]]
mse=0.25
```
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 为什么重构网络不能直接当成可靠生成器？
:::

:::field{path="commonQuestions.0.answer" type="text"}
训练可能只约束输入经过编码后的 latent 区域，任意先验采样未必落在这些区域；需要先验约束或明确的生成分布建模。
:::
