## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
文本、音频和行为序列有顺序且长度不同。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Embedding 是 \[V,D\] 查找表；id 只是索引，无连续大小意义。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
每个离散 token 从表中取一行向量，训练让有用 token 行逐步更新。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
词表只由训练数据建立，训练/部署编号一致；padding 不参与池化损失指标。

普通 token Embedding 不含顺序，需 RNN/卷积或位置表示。
:::

### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
E\in\mathbb{R}^{V\times D},\quad Embedding(i)=E_i
$$
:::

:::field{path="formulas.0.description" type="text"}
V 词表大小，D 向量维度。
:::
