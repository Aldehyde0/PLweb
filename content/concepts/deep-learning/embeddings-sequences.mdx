## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
文本 token、商品和离散类别通常先表示为整数编号。整数大小本身没有距离意义，不能把编号 100 直接当成比编号 2 强五十倍的连续特征。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Embedding 是从离散索引到可学习稠密向量的查表映射。词表大小 V、向量维度 D 对应一个 V×D 参数矩阵，每个索引取出一行。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
编号是书架位置，向量是书的内容表示；编号相邻不保证语义相近，向量相近要由训练目标形成。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
输入索引通常为 long 类型，形状 $[N,L]$ 经 Embedding 后变为 $[N,L,D]$。反向把梯度写回本次使用的行，重复索引的贡献会累计；词表与编号映射必须在训练、验证和部署保持一致。

padding_idx 可阻止默认梯度更新该填充行，但不会自动给后续注意力、池化或损失添加 mask。即使填充向量为零，直接平均仍会把分母增大，缩小短序列表示。

普通 token embedding 不包含顺序。若把向量直接无序求和，“猫追狗”与“狗追猫”可能无法区分；需要位置表示、RNN 或其他顺序机制。未登录词也应有事先定义的处理规则，不能临时分配与训练冲突的 ID。
:::

### 带 padding 的向量平均

padding_idx 让填充向量为零，却不会告诉 mean 应除以 2 而不是 3。这个错误不会改变输出 shape，因此要从有效位置数量核对数值。

如果一批中存在全 padding 样本，还需明确处理策略。用 clamp_min(1) 可以避免除零，但空序列是否允许、应输出什么，仍是数据契约问题。

:::


## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 带 padding 的向量平均的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对带 padding 的向量平均，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
embedding = nn.Embedding(3, 2, padding_idx=0)
with torch.no_grad():
    embedding.weight.copy_(torch.tensor([[0., 0.], [1., 2.], [3., 4.]]))
ids = torch.tensor([[1, 2, 0]])
x = embedding(ids)
valid = ids.ne(0)
masked = (x * valid.unsqueeze(-1)).sum(1) / valid.sum(1, keepdim=True).clamp_min(1)
print("shape:", tuple(x.shape))
print("masked mean:", masked.detach().tolist())
print("plain mean:", [[round(v, 4) for v in row] for row in x.mean(1).detach().tolist()])
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 固定整张查表矩阵，可手算每次查询。
- 有效 mask 独立于 padding_idx 使用。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
shape: (1, 3, 2)
masked mean: [[2.0, 3.0]]
plain mean: [[1.3333, 2.0]]
```
:::

:::field{path="commonQuestions.0.question" type="text"}
### Embedding 是否等价于对 one-hot 做线性变换？
:::

:::field{path="commonQuestions.0.answer" type="text"}
在不含偏置的相同权重约定下，索引查表等价于选取 one-hot 对应行，但查表不必显式构造庞大的 one-hot 张量。
