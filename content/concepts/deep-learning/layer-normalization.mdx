## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
序列长度和 batch 大小会变化，在线推理甚至只有一个样本。LayerNorm 不依赖同批样本的统计，因而常用于序列与 Transformer 隐藏表示。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
LayerNorm 对输入指定的尾部维度计算均值与有偏方差，再用可选的逐元素缩放和偏移变换。LayerNorm(D) 对每个位置的 D 个特征独立计算。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
每个 token 自己建立一把特征刻度尺。同批换了另一句话，当前 token 的标准化基准不会因此改变。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
若输入为 $[N,L,D]$ 且 normalized_shape=D，统计轴只有最后一维，均值形状可理解为 $[N,L,1]$。若指定 (L,D)，则同时跨两个尾轴统计，语义和参数形状都改变，不能看名字相同就混用。

LayerNorm 默认有与 normalized_shape 一致的 affine 参数，因而标准化输出不保证训练后仍为零均值单位方差。默认不维护 BatchNorm 那样的运行均值与方差，所以单独的 LayerNorm 在 train 与 eval 下计算相同。

在残差块中，Pre-LN 和 Post-LN 的归一化位置不同，会影响梯度路径和训练配方。LayerNorm 并不会识别 padding，若随后对序列求平均，仍需用有效位置 mask 排除填充。
:::

### 两个 token 各自标准化

虽然第二个 token 的绝对值大很多，LayerNorm 主要保留其内部相对结构。若任务必须使用原始幅度作为信号，需要考虑归一化位置和残差是否保留了相关信息。

如果写成 LayerNorm((2,2))，就会把两个 token 合在一起求统计，并且学习 2×2 的 affine 参数。这不是对原操作的等价写法。

### 两个 token 各自标准化的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对两个 token 各自标准化，输出只表示本例计算。

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
x = torch.tensor([[[1., 3.], [10., 14.]]])
ln = nn.LayerNorm(2, elementwise_affine=False)
ln.train()
a = ln(x)
ln.eval()
b = ln(x)
print([[round(v, 4) for v in row] for row in a[0].tolist()])
print("mode max diff:", (a - b).abs().max().item())
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 两个 token 使用不同绝对范围。
- 关闭 affine 以直接核对标准化输出。
:::

```text
mode max diff: 0.0
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### LayerNorm(D) 为什么适合变长序列？
:::

:::field{path="commonQuestions.0.answer" type="text"}
统计和参数只依赖末维 D，长度 L 可以变化；若把 L 也放进 normalized_shape，就失去这一性质。
:::

:::field{path="commonQuestions.1.question" type="text"}
### 这个示例能说明什么边界？
:::

:::field{path="commonQuestions.1.answer" type="text"}
LayerNorm 不会自动屏蔽 padding，也不保证保存所有绝对幅度信息。
:::
