## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
序列和小 batch 场景不适合依赖 batch 统计。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
LayerNorm 不维护 running stats，训练和评估对同一输入公式相同。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
每个 token 自己在隐藏维上校准，不借用其他样本。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
对 \[N,L,D\] 使用 LayerNorm(D)，每个 n,l 独立对 D 维统计。

normalized\_shape 必须匹配输入尾部维度；仍有可训练 γ/β。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
y_{nld}=\gamma_d\frac{x_{nld}-\mu_{nl}}{\sqrt{\sigma_{nl}^2+\varepsilon}}+\beta_d
$$
:::

:::field{path="formulas.0.description" type="text"}
每个 token 对 D 维归一化。
:::
