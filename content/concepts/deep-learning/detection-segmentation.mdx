## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
分类只回答图中有什么，检测还回答在哪里，分割则给每个像素分配标签。目标格式与评估单位改变后，不能直接沿用图像级分类管道。
:::

## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
检测画框圈出对象，语义分割给每块区域上色，实例分割再为两只同类动物分别编号。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
检测框可用 xyxy 或中心宽高等格式，需明确坐标是否归一化及边界定义。resize、crop、flip 必须同步变换图像和框；分割 mask 缩放通常用最近邻以免制造不存在的类别编号。

IoU 是交集面积除以并集面积，可比较框或像素区域。检测评估还要按类别、置信度和 IoU 阈值匹配预测与真实框，重复框不能都算真阳性；AP 不是一个 IoU 均值。

语义分割常输出 $[N,C,H,W]$ logits、目标为 $[N,H,W]$ 整数类别，ignore 区域需从损失与指标排除。小目标、遮挡与类不平衡会使总像素准确率掩盖错误，应查看每类 IoU 和对象尺度。
:::

### 两个 4×4 框的 IoU

若把框当作包含端点的整数像素坐标并加 1，面积会变成另一套口径。应按数据集规范统一，而不是在同一项目里混用。

本例只验证几何重叠，没有类别、置信度或匹配过程，因此不能把 0.142857 称为检测准确率。空框或退化框也要有明确处理，本实现把非正并集返回 0。

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
def iou(a, b):
    inter_w = max(0., min(a[2], b[2]) - max(a[0], b[0]))
    inter_h = max(0., min(a[3], b[3]) - max(a[1], b[1]))
    intersection = inter_w * inter_h
    area_a = max(0., a[2] - a[0]) * max(0., a[3] - a[1])
    area_b = max(0., b[2] - b[0]) * max(0., b[3] - b[1])
    union = area_a + area_b - intersection
    return intersection / union if union > 0 else 0.
print(f"overlap={iou([0, 0, 4, 4], [2, 2, 6, 6]):.6f}")
print(f"disjoint={iou([0, 0, 1, 1], [2, 2, 3, 3]):.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 明确 xyxy 与连续坐标面积约定。
- 处理不相交与退化并集。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 分割 mask 缩放为什么不用普通双线性插值？
:::

:::field{path="commonQuestions.0.answer" type="text"}
类别编号是离散标签，双线性会混合编号产生无意义值；通常用最近邻，概率图的处理则应另行定义。
:::
