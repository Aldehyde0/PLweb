## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
同一模型训练与部署采用不同数值范围，或标准化统计混入验证数据，都会使评估失真。数据管道需要同时维护数值、形状和划分来源。
:::

:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
模型不是只吃一张图片，而是吃“按某种规则加工后的张量”。保存权重却丢失加工规则，等于只留下半个系统。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
均值、标准差、词表和缺失值填补等数据驱动规则只能在训练部分拟合，再固定用于验证与测试。先全量拟合再划分，会让未来数据影响训练表示，形成泄漏。

训练增强可随机，但必须保持标签语义；验证和推理通常使用确定性变换。图像与框、mask 必须同步变换，序列标签也要与 token 对齐。预训练权重还应使用配套的尺寸和归一化。

计算 epoch 均值损失时，若 criterion 返回批内均值，应乘批样本数再累计。序列和分割若按有效 token 或像素定义目标，权重应改为对应有效数量，不能机械地都乘 batch size。
:::

### 尾批使批均值平均失真
:::

:::field{path="numericalExample.given" type="list"}

- batch_size=2，批均值为 1、1、9

:::field{path="numericalExample.steps" type="ordered"}

:::

:::field{path="numericalExample.comparison" type="list"}

### 尾批使批均值平均失真

尾批只有一条，若与两条样本的批次等权，就放大了它的影响。代码构造平方误差恰为这五个值，只演示日志归一化，不训练模型。

若任务按 token 求平均，最后一批可能虽样本少却 token 多。此时应记录 loss sum 与有效 token count，依据目标定义计算，而不是照搬本例样本数。

:::

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对尾批使批均值平均失真，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch.utils.data import DataLoader, TensorDataset
error = torch.tensor([1., 1., 1., 1., 3.])
loader = DataLoader(TensorDataset(error), batch_size=2)
total, count, batch_means = 0., 0, []
for (e,) in loader:
    loss = e.square().mean()
    total += loss.item() * len(e)
    count += len(e)
    batch_means.append(loss.item())
print(f"weighted={total / count:.4f} mean_of_batches={sum(batch_means) / len(batch_means):.4f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 平方误差输入完全给定。
- 明确区分样本加权与等权批平均。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
weighted=2.6000 mean_of_batches=3.6667
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 验证集可以重新计算自己的标准化均值吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
通常不可以。部署时应应用训练拟合的规则；单独重新拟合会改变评估契约，也可能使用本不应知道的评估分布信息。
:::

:::
