## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
大数据无法一次装入显存，因此按 batch 流式训练。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
小批量训练平衡显存、硬件并行和梯度噪声。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
一本题库分多页做，一页是 batch，做完一页是 iteration，整本做完是 epoch。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
保留尾批时每 epoch 批次数是 ceil(N/B)；梯度累积时 iteration 不一定等于参数更新。

小 batch 梯度波动大，大 batch 占内存多且更新次数少。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
steps=\left\lceil\frac{N}{B}\right\rceil
$$
:::

:::field{path="formulas.0.description" type="text"}
N 是训练样本数，B 是 batch size。
:::
