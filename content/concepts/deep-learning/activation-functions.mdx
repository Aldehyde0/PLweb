## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
如果把两个全连接层直接相连，后一层仍只是在前一层的线性结果上做线性变换。无论堆多深，整体都可以合并成一个仿射变换，无法因此获得弯曲的决策边界。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
激活函数是施加在层输出上的非线性映射。ReLU、Sigmoid、Tanh、GELU 的输出范围和导数不同，因此会同时影响表示能力与梯度传播。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
ReLU 像按条件打开的开关：某个隐藏特征在正区间传递数值，在负区间停止响应。不同神经元打开的区域不同，多层组合便能拼出分段的非线性函数。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
仿射层计算 $z=XW^T+b$，逐元素激活计算 $h=\phi(z)$。激活通常保持张量形状，改变的是每个位置的数值和局部导数；它不会自动增添特征维度。

ReLU 在正区间导数为 1，负区间为 0。若某神经元对全部训练样本都落在负区间，沿该分支的梯度可能长期为零，形成死亡 ReLU。LeakyReLU 给负半轴保留斜率，但并不能修复错误标签或过大的学习率。

Sigmoid 把实数映射到 0 到 1，适合解释二元概率；当输入绝对值很大时，导数接近零。Tanh 同样会饱和，GELU 则平滑地按输入大小调节输出。隐藏层激活与输出概率变换应分开：交叉熵等组合损失需要原始 logits。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 用 ReLU 组合出绝对值
:::

:::field{path="numericalExample.given" type="list"}
- 输入 x 为 -2、0、3
- 两个隐藏单元分别计算 ReLU(x) 与 ReLU(-x)
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 先对 x 和 -x 分别截断负值。
2. 把两个非负响应相加，得到绝对值。
:::

:::field{path="numericalExample.result" type="text"}
两条分支相加得到 2、0、3；单个仿射函数无法在整条数轴上表示这个折点。
:::

:::field{path="numericalExample.comparison" type="list"}
- ReLU 可以产生折点，但不会自动学到合适参数；概率输出也不能任意替换隐藏激活。
:::

### 案例推演与判断

在 x=-2 时，正向单元为 0，反向单元为 2；在 x=3 时恰好相反。最终输出可以写成 $\mathrm{ReLU}(x)+\mathrm{ReLU}(-x)$。这个构造展示非线性来自激活与分支组合，并不来自“层数”这个数字。

如果删掉两个 ReLU，同样的加法变成 x+(-x)=0，结构仍在却失去目标函数。反向传播时还要注意零点不可微，框架选择一个约定的次梯度；这不妨碍函数前向计算。
