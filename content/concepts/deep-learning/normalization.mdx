## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
中间激活的尺度变化会影响训练，但“归一化”不是一个唯一操作。不同方法沿不同轴统计，选错轴会把样本、时间和特征的语义混在一起。
:::

:::field{path="definition" type="paragraphs"}

:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
同样是一张成绩表，可以按每科在全班中的分布标准化，也可以按每个学生自身的各科分布标准化；两种比较基准不会等价。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
BatchNorm 对每个通道聚合批内样本及适用的空间/序列位置，训练通常使用当前批统计并维护运行统计。LayerNorm 按每个样本的指定尾部维度统计，不依赖同批其他样本。GroupNorm 则在单样本内按通道分组并包含空间维。

对序列 $[N,L,D]$，LayerNorm(D) 独立标准化每个 token 的 D 个特征。BatchNorm1d(D) 常要先转成 $[N,D,L]$，再跨 N 和 L 统计；这会把不同位置放进同一个统计池，不是纯粹的轴语法变化。

归一化不等同于原始数据标准化，也不保证泛化或消除全部分布变化。小批量、在线推理、变长 padding 和跨域数据都可能改变方法是否合适，应按实际统计含义选择。
:::

### 同一 2×2 表按列或按行标准化

第一种结果表达“这个样本在两个特征上都低于批内均值”，第二种表达“每条样本的第一个特征都低于自身均值”。它们保存和抹去的信息不同，不能仅按有没有 train/eval 差异互换。

代码保留默认 epsilon 并只格式化到三位小数，便于对照手算；实际实现不应为了精确得到 ±1 而把 epsilon 删除。

### 同一 2×2 表按列或按行标准化的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对同一 2×2 表按列或按行标准化，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
x = torch.tensor([[1., 3.], [5., 7.]])
bn = nn.BatchNorm1d(2, affine=False, track_running_stats=False)
ln = nn.LayerNorm(2, elementwise_affine=False)
for name, y in [("BN", bn(x)), ("LN", ln(x))]:
    print(name, [[round(v, 3) for v in row] for row in y.tolist()])
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 同样的二维输入比较两套统计轴。
- 显式关闭 affine，避免学习参数遮蔽标准化本身。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
BN [[-1.0, -1.0], [1.0, 1.0]]
LN [[-1.0, 1.0], [-1.0, 1.0]]
```
:::
