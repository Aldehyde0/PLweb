## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
序列的当前含义往往依赖先前内容。RNN 将过去压缩进隐藏状态，再与当前输入共同更新，使同一单元可以逐步处理不同长度的数据。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
循环神经网络在时间上重复使用同一组参数，通过隐藏状态连接相邻时刻。普通 RNN 常以线性组合加 tanh 更新状态。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
边读句子边维护一份会更新的笔记；每个新词既参考自身，也参考之前的笔记。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
状态更新可写为 h_t=tanh(W_x x_t+W_h h_prev+b)。输入、循环权重在所有时间步共享，所以增加序列长度增加计算步数，不自动增加模型参数。初始状态通常为零，也可由任务另行指定。

训练按时间展开后执行 BPTT，梯度沿循环链相乘。反复乘较小或较大局部导数会造成梯度消失或爆炸，这也是长依赖较难学习的原因；裁剪只能限制爆炸，不能直接恢复已经消失的信息。

PyTorch batch_first 只控制输入与 output 的轴，最终状态仍按层数×方向数、batch、hidden 排列。变长输入应使用 packed sequence 或明确 mask，直接取 out[:, -1] 可能取到 padding 后的状态。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 标量 RNN 记住上一步
:::

:::field{path="numericalExample.given" type="list"}
- h0=0，输入为 1、0
- 输入权重与循环权重均为 1，无偏置
:::

:::field{path="numericalExample.steps" type="ordered"}
1. h1=tanh(1)，约 0.761594。
2. h2=tanh(h1)，约 0.642015。
:::

:::field{path="numericalExample.result" type="text"}
第二步输入为零，状态仍保留第一步影响。
:::

:::field{path="numericalExample.comparison" type="list"}
- 有限隐藏状态不是完整历史副本，普通 RNN 的长依赖与状态重置都需要特别检查。
:::

### 标量 RNN 记住上一步

如果没有循环项，第二步输出就是 tanh(0)=0。保留下来的 0.642 显示状态依赖过去，但每次 tanh 也会改变幅度，不能把隐藏状态当作无损历史存储。

同一权重被用两次，反向的贡献会汇总到这组共享参数。在线推理中可以携带状态；跨独立样本则必须重置，避免串入上一条序列的信息。

### 标量 RNN 记住上一步的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对标量 RNN 记住上一步，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
rnn = nn.RNN(1, 1, bias=False, batch_first=True)
with torch.no_grad():
    rnn.weight_ih_l0.fill_(1.)
    rnn.weight_hh_l0.fill_(1.)
out, h = rnn(torch.tensor([[[1.], [0.]]]))
print([round(v, 6) for v in out.detach().flatten().tolist()])
print("output:", tuple(out.shape), "hidden:", tuple(h.shape))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 固定循环权重，与手算更新完全对应。
- batch_first 不改变 h 的轴约定。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
[0.761594, 0.642015]
output: (1, 2, 1) hidden: (1, 1, 1)
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### RNN 的参数量会随序列长度增加吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
同一层的参数在时间上共享，因此不随长度增加；计算量和反向保存的激活通常会随长度增加。
:::

:::field{path="commonQuestions.1.question" type="text"}

:::

:::field{path="commonQuestions.1.answer" type="text"}
