## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
单个注意力分布只能用一套投影衡量位置关系。多头注意力把表示投影到多个子空间，让不同关系能够并行形成再被融合。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
多头注意力对 Q、K、V 做可学习投影，按 head 拆分后分别计算缩放点积注意力，再拼接各头并执行输出投影。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
同一段文字交给多组不同观察角度，每组产生自己的信息汇总，再把结果一起整合。观察角度由训练学出，不保证自然对应可命名语法规则。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
若总维度 D、头数 H，每头常取 d_h=D/H，所以 D 必须能被 H 整除。分数张量典型形状为 $[N,H,L_q,L_k]$，softmax 在 key 轴归一化；输出合并回 $[N,L_q,D]$。

每头的输入来自投影，不是简单把原始 token 切成互不关联的几段；完整 Q、K、V 线性投影通常先混合特征。缩放使用每头 d_h 的平方根，避免高维点积量级过大。

PyTorch MultiheadAttention 默认返回跨头平均权重；要检查每头应设置 average_attn_weights=False。注意力权重是计算中的混合系数，不能单独当作模型解释或因果贡献。
:::

### 两头注意力核对分数与输出形状

若只打印默认权重，会看到 (2,3,3)，容易误以为网络只有一个头。该形状是平均后的结果，计算中仍有两个独立分布。

示例关闭 dropout 并评估，检查归一化性质。训练时若对权重施加 dropout，单次返回的注意力行和可能不再严格为 1，不能把这一检查不加条件用于所有模式。

### 两头注意力核对分数与输出形状的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对两头注意力核对分数与输出形状，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
torch.manual_seed(7)
mha = nn.MultiheadAttention(8, 2, dropout=0., batch_first=True)
mha.eval()
x = torch.zeros(2, 3, 8)
with torch.inference_mode():
    y, weights = mha(x, x, x, average_attn_weights=False)
print("output:", tuple(y.shape), "weights:", tuple(weights.shape))
print("rows sum to one:", bool(torch.allclose(weights.sum(-1), torch.ones(2, 2, 3))))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 显式返回各头权重。
- dropout=0 使行归一化检查条件明确。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
output: (2, 3, 8) weights: (2, 2, 3, 3)
rows sum to one: True
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 头数加倍会让输出维度加倍吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
若保持总维度 D 不变，通常每头维度相应减半，拼接后仍是 D；头数和总维度应分别理解。
