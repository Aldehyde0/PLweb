shape 是公式的单位检查。就像不能把米和秒直接相加，也不能把“每个样本的损失”与“每个类别的分数”当成同一个维度。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
矩阵 $X\in\mathbb R^{N\times D}$ 的行通常表示样本、列表示特征，$XW^T$ 把 D 维表示变为 H 维。求和、均值和广播都要明确轴；对类别求 softmax 和对样本求 softmax 对应完全不同的概率解释。

链式法则把损失对输出的变化率，沿各层局部导数传回参数。若 $\hat y=wx$、$L=(\hat y-y)^2$，则 $\partial L/\partial w=2(wx-y)x$。梯度与参数形状相同，标量损失不会意味着只有一个参数梯度。

概率目标常含指数和对数。softmax 的分子分母可同时减去最大 logit，避免 exp 溢出；logsumexp 直接在对数域完成归一化。交叉熵分解为熵与 KL 时，两个分布及其支持也必须明确。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 同时核对链式法则与稳定 softmax
:::

:::field{path="numericalExample.given" type="list"}
- w=1，x=2，目标 y=6
- 分类 logits 为 1000 和 1001
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 预测为 2，平方损失为 16。
2. 梯度为 2×(2−6)×2=-16。
3. 对 logits 减去 1001，再求 softmax。
:::

:::field{path="numericalExample.result" type="text"}
梯度为 -16；两个概率约为 0.268941 与 0.731059，和为 1。
:::

:::field{path="numericalExample.comparison" type="list"}
- 平移技巧解决指数溢出，不能修复输入本身含 NaN 或错误的概率建模。
:::

### 案例推演与判断

如果只用损失对预测的导数 -8 更新 w，就漏掉了乘数 x=2。自动微分能避免手写每条链，但仍需要手算小例子确认目标和路径没有接错。

直接计算 exp(1001) 会超出常见浮点范围，而减去最大值后只需 exp(-1) 与 exp(0)。这种平移不改变 softmax 概率，因为分子分母拥有相同缩放。

### 同时核对链式法则与稳定 softmax的最小验证

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对同时核对链式法则与稳定 softmax，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
w = torch.tensor(1., requires_grad=True)
loss = (w * 2 - 6) ** 2
loss.backward()
prob = torch.softmax(torch.tensor([1000., 1001.]), dim=0)
print(f"loss={loss.item():.1f} grad={w.grad.item():.1f}")
print([round(v, 6) for v in prob.tolist()])
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 标量例子对应显式链式求导。
- softmax 使用稳定实现，未直接计算大指数。
:::

```text
loss=16.0 grad=-16.0
[0.268941, 0.731059]
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 为什么要先确认 softmax 的维度？
:::

:::field{path="commonQuestions.0.answer" type="text"}
归一化轴决定哪些元素相互竞争。多分类通常按类别归一化；若沿 batch 轴归一化，一条样本的概率会依赖同批其他样本。
:::
