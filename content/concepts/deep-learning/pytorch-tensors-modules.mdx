## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Tensor 具有 shape、dtype、device、requires\_grad；Module 注册子模块和状态。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
Tensor 是数据容器，Module 是会管理状态的计算单元。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
通过 model(x) 调用 forward；Parameter 参与优化，buffer 随模型移动和保存但不训练。

state\_dict 保存参数与持久 buffer，不保存类定义。
:::

```PyTorch
class Tiny(nn.Module):
    def __init__(self):
        super().__init__();self.fc=nn.Linear(10,4)
    def forward(self,x):return self.fc(x)
print(Tiny()(torch.randn(8,10)).shape)
```
