## 为什么需要这个概念 {#importance}

:::field{path="importance" type="paragraphs"}
全局范数裁剪把所有参与参数的梯度看成一个向量；范数超过阈值 M 时按同一比例缩小，低于阈值时保持。它与逐元素截断不同。
:::

## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
循环网络或困难批次可能产生很大的梯度，使一次更新破坏已有参数。梯度裁剪限制更新方向的输入幅度，用于控制这种瞬时风险。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
全局范数裁剪把所有参与参数的梯度看成一个向量；范数超过阈值 M 时按同一比例缩小，低于阈值时保持。它与逐元素截断不同。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不是把方向重新指向别处，而是把过长的箭头缩短；各参数之间的相对比例尽量保留。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
若梯度向量 g 的 L2 范数为 G，裁剪系数约为 min(1,M/G)。clip_grad_norm_ 原地修改梯度，并返回裁剪前总范数。阈值是梯度尺度，和学习率共同影响实际参数变化。

顺序通常是 backward、必要时 AMP unscale、clip、optimizer.step。若在 scaled 梯度上裁剪，阈值会被缩放因子扭曲；若在 backward 前裁剪，则没有本步梯度可处理。

裁剪不能修复 NaN 损失、标签越界或除零。若频繁触发，应检查学习率、数据异常和目标归一化；持续强裁剪可能掩盖更深问题，也可能让有效更新过小。
:::

### 核心公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
g\leftarrow g\min(1,M/(\lVert g\rVert_2+\varepsilon))
$$
:::

### 把 (3,4) 梯度裁剪到范数 1

如果逐元素把每个值截到 1，会得到 (1,1)，方向从 3 比 4 改为 1 比 1。范数裁剪与值裁剪即使使用相同阈值，也不是相同算法。

代码保留框架为数值稳定加入的极小项，因此输出格式化到三位小数，不把微小浮点差异误认成公式错误。

:::field{path="codeExamples.0.language" type="text"}

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对把 (3,4) 梯度裁剪到范数 1，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
p = torch.nn.Parameter(torch.zeros(2))
p.grad = torch.tensor([3., 4.])
before = torch.nn.utils.clip_grad_norm_([p], 1., error_if_nonfinite=True)
print(f"before={before.item():.3f} after={p.grad.norm().item():.3f}")
print([round(v, 3) for v in p.grad.tolist()])
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 返回值是裁剪前范数。
- 不执行优化，单独验证梯度变换。
:::

```text
before=5.000 after=1.000
[0.6, 0.8]
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 裁剪后为什么损失仍可能爆炸？
:::

:::field{path="commonQuestions.0.answer" type="text"}
裁剪不改变坏输入或不稳定前向，而且 Adam 等优化器还有内部状态；应检查非有限数值来源及整体更新设置。
:::

:::field{path="commonQuestions.1.question" type="text"}
### 这个示例能说明什么边界？
:::

:::field{path="commonQuestions.1.answer" type="text"}
裁剪限制有限梯度的幅度；非有限梯度应定位原因而不是靠阈值隐藏。
:::
