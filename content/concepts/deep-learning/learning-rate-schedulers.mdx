## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
训练初期大步探索、后期小步调整是常见策略，但学习率不能只凭曲线名称设置。总更新数、热身长度和调用位置都决定真正执行的序列。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
学习率调度将训练进度或验证反馈映射为学习率。固定阶梯、余弦、热身、单周期和平台衰减分别表达不同的时间或反馈假设。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
调度表像按里程安排速度。如果把每个数据批当作里程，而实际两批才更新一次，速度表会提前走完。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
余弦衰减在指定区间把学习率从最大值平滑降到最小值。公式中的 t 与 T 必须是同一单位；若 T=1000 个更新，不能把 t 当 epoch。热身常用于逐渐放大学习率，长度也要记录单位。

StepLR、CosineAnnealingLR 等通常在优化器更新后调用，是否按批或按轮取决于配置。ReduceLROnPlateau 则需要验证指标，并在持续不改善时降低学习率，不能把它按普通无参数 step 使用。

断点恢复必须保留调度器计数与优化器当前学习率。改变 batch 大小、梯度累积或剩余预算后，还要决定延续原计划还是重定计划，避免日志看似连续、数值已经重启。
:::

### 四步余弦调度的端点与中点

这里 T_max 指四次调度调用。代码同时打印起点，再逐次更新并打印下一步学习率，便于对应公式端点。

若训练只做两次更新，却每批调用四次，学习率会过早降到底。反之不推进则始终停留在初始值；两者都不能仅凭选择了 Cosine 名称保证正确。

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对四步余弦调度的端点与中点，输出只表示本例计算。

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
p = torch.nn.Parameter(torch.tensor(0.))
opt = torch.optim.SGD([p], lr=0.1)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=4)
print(f"t=0 lr={opt.param_groups[0]['lr']:.6f}")
for t in range(1, 5):
    p.grad = torch.zeros_like(p)
    opt.step()
    scheduler.step()
    print(f"t={t} lr={opt.param_groups[0]['lr']:.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 四次更新与四次调度严格配对。
- 打印的是调度后供下一步使用的值。
:::

```text
t=1 lr=0.085355
t=2 lr=0.050000
t=3 lr=0.014645

```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- step 顺序反
- 所有 scheduler 放 epoch 末
- Plateau 不传指标
- 累积每微批推进
:::
