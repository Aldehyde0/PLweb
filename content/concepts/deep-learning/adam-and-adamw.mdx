## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
不同参数的梯度尺度可能相差很大，普通固定步长更新需要细致调节。Adam 利用历史梯度估计为各参数调整更新尺度，而 AdamW 进一步区分数据梯度与权重衰减。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Adam 维护梯度一阶矩 m 与平方梯度二阶矩 v，进行偏差修正后更新；AdamW 在该更新之外直接按比例缩小权重，避免衰减项混入自适应矩估计。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
Adam 按每个参数过去的梯度量级调整步幅；AdamW 另外施加一个持续把参数拉向零的动作。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
一阶矩是梯度的指数移动平均，二阶矩是梯度平方的指数移动平均。初始矩为零会偏小，因此用与步数相关的因子修正。分母使用二阶矩的平方根和 epsilon，不能把 v 理解成严格的梯度方差。

经典耦合 L2 会先把衰减项加到梯度，再参与 m、v 的更新；AdamW 的衰减直接作用于参数，因此相同 weight_decay 数字不保证与 Adam 的 L2 相同效果。学习率仍然影响衰减幅度。

参数组可以为骨干、任务头、偏置和归一化设置不同规则，但应遵循验证过的训练配方。优化器状态包含矩和步数，恢复训练只加载模型参数会改变后续轨迹。
:::

### 零数据梯度时隔离 AdamW 衰减

这个例子显式设置零梯度，而不是让 grad=None。PyTorch 优化器可能跳过没有梯度的参数，所以这两种状态不能混为一谈。

非零历史矩还会继续产生自适应更新，本例使用新优化器以隔离衰减。真实训练不能只根据参数变小就认定某次更新只有正则项。

2. 执行解耦缩放 2×(1−0.1×0.2)。
:::

:::field{path="codeExamples.0.title" type="text"}
### 零数据梯度时隔离 AdamW 衰减的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对零数据梯度时隔离 AdamW 衰减，输出只表示本例计算。

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
p = torch.nn.Parameter(torch.tensor(2.))
optimizer = torch.optim.AdamW([p], lr=0.1, weight_decay=0.2)
p.grad = torch.zeros_like(p)
optimizer.step()
print(f"parameter={p.item():.4f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 新建优化器，没有历史矩干扰。
- 显式零梯度保留权重衰减更新。
:::

```text
parameter=1.9600
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### Adam 的二阶矩就是梯度方差吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是，它估计梯度平方的移动平均，未减去均值平方；将其当成严格方差会误解分母的作用。
:::

:::field{path="commonQuestions.1.question" type="text"}
### 这个示例能说明什么边界？
:::

:::field{path="commonQuestions.1.answer" type="text"}
自适应步长不等于无需调学习率；grad=None 与零梯度的更新行为也可能不同。
:::
