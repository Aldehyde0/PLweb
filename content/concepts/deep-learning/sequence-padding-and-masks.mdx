## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
同一批句子长度不同，直接堆叠会失败。padding 把形状补齐，但补出来的位置不是真实内容，必须避免它们影响表示、损失和指标。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
padding 为变长样本补上占位值，mask 标注哪些位置有效。有效位置、禁止注意力位置与损失忽略位置是相关但不同的接口。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
补齐的空座位只是为了让每排长度相同，统计乘客数量时不能把空座也当人。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
右侧 padding 时，可用位置索引小于长度生成 valid mask。动态按批内最大长度补齐可减少浪费；若按固定全局最大长度，短样本会承担较多无用计算。左 padding 则可能需要重新定义位置编号。

序列求均值时用 mask 控制分子和分母，token 级损失可使用 ignore_index 或 masked reduction，评估同样只计有效 token。只在模型输入置零并不足够，因为偏置、位置编码和注意力仍能让 padding 产生非零表示。

不同 API 对 bool mask 的方向约定可能相反。应明确 valid 的 True 表示有效，转换成某个模块的屏蔽 mask 时再取反，避免同一个变量在不同上下文混用。全空序列还需要单独的数据策略。
:::

### 两条序列的有效位置计数

即使 padding 恰好是零，错误也已存在于分母。若后续加了位置向量，分子同样会被污染，所以应贯穿模型、池化、损失和评估检查 mask。

本例没有全空样本。代码分母使用 clamp_min 避免数值除零，但不会因此把空序列变成有意义的数据；真实输入应事先决定是否拒绝或映射为空标记。

## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 两条序列的有效位置计数的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对两条序列的有效位置计数，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
lengths = torch.tensor([3, 1])
x = torch.tensor([[1., 2., 3.], [4., 0., 0.]])
valid = torch.arange(3)[None, :] < lengths[:, None]
means = (x * valid).sum(1) / valid.sum(1).clamp_min(1)
print(valid.tolist())
print("valid counts:", valid.sum(1).tolist())
print("masked means:", means.tolist())
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 明确 True 表示有效位置。
- 分子和分母都使用同一有效 mask。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
[[True, True, True], [True, False, False]]
valid counts: [3, 1]
masked means: [2.0, 4.0]
```
:::
