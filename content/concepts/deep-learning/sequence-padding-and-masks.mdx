## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
padding 只是组批工具，不应参与注意力、池化、损失或指标。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
valid\_mask=True 常表示真实 token；某些 API 的 padding mask=True 反而表示屏蔽。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
补齐的空位只是占位，不是模型应学习的内容。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
动态 padding 减少浪费；mask 形状、device、dtype 和布尔方向必须匹配 API。

左 padding 可能需基于有效 mask 重新编号位置。
:::
