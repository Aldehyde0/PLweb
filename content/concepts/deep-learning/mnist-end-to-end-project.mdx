## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
常见输入为 $[N,1,28,28]$，标签为 $[N]$ 的 long 索引，模型输出 $[N,10]$ 原始 logits。归一化统计仅从训练部分估计，随机增强只在语义允许时使用，验证保持确定性。

每个训练批执行清梯度、前向、交叉熵、反向和更新；验证使用 eval 与关闭梯度，按样本汇总损失和正确数。最佳权重按验证规则保存，不能拿测试集挑 epoch。

正式项目还应检查混淆数字和错误样本，保存类别表、配置及预处理，加载后复核固定输入。下面代码仅做无需下载的数据与训练路径烟雾检查，真实 MNIST 评估需另行准备官方数据与独立划分。
:::

### 合成灰度批次检查完整训练路径

全零图像与编号标签并不构成真实识别任务，因此代码不报告所谓 MNIST 准确率。它的用途是验证所有组件可以连通，并防止不完整的 MNISTCNN、loader 或 evaluate 名称让示例无法独立运行。

正式替换为真实数据后，先保留同样的 shape 与 dtype 检查，再加入独立验证、最佳检查点和最终测试。这样才能把结构正确与任务效果分开核对。

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import torch
from torch import nn
torch.manual_seed(7)
model = nn.Sequential(nn.Conv2d(1, 4, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), nn.Flatten(), nn.Linear(4 * 14 * 14, 10))
x = torch.zeros(4, 1, 28, 28)
target = torch.tensor([0, 1, 2, 3])
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
model.train()
optimizer.zero_grad(set_to_none=True)
logits = model(x)
loss = nn.CrossEntropyLoss()(logits, target)
loss.backward()
optimizer.step()
print("logits:", tuple(logits.shape), "target dtype:", target.dtype)
print("finite loss:", bool(torch.isfinite(loss)))
print("all gradients present:", all(p.grad is not None for p in model.parameters()))
```
:::

- 无外部数据下载或隐藏辅助函数。
- 明确标注合成数据，只报告结构与数值检查。
:::
