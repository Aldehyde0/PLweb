## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
高基数特征、相关特征和训练偏差会扭曲重要性；相关特征可能分摊贡献。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
feature\_importances\_ 汇总特征用于分裂时加权不纯度下降。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
它回答“模型在这组树里多常靠该特征降低不纯度”，不回答“现实中它造成了结果”。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
配合置换重要性、跨折稳定性和领域实验；重要性计算也必须基于可靠评价。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 训练可靠模型
2. 提取不纯度重要性
3. 在验证数据做置换重要性
4. 检查相关特征
5. 跨折比较
6. 限制解释语言
:::
