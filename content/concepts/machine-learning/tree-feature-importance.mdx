## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
一棵树经常使用某个特征，不代表改变该特征会导致结果变化。高基数变量有更多尝试划分的机会，相关特征又可能互相替代。重要性分数首先解释特定模型的使用方式，而不是现实世界的因果关系。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
不纯度重要性 MDI 汇总某特征参与分裂时带来的样本加权不纯度下降，再按总量归一化。置换重要性固定已训练模型，在指定评价数据上打乱一个特征并测量分数下降，回答该模型对该特征信息的依赖程度。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
一本复习资料经常被翻阅，并不证明没有它就会考差；也可能有另一本内容相同的资料。置换像临时把一份资料的页码打乱，观察现有答题方法受多大影响，但并不是重新训练后能否适应。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
MDI 在训练分裂上计算，可能偏向连续或高基数特征，并把过拟合噪声也记作贡献。分数为零只说明当前模型没使用它，不说明该变量在任何合理模型中都无价值。

置换应在独立验证数据上使用与任务一致的 scoring，并重复计算不确定性。高相关特征互相替代会降低单列置换损失；独立打乱还可能制造不现实组合，分组置换也需要领域约定。

重要性应先建立在模型有足够预测能力的前提上。跨折比较、相关簇分析和领域干预可补充证据；若用置换结果筛选特征，就需要训练内嵌套选择与独立最终测试，不能反复消费同一测试集。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 置换引起的评分下降
:::

:::field{path="formulas.0.expression" type="math"}
$$
I_j=\operatorname{score}(f,X,y)-\mathbb E_{\mathrm{perm}(j)}[\operatorname{score}(f,X^{\mathrm{perm}(j)},y)]
$$
:::

:::field{path="formulas.0.description" type="text"}
模型固定不重训；若 scoring 越大越好，正下降表示置换损害该模型表现。
:::

## 手算与场景核对 {#worked-example}

假设树的加权不纯度下降中，特征 A 贡献 0.2，B 贡献 0.1，归一化 MDI 为 2/3 和 1/3。这些比例分配的是已建成树的分裂改善，不是目标的因果解释份额。

若验证准确率为 0.90，置换 A 后平均为 0.70，则本协议的置换重要性为 0.20；换模型、换验证分布或存在相关替代特征，数值都可能改变。下方使用固定构造数据执行这一计算。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 先固定独立验证与评分指标，训练可靠基线。
2. 读取 MDI 并检查基数、泄漏列和训练过拟合。
3. 在验证数据对各列重复置换，保留均值和波动。
4. 检查相关列是否互相替代，必要时按组分析。
5. 仅作模型依赖解释；特征筛选与因果结论另需验证。
:::

:::field{path="codeExamples.0.purpose" type="text"}

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance
from sklearn.model_selection import train_test_split

X, y = make_classification(n_samples=200, n_features=4, n_informative=2,
                           n_redundant=1, random_state=42)
X_train, X_valid, y_train, y_valid = train_test_split(X, y, test_size=0.3,
                                                    stratify=y, random_state=42)
model = RandomForestClassifier(n_estimators=50, min_samples_leaf=2, random_state=42)
model.fit(X_train, y_train)
result = permutation_importance(model, X_valid, y_valid, n_repeats=5,
                                scoring="accuracy", random_state=42)
print(f"validation_accuracy={model.score(X_valid, y_valid):.4f}")
print("MDI=" + ",".join(f"{x:.4f}" for x in model.feature_importances_))
print("permutation=" + ",".join(f"{x:.4f}" for x in result.importances_mean))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 模型只在训练划分 fit；置换时固定该模型。
- MDI 与置换数值的定义和尺度不同，不能要求总和相同。
- 构造数据含冗余特征，可提醒相关性解释风险，但不能推断真实业务因果。
:::


## 实际应用 {#applications}

:::field{path="applications" type="list"}
- 发现模型过度依赖 ID、时间泄漏或代理特征。
- 为后续特征分析形成候选，结合跨折稳定性筛选检查重点。
:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把模型重要性写成因果效应或业务贡献比例。
- 在训练集做置换后将分数作为独立泛化证据。
- 相关特征单列置换损失小，就认定它们都没用。
:::
