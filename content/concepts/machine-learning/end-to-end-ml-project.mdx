## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
Wine 项目的任务是根据化学测量识别三类葡萄酒来源类别，不是给酒打质量等级。这个小型数据集适合练习实验链条：数据是否一致、特征怎样处理、怎样比较模型，以及最终模型怎样被正确恢复使用。

一次 fit 成功只覆盖其中一环。若测试集参与了选型、标准化在全数据拟合，或者交付时丢失特征顺序，即使分数很高也没有形成可靠的端到端项目。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
端到端项目要求每个阶段都有明确输入、输出和边界，最终产物是完整 Pipeline 与可复现报告。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
把项目当作一条可复现、可审计的实验链，而不是追求一次最高分。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
先固定任务与输入契约。Wine 有 178 行、13 个数值特征，标签为三类；应检查形状、类别数量、缺失和特征定义，并保留原始行标识。不同化学量纲使缩放对距离模型和正则化模型尤其相关，不能只按列数拼接未知输入。

使用固定分层划分留下 20% 测试集，剩余部分用于比较与调参。基线、逻辑回归、KNN 和树模型共享同一组训练内验证折；各自需要的预处理放进 Pipeline，每折重新学习，不在全部数据上先标准化。

主指标在搜索前固定为 macro F1，并保留每折结果、候选参数与时间。GridSearchCV 的 best_score_ 是选择依据，不是独立测试结果；refit 使用整个开发部分，但仍不能触碰留出的测试样本。

配置锁定后评价最终测试，检查混淆矩阵与错误，并把局限写进报告。若据测试错误继续改模型，原测试结果就已经进入开发，需要另有独立验证，不能反复挑最好的测试分数。

交付应保存完整已拟合 Pipeline、特征顺序、类别、版本和实验记录。恢复后先用固定输入检查预测一致，再考虑批量预测与监控；小数据集上的成绩不证明真实化学仪器、其他产地或新时期样本同样适用。
:::

### 案例：从候选搜索到可信文件往返

下方最小闭环先保留 36 行测试，142 行开发数据在同一组 5 折内比较常量基线、逻辑回归、KNN、树和随机森林。候选共 8 组配置，因此搜索需要 40 次折内拟合，再做一次开发集 refit。

只有选定配置后才预测留出测试，并把已拟合流程保存到临时目录，再加载本进程刚创建的可信文件核对预测一致。加载成功不证明泛化，测试分数也仅描述该固定教学划分；没有把 Wine 类别解释为质量好坏。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 审计 Wine 的 178 行、13 个特征、三类标签与数值范围，保存特征顺序。
2. 固定分层开发/测试索引，测试集仅保留，不用于选模型。
3. 将基线、需要缩放的模型和树模型注册为带完整预处理的候选。
4. 在开发部分用同一组五折比较，记录 macro F1、逐折分数与计算开销。
5. 只在开发部分搜索参数，锁定选择规则并 refit 完整流程。
6. 评价最终测试，检查混淆与错误，说明数据范围和未验证条件。
7. 保存可信 Pipeline、元数据和实验报告，核对加载前后预测一致。
8. 验证推理输入契约，并为数据质量、分布与延迟标签效果设计监控。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
from pathlib import Path
from tempfile import TemporaryDirectory
import json
import joblib
import numpy as np
import sklearn
from sklearn.datasets import load_wine
from sklearn.dummy import DummyClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, f1_score
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.tree import DecisionTreeClassifier

data = load_wine()
X, y = data.data, data.target
assert X.shape == (178, 13) and np.isfinite(X).all()
train, test = train_test_split(np.arange(len(y)), test_size=0.2, stratify=y, random_state=42)
cv = list(StratifiedKFold(5, shuffle=True, random_state=42).split(X[train], y[train]))
pipeline = Pipeline([("scale", "passthrough"), ("model", DummyClassifier())])
grid = [
    {"scale": ["passthrough"], "model": [DummyClassifier(strategy="most_frequent")]},
    {"scale": [StandardScaler()], "model": [LogisticRegression(max_iter=3000)], "model__C": [0.1, 1.0]},
    {"scale": [StandardScaler()], "model": [KNeighborsClassifier()], "model__n_neighbors": [5, 9]},
    {"scale": ["passthrough"], "model": [DecisionTreeClassifier(random_state=42)], "model__max_depth": [3, None]},
    {"scale": ["passthrough"], "model": [RandomForestClassifier(n_estimators=50, random_state=42)]},
]
search = GridSearchCV(pipeline, grid, cv=cv, scoring="f1_macro", refit=True)
search.fit(X[train], y[train])
prediction = search.predict(X[test])
print("train_test:", (len(train), len(test)))
print("candidates:", len(search.cv_results_["params"]))
print("selected:", type(search.best_estimator_.named_steps["model"]).__name__)
print(f"selection_cv_macro_f1={search.best_score_:.3f}")
print(f"test_accuracy={accuracy_score(y[test], prediction):.3f}")
print(f"test_macro_f1={f1_score(y[test], prediction, average='macro'):.3f}")
with TemporaryDirectory() as temporary:
    root = Path(temporary)
    joblib.dump(search.best_estimator_, root / "wine.joblib")
    metadata = {"features": list(data.feature_names), "classes": search.classes_.tolist(), "sklearn": sklearn.__version__}
    (root / "metadata.json").write_text(json.dumps(metadata), encoding="utf-8")
    loaded = joblib.load(root / "wine.joblib")
    assert np.array_equal(prediction, loaded.predict(X[test]))
    print("round_trip_predictions_equal:", True)
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 8 组候选共享保存的五折索引，缩放器随训练折重新拟合。
- 选择分数和测试分数分开输出；测试没有参与 search.fit。
- 临时保存包含整个 Pipeline，metadata 记录特征、类别与依赖，round-trip 检查不等同泛化评价。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 Wine 标签当作质量等级，或把内置数据的分数当作真实业务认证。
- 以测试分数挑模型、随机种子或搜索范围，随后仍声称测试独立。
- 只保存分类器而丢失缩放、特征名和环境版本；加载不可信模型文件。
:::
