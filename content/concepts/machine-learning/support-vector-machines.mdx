## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
多个边界都能分开训练点时，SVM 偏好离最近点更远的边界。这个间隔偏好与软间隔错误惩罚共同决定模型，而核方法进一步改变距离空间。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
支持向量机寻找最大间隔边界，软间隔允许一定违例。支持向量是对边界有约束作用的训练点；核函数以相似度隐式表达非线性特征空间。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
在两类之间放一条尽量宽的路，同时允许少数难点进入路内，而不是为每个噪声点把路弯得很复杂。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
线性软间隔目标由权重范数和 hinge 违例惩罚组成。标签常写为 ±1，间隔条件是 y×score 不小于 1。C 越大越重视违例，C 越小则更强地偏向较小权重；这不保证训练准确率总呈严格单调。

RBF 核为 exp(-gamma×距离平方)。gamma 大使单点影响更局部，可能形成复杂边界；gamma 小产生更宽相似范围。尺度直接改变距离，所以 StandardScaler 与 C、gamma 搜索应在同一个交叉验证 Pipeline 内。

SVC 的 decision_function 不是默认校准概率，启用概率估计还带来额外计算与验证问题。核 SVM 大样本训练成本可能高，线性 SVM 或其他基线可能更合适，需连同预测成本和支持向量数量一起比较。
:::

### 一维最大间隔由最近两点决定

- 负类位置为 -2、-1，正类为 1、2
- 使用线性 SVC，C=1000

四条预测分别为 -1、-1、1、1，支持向量为 -1 和 1。

距离边界更远的 -2 和 2 没有收紧当前间隔，因此不必都成为支持向量。若在间隔附近加入噪声点，软间隔惩罚会参与权衡，不能仍机械套用这个边界。

RBF 情况没有同样简单的原空间直线间隔解释。相隔 2 时，gamma=0.25 的相似度为 exp(-1)，gamma=4 则为 exp(-16)，可见同样数据在不同核尺度下相似程度差很多。



## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 核心表达
:::

:::field{path="formulas.0.expression" type="math"}
$$
\min_{w,b}\frac12\lVert w\rVert^2+C\sum_i\max(0,1-y_i(w^Tx_i+b)),\quad K(x,x^\prime)=e^{-\gamma\lVert x-x^\prime\rVert^2}
$$
:::

:::field{path="formulas.0.description" type="text"}
左侧为线性二分类 hinge 目标，右侧为 RBF 核；核化改变表示空间，不能把两者混成同一个原空间线性函数。
:::

::::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 先定义可比较的特征尺度和合法划分。
2. 在线性与核候选中交叉验证 C、gamma 等参数。
3. 核查支持向量、验证误差和训练预测成本。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
import math
import numpy as np
from sklearn.svm import SVC
x = np.array([[-2.], [-1.], [1.], [2.]])
y = np.array([-1, -1, 1, 1])
model = SVC(kernel="linear", C=1000).fit(x, y)
print("support vectors:", model.support_vectors_.flatten().tolist())
print("predictions:", model.predict(x).tolist())
for gamma in [0.25, 4.]:
    print(f"gamma={gamma:.2f} similarity_at_distance_2={math.exp(-gamma * 4):.8f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 对称小数据使间隔可手算。
- RBF 数值只解释相似度，未冒充核模型效果。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 未缩放
- C/gamma 都过大
- 无需求却开启 probability
:::
