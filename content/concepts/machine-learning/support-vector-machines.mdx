## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
中小型高维数据常表现良好，但对尺度和参数敏感，大数据训练成本可能较高。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
SVM 的边界由最靠近间隔的支持向量决定；C 控制错误惩罚，RBF gamma 控制局部影响范围。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不仅分开两类，还在两侧留出尽量宽的安全走廊。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
C 小正则更强、边界更平滑；gamma 大影响更局部。两者和标准化必须在 Pipeline 内交叉验证。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 标准化
2. 选择核
3. 设 C/gamma 对数范围
4. 分层 CV
5. 检查支持向量与验证稳定性
:::

from sklearn.preprocessing import StandardScaler
model=make_pipeline(StandardScaler(),SVC(kernel="rbf",C=1,gamma="scale"))
