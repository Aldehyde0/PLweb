## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
对尺度、初始化、异常值和非球形簇敏感；编号不带业务语义。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
K-Means 需要预先给 K，学习 K 个中心；轮廓系数比较本簇紧密度与最近其他簇距离。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不断重复“按最近中心分组”和“把中心移到组均值”。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
使用多次初始化并标准化。K 增大会单调降低簇内误差，肘部和轮廓只是参考，还需稳定性与业务解释。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```scikit-learn
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
labels=KMeans(n_clusters=3,n_init=20,random_state=42).fit_predict(X_scaled)
print(silhouette_score(X_scaled,labels))
```
