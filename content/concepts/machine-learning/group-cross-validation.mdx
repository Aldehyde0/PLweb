## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
同一对象跨折会让模型通过身份特征认出验证记录，结果无法代表新对象。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
groups 标识相互依赖的样本集合；GroupKFold 以组为不可拆分单位。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
一个人的多次记录必须整组进入同一考场。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
分组隔离通常优先于简单分层。若同时关心类别比例，可用 StratifiedGroupKFold。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 定义群组 ID
2. 检查每组样本数
3. 选 GroupKFold
4. 传 groups 参数
5. 验证无交集
6. 报告组级分布
:::
