## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
形状错误、样本标签错位和把单样本降成一维，是传统机器学习最常见的接口与语义错误。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
sklearn 表格输入通常为 X.shape=(n\_samples,n\_features)，分类/回归目标常为 y.shape=(n\_samples,)。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
X 是题目表，每行一道题；y 是答案列，行号必须一一对应。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
任何筛选、打乱和划分都必须对 X 与 y 使用相同索引；单条预测也通常保留二维形状 (1,d)。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 打印 X/y shape
2. 验证第一维相等
3. 随机检查样本标签对应
4. 划分时同时传入 X/y
5. 预测单条时保留二维
:::
