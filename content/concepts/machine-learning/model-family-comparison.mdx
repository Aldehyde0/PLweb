## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
KNN、贝叶斯和 SVM 的优势取决于数据表示与约束。拿不同划分或不同预处理的最高分比较，会把协议差异误当模型差异。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
模型家族比较在相同独立划分、指标和预算下，评估各家族的预测、波动、计算、概率语义及部署行为。预处理可不同，但必须各自在训练折学习。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
公平比较比赛成绩需要同一赛道，但选手仍可使用各自合规装备；不能为表面统一而故意省去某模型需要的缩放。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
KNN 依赖局部距离，把主要成本放在预测；高斯贝叶斯依赖类条件分布假设，参数少且推理快；SVM 依赖间隔与核，尺度和核参数尤其关键。它们不是同一目标的三种名称。

固定同一组交叉验证折，对每个模型分别用 Pipeline 处理拟合变换，再记录逐折指标。不要只保留最好一折；均值与波动说明不同方面，折间分数又并非完全独立，因此简单标准差不是严格置信区间。

若用交叉验证调很多超参数，最终性能估计可能还需要嵌套验证或独立测试。训练时间、延迟、内存与校准也应实际测量；不能从算法标签直接给出某项目的耗时结论。
:::

### 相同三折上的受控小型对照

- 构造十二个一维样本，前六个为负类、后六个为正类
- 固定三折 StratifiedKFold
- KNN 与 SVM 在各自 Pipeline 中缩放，GNB 使用其高斯特征模型

代码实际产生三组逐折分数；只对应这个构造数据，不能作为真实任务排名。

本例类别沿一条轴分开，刻意保持简单以验证比较协议。即使三家分数相同，也不意味着真实数据中三者等价，而是这套小数据没有足够区分力。

真实选择还要给定时延或概率要求。例如预测量很大时 KNN 的查询成本可能成为约束；需要概率时不能把 SVM 分数直接与 GNB 概率同口径比较。

:::field{path="algorithmSteps" type="ordered"}
1. 预先固定划分、指标、候选和资源约束。
2. 为每个候选建立必要的训练内预处理 Pipeline。
3. 保留逐折结果与资源测量，锁定方案后再测试。
:::

```python
import numpy as np
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.naive_bayes import GaussianNB
from sklearn.svm import SVC
x = np.array([-6., -5., -4., -3., -2., -1., 1., 2., 3., 4., 5., 6.]).reshape(-1, 1)
y = np.array([0] * 6 + [1] * 6)
cv = StratifiedKFold(3, shuffle=True, random_state=7)
models = {
    "KNN": make_pipeline(StandardScaler(), KNeighborsClassifier(3)),
    "GNB": GaussianNB(),
    "SVM": make_pipeline(StandardScaler(), SVC(kernel="linear", C=1)),
}
for name, model in models.items():
    scores = cross_val_score(model, x, y, cv=cv, scoring="accuracy")
    print(name, [round(v, 3) for v in scores.tolist()])
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 数据、折、模型和评价指标全部显式定义。
- 逐折分数为实际运行结果，但只针对构造案例。
:::
