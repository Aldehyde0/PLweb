## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
不同预处理要求必须由各自 Pipeline 体现，不能为了统一而省略必要步骤。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
模型比较不是只看最高平均分，还要比较尺度需求、训练/预测成本、稳定性、概率和解释方式。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
让每位选手使用合法装备、在同一赛道和计分规则下比赛。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
固定折、指标和随机种子；报告平均、标准差和耗时；测试集不参与候选选择。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 注册候选 Pipeline
2. 固定 StratifiedKFold
3. cross\_validate 多指标
4. 比较均值/波动/耗时
5. 锁定模型
6. 最终测试
:::
