## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
树不能只看某个子节点是否纯，还要评估整个划分对父节点的总体改善。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Gini=1-类别比例平方和；纯节点为 0。左右子节点的不纯度按样本数加权。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
好问题应让两边都更“单一”，且不能靠把极少样本分出去制造假象。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
枚举特征和候选阈值，计算 Gain=父 Gini-子节点加权 Gini，贪心选择最大增益。
:::

```NumPy
import numpy as np
def gini(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / len(y)
    return 1 - np.sum(p**2)
print(gini(np.array([0,0,1,1])))
```
