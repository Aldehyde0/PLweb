## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
分类树需要判断把一个节点拆成两个子节点是否让标签更集中。只看拆分后一个子节点很纯是不够的，还必须考虑其他子节点与各自样本数量。

基尼不纯度是一种衡量节点标签混杂程度的标准，划分增益则比较拆分前后加权不纯度的下降。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
节点的基尼不纯度为 1 减各类别比例平方之和。只有一个类别时为 0；同一类别集合下，分布越均匀通常越不纯。

一个候选划分的增益，是父节点不纯度减去子节点按样本比例加权的不纯度。它衡量该次局部划分，不等同于整棵树的最终泛化能力。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
把节点想成混合了不同颜色的球。把球分成两个袋子后，要同时看两个袋子的颜色组成，还要看每个袋子里有多少球，不能让一个很小的纯袋子掩盖大袋子的混乱。
:::

### 同样四条标签，两个阈值的增益不同

令有序特征为 [1,2,3,4]，标签为 [0,0,1,1]，父节点 Gini=0.5。阈值 2.5 把两类完全分开，两个子节点 Gini 都是 0，增益为 0.5。

阈值 1.5 则得到左侧 [0] 和右侧 [0,1,1]。右侧 Gini=4/9，子节点加权不纯度为 1/4×0+3/4×4/9=1/3，因此增益约为 0.1667；不能把两个子节点简单平均。


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
分类树会枚举特征和候选阈值，计算局部增益，再贪心选择当前最有利的划分。贪心过程并不保证得到所有可能树中的全局最佳结构。

子节点必须按其样本数量加权。若左右分别有 1 条和 99 条记录，直接平均两个不纯度，就把它们错误当成同样大的人群。

最大化训练增益可能追随噪声。最大深度、最小叶样本数和剪枝等限制，需要按独立验证选择；纯叶子多不等于对新数据可靠。

基尼增益还影响常见树重要性，但频繁获得切分机会的特征可能被偏爱。由不纯度下降得到的重要性，不应直接解释成因果作用。
:::

```NumPy
import numpy as np
def gini(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / len(y)
    return 1 - np.sum(p**2)
print(gini(np.array([0,0,1,1])))
```
:::
