## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
只写“交叉验证得分 0.9”无法让读者判断结论。折数、数据边界、指标口径和搜索过程都会影响分数；一个均值还可能隐藏不稳定折或关键群体失败。

报告应让别人能够重建评价问题与流程，同时区分开发分数、最终测试结果和对不确定性的合理解释。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
结果报告必须让他人重建评价协议，而不是只给一个“CV=0.97”。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
分数没有考试规则就无法解释和复现。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
至少记录数据版本、评价单位、划分器配置与实际索引、随机种子、预处理和模型参数。分组与时间任务还要说明实体定义、时间跨度及间隔，单独记录随机种子不能替代完整协议。

每折分数、均值、折间标准差与样本量应一起保留。下方公式中的标准差是折分数的描述性波动；由于训练集重叠，不能把折分数直接当成独立样本来套普通置信区间。

模型比较最好使用同一组划分，保留每折成对差异和重要切片。分数接近时需要结合成本、失败模式与选择过程判断，不能只按均值第三位小数排出确定优劣。

报告搜索空间、主指标、失败运行和最终测试使用情况，防止只展示最好结果。环境与依赖版本会影响复现，训练与评分耗时还受硬件、并行和缓存影响，应说明可比较范围。
:::

### 案例：三个构造分数不能直接生成置信区间

假设三折分数为 0.7、0.8、0.9，均值为 0.8，样本标准差为 0.1。可以报告为“折均值 0.8，折间标准差 0.1”，并列出各折样本数与协议。

把 0.8 ± 0.1 叫作 95% 置信区间没有依据。重复 CV 也不让所有折独立；若要推断不确定性，需要明确抽样单位和适合的统计方法。下方数字完全是教学构造，用于核对汇总计算，不是某模型实测表现。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 记录划分
2. 列每折分数
3. 计算均值/样本标准差
4. 记录耗时
5. 记录搜索范围
6. 独立测试
7. 保存版本
:::

### 明确区分均值与折间样本标准差
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
只汇总明确给定的教学分数；ddof=1 对应样本标准差，不附会统计置信水平。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import numpy as np

scores = np.array([0.7, 0.8, 0.9])
assert len(scores) > 1
print("folds:", scores.tolist())
print(f"mean={scores.mean():.3f}")
print(f"sample_std={scores.std(ddof=1):.3f}")
print("interpretation: descriptive fold spread, not a confidence interval")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 完整折分数保留，均值不会隐藏其中的高低差。
- 折分数相关，输出最后一行明确限制解释。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}

```text

mean=0.800
sample_std=0.100
interpretation: descriptive fold spread, not a confidence interval
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 只报告最高折或最好一次运行，隐去完整分数与失败。
- 把折间标准差当作置信区间，或把重复折当独立样本夸大精度。
- 仅写随机种子，没有数据版本、索引、Pipeline 与搜索记录。
:::
