## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
逻辑回归/KNN/SVM 需要标准化，树通常不需要。K 和 max\_depth 还需观察训练/验证差距。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
模型注册表让所有候选共享同一 CV 与指标，同时保留各自必要的 Pipeline。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
把项目当作一条可复现、可审计的实验链，而不是追求一次最高分。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
主要按训练部分 CV macro F1 选择，不读取测试结果；报告均值、标准差、训练和验证耗时。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 注册 Dummy
2. LR Pipeline
3. KNN Pipeline 并比较 K
4. 树比较深度
5. 增加 RF/SVM
6. 同一五折 cross\_validate
7. 锁定最终模型
:::
