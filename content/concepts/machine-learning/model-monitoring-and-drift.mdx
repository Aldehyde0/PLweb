## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
离线评估只覆盖已有数据，部署后的缺失模式、用户群体和标签关系可能发生变化。模型继续返回数字并不意味着输入正常或业务质量稳定，需要持续观察真实流量与延迟结果。

监控先区分数据接口故障、输入分布变化和预测质量退化，才能选择修数据、调整阈值、再训练或回滚等不同处理。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
数据漂移是输入分布变化；概念漂移是输入与目标关系变化。两者都可能让离线模型失效。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
模型像根据旧地图导航，城市或道路规则变化后必须发现并更新。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
数据质量监控关注缺失率、类型、范围、延迟和输入量，常能更早发现接口破坏。分布监控比较当前窗口与基准窗口，但季节性、采样变化和窗口大小都会影响差异。

输入分布改变不一定导致性能下降，输入边际稳定也不能证明条件关系不变。概念漂移涉及目标与特征之间的关系变化，通常需要成熟标签与适当比较才能确认，不能仅凭一个分布统计下结论。

没有即时标签时，可以监控输入、预测分布和拒绝率等代理信号；标签到达后再计算真实分群指标。只对被审核样本有标签时，要注意选择偏差，不能把这部分样本直接当成全部流量。

告警阈值应结合业务损失、正常波动与响应流程，注明谁负责检查。发现漂移不应无条件自动发布新模型；应核对数据、离线回归和新模型边界，并保留可回退版本。
:::

### 案例：缺失率上升与延迟准确率分别检查

构造一个基准窗口与当前窗口，当前数值字段有 1 / 4 缺失，中位数也从 2.5 变为 4。这个差异值得调查数据采集或人群变化，但不能单凭它证明模型已经失效。

当同批样本标签成熟后，再独立核对预测，构造例中的准确率为 0.75。实际还要检查标签是否完整、各群体是否退化、窗口是否可比较。下方数字只是演示监控计算，既不是通用告警阈值，也不说明缺失变化导致了某次预测错误。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 记录模型/数据版本
2. 监控缺失和范围
3. 比较特征分布
4. 监控预测比例/置信度
5. 回收标签
6. 分群评价
7. 定义回滚与再训练
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import numpy as np
from sklearn.metrics import accuracy_score

reference = np.array([1.0, 2.0, 3.0, 4.0])
current = np.array([3.0, 4.0, np.nan, 5.0])
print(f"reference_missing={np.isnan(reference).mean():.2f}")
print(f"current_missing={np.isnan(current).mean():.2f}")
print(f"reference_median={np.nanmedian(reference):.1f}")
print(f"current_median={np.nanmedian(current):.1f}")

mature_labels = [0, 0, 1, 1]
saved_predictions = [0, 1, 1, 1]
print(f"mature_label_accuracy={accuracy_score(mature_labels, saved_predictions):.2f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 无标签时只能观察输入与预测代理，不能直接计算真实准确率。
- np.nanmedian 忽略缺失值计算中位数，但缺失率单独报告。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把输入漂移直接等同于性能下降，或者因边际分布稳定就认定无需标签评估。
- 忽略标签延迟和审核选择偏差，拿不完整样本计算总体效果。
- 告警后不查原因就自动再训练发布，缺少回归、负责人和回退路径。
:::
