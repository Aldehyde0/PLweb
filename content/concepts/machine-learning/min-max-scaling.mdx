## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
一些模型或显示需要把不同数值范围映射到统一区间。Min-Max 使用训练数据的最小值与最大值进行线性缩放，易于解释，但并不提供稳健的异常值处理。

“训练样本落在 0 到 1”与“所有未来样本都落在 0 到 1”是不同陈述。忽略这一区别，容易把正常超出训练范围的输入误认为计算错误。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
常见 Min-Max 变换为 (x−min_train)/(max_train−min_train)，也可以映射到其他目标区间。它保持非恒定特征内部的顺序，但不自动改变分布形状。

极值是训练阶段学到的状态。未来数据应使用同一组极值，不能每来一个批次就重新估计后仍认为特征接口没有变化。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
把训练范围当作尺子的两端。新物体长过原来的尺子，刻度值超过 1 完全可能；把数值硬截到 1 是额外处理，不是原始线性缩放本身。
:::

### 训练落在区间内，未来可以超过 1

构造训练值 [10,20,30]，极值差为 20，映射到 [0,0.5,1]。未来的 40 使用相同尺子，结果为 (40−10)/20=1.5。

若把 40 加回训练范围重新 fit，原来的 20 会变成 1/3 而不是 0.5，所有历史特征含义都变了。是否允许更新尺子是模型版本与重训问题，不能在预测时悄悄发生。


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
训练极值会受异常点影响。若少数巨大数值把区间拉长，大部分正常样本可能被压缩到很小范围，距离与梯度的有效尺度也会受影响。

未来超出范围时，默认线性变换通常允许超出目标区间。clip 可以限制输出，但会丢失超出边界的差异；是否需要它应根据模型接口与业务含义决定。

常量列没有正的训练范围，手写公式必须处理零分母；库的处理也应通过固定样本确认，不能把一个特定实现约定当成数学除零成立。

缩放本身不会消除数据泄漏。交叉验证中的极值仍必须来自当前训练折，对所有样本先 fit 再验证会改变评价边界。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### Min-Max 公式
:::

:::field{path="formulas.0.expression" type="math"}
$$
x'ⱼ = (xⱼ - xⱼ,min) / (xⱼ,max - xⱼ,min)
$$
:::

:::field{path="formulas.0.description" type="text"}
默认映射到 \[0,1\]；分母为 0 时是常量特征。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 把 \[10,20,30\] 映射到 \[0,1\]
:::

:::field{path="numericalExample.given" type="list"}
- 训练最小值 10
- 训练最大值 30
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 10 → (10-10)/(30-10)=0
2. 20 → 0.5
3. 30 → 1
4. 未来值 40 → 1.5
:::

:::field{path="numericalExample.result" type="text"}
训练集变为 \[0,0.5,1\]，未来值可以超过目标范围。
:::

:::field{path="numericalExample.comparison" type="list"}
- Z-score 使用均值和标准差，结果无固定上下界。
- Min-Max 使用端点，保持有限训练范围但更怕极端值。
:::


## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 先划分数据。
2. 在训练集拟合 min/max。
3. 检查常量列和异常值。
4. 转换所有分块。
5. 保存 scaler 与模型。
:::


## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### MinMaxScaler
:::

:::field{path="codeExamples.0.language" type="text"}
scikit-learn
:::

:::field{path="codeExamples.0.purpose" type="text"}
安全保存训练区间并转换未来数据。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```scikit-learn
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
train = [[10.0], [20.0], [30.0]]
future = [[40.0]]
print(scaler.fit_transform(train).ravel())
print(scaler.transform(future).ravel())
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- fit\_transform 只用于训练数据。
- future 超出训练最大值，因此得到 1.5。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
\[0. 0.5 1.\]，随后 \[1.5\]。

```text
[0.  0.5 1. ]
[1.5]
```
:::

::::

## 实际应用 {#applications}

:::field{path="applications" type="list"}
- 有明确有限输入范围的模型
- 像素或传感器特征缩放
:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 以为未来结果一定在 \[0,1\]
- 存在异常值仍直接使用
- 测试集重新拟合端点
:::
