## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
尺度、共线性、多分类参数和正则化都会改变权重，模型关联不是因果。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
在线性分数中，wⱼ 表示 xⱼ 增加一个单位时 score 的变化；标准化后可比较一个标准差变化的影响。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
权重像模型内部的方向和力度，不是现实世界的原因证明。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
解释前说明预处理、目标编码、类别基准和不确定性；相关特征可能分摊或交换权重。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 确认特征尺度
2. 提取正确类别权重
3. 结合方向与单位
4. 检查相关性和稳定性
5. 避免因果语言
:::
