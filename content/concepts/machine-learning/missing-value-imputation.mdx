## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
缺失值不只是一个需要填成数字的空位。它可能来自设备故障、问卷跳题、不适用或信息尚未产生，不同原因可能与标签和使用环境有关系。

填补让估计器能接收统一结构，却不会恢复未观察到的真实数值，也不能消除缺失机制带来的偏差。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
缺失值填补依据既定规则为未观测位置提供替代值，例如数值中位数、类别众数、常量或由其他信息估计的值。数据驱动的规则属于已学状态，应仅从训练范围估计。

缺失指示列记录原始位置是否缺失，它与填补后的数值承担不同信息；是否加入指示列应通过合适验证判断，不能默认必然提高效果。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
中位数填补相当于给缺失位置放一个训练集的典型值。填入 15 只表示采用了这个约定，不意味着该记录的真实值恰好是 15。
:::

### 同一个填补值用于两条未来记录

训练列为 [10,缺失,20]，非缺失部分的中位数是 15。未来列 [100,缺失] 应变为 [100,15]，而不是根据未来的 100 再估计一个新填补值。

若保留缺失指示，则两行分别附上 0 与 1。这样模型能区分真实观测到的 15 与由规则填成的 15，但不能据此认定缺失一定代表某种类别。


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
先判断缺失含义与可用信息，再选择策略。全部删除可能改变样本分布，简单平均可能压缩方差，复杂估计也可能引入额外假设和计算成本。

填补统计量只能由训练数据学习，交叉验证时也必须折内拟合。未来大数值若参与计算，会提前改变训练规则，即使没有直接使用测试标签也可能泄漏。

数值与类别列一般采用不同处理，类别常量还要避免与真实类别混淆。整列缺失、训练没有缺失而未来出现缺失等情况，需要核对变换器的输出列规则与版本。

保留缺失率监控和原始标识有助于发现采集变化。预测时缺失模式大量变化，不能只靠继续填补就认为输入仍处于已验证范围。
:::


## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 统计每列缺失比例。
2. 区分数值、类别和结构性缺失。
3. 判断缺失是否可能携带信息。
4. 在训练集拟合填补器。
5. 对其他分块只 transform。
6. 比较不同策略并检查填补后的分布。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import numpy as np
from sklearn.impute import SimpleImputer
train = np.array([[10.0], [np.nan], [20.0]])
future = np.array([[100.0], [np.nan]])
imputer = SimpleImputer(strategy="median", add_indicator=True).fit(train)
print("median:", imputer.statistics_.tolist())
print("future:", imputer.transform(future).tolist())
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 训练中的缺失不参与中位数，学到的统计量为 15。
- 该列在训练时有缺失，因此本例附加一个指示列；其他输入情形应核对具体列生成规则。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 用完整数据算填补值
- 把未知类别和缺失混为一谈
- 不分析高缺失比例特征的业务含义
:::
