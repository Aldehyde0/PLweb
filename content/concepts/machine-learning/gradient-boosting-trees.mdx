## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
一个常数预测器可能太简单，而直接拟合一棵很深的树又容易过拟合。梯度提升从简单初值开始，依次加小树，让每轮新树修正当前预测的损失方向；每棵树的任务由已经建成的模型决定。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
梯度提升树是以树为增量的加法模型。每轮在训练样本上计算当前预测处的损失负梯度，再拟合一棵受限复杂度的树，并乘学习率加入旧模型。只有平方误差等特定损失下，负梯度才恰好是普通残差。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先画一张粗略地图，再一层层添加修正，而不是让许多完整地图平权投票。每层修正通常较小，避免一次把偶然误差全部记住。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
平方损失的一半形式对应负梯度 y−F(x)，分类的对数损失则通常在 margin 或 logit 空间计算梯度。分类树增量不是直接加到概率后随意裁剪，链接函数必须与目标一致。

learning_rate 小会让每步修正温和，但往往需要更多树；单树深度、叶子数、最小叶样本与子采样共同控制容量。降低学习率却大幅增加迭代数，仍可能过拟合，不能只看一个参数。

早停基于验证目标选迭代数，验证数据不能再被当作最终独立测试。直方图实现通过分箱提高分裂搜索效率，可能还用二阶信息优化叶值；不能把所有实现细节简化成完全相同的残差树。
:::

### 加法模型的本轮修正
:::

:::field{path="formulas.0.expression" type="math"}
$$
F_m(x)=F_{m-1}(x)+\eta h_m(x)
$$
:::

:::field{path="formulas.0.description" type="text"}
h 拟合当前损失的负梯度方向，η 为学习率；具体叶值计算取决于损失与实现。
:::

## 手算与场景核对 {#worked-example}

平方误差回归有两条标签 1、3，初始常数均为 2，残差为 −1、1。假设本轮弱树只拟合出 −0.5、0.5，学习率 0.2，新预测变成 1.9、2.1。

均方误差从 1 降到 0.81。树只修正一部分残差；这说明给定本轮方向的损失变化，不能作为任意学习率都安全或验证误差必降的保证。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 选择损失与链接函数，用训练数据计算合适常数初值。
2. 在当前预测处计算负梯度或实现所需的一二阶量。
3. 用受限复杂度树拟合本轮修正目标。
4. 乘学习率累加到当前模型，记录训练与验证损失。
5. 按固定早停或预算规则选择迭代数，再作独立测试。
:::

### 平方损失下的一次小步树增量
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
固定标签、旧预测和弱树输出，核对残差与学习率累加。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
targets, predictions = [1.0, 3.0], [2.0, 2.0]
weak_tree_output, rate = [-0.5, 0.5], 0.2
residual = [y-p for y, p in zip(targets, predictions)]
updated = [p + rate*h for p, h in zip(predictions, weak_tree_output)]
mse = lambda values: sum((y-p)**2 for y, p in zip(targets, values))/len(targets)
print(f"residual={residual}")
print("updated=" + ",".join(f"{p:.3f}" for p in updated))
print(f"MSE_before={mse(predictions):.3f}, MSE_after={mse(updated):.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 弱树输出被明确给定，未假装完整训练过程。
- 本例使用平方误差，所以负梯度与残差相同。
- 训练损失变化与独立泛化表现需要分别验证。
:::


## 实际应用 {#applications}

:::field{path="applications" type="list"}
- 表格数据分类与回归，逐步拟合非线性和交互。
- 在验证预算固定时比较树数、学习率与叶子复杂度的组合。
:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把任何分类目标的负梯度都叫 y−预测概率残差。
- 只减学习率却不控制总迭代容量。
- 用最终测试集选早停轮数，泄露评测信息。
:::
