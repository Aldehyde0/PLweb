## 通俗直觉 {#intuition}

:::field{path="explanation" type="text"}
把高维数据投影到最能保留变化的几条轴上，方便观察但不保证类别分得最好。
:::


## 核心原理 {#core-principle}

:::field{path="principle" type="text"}
第一主成分使投影方差最大，后续主成分与之前方向正交；聚类编号本身没有类别语义。
:::


## 数学公式 {#formulas}

:::field{path="formula.expression" type="math"}
$$
v₁ = argmax||v||=1 Var(Xv)
$$
:::

:::field{path="formula.description" type="text"}
第一主成分是在单位方向中投影方差最大的方向。
:::

## 代码示例 {#code}

:::field{path="code.language" type="text"}
Python
:::

:::field{path="code.source" type="code" trailing="0"}
```Python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)
X_2d = PCA(n_components=2).fit_transform(X_scaled)
print(X_2d.shape)
```
:::

:::field{path="code.highlights" type="list"}
- 先检查数据和张量形状
- 把会学习参数的步骤限制在训练数据内
:::

:::field{path="codeExplanation" type="text"}
先标准化再做 PCA，避免大尺度特征主导方差方向。
:::
