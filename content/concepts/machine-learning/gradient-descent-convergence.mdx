## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
运行固定 epochs 既可能提前停止，也可能浪费计算。某一轮变化小也可能只是震荡瞬间，因此需要阈值与 patience。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
收敛表示在当前模型、特征和优化设置下，参数更新带来的目标改善已经很小；它不等于模型泛化良好。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不是看到车速慢一次就说已到终点，而是连续多次变化都很小，并确认没有发散或停在错误原因上。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
相对损失变化对不同损失量级更可比；梯度范数接近 0 是补充信号。训练和验证曲线还用于区分优化收敛与过拟合。
:::

### 相对损失变化
:::

:::field{path="formulas.0.expression" type="math"}
$$
rₜ = |Jₜ-Jₜ₋₁| / max(|Jₜ₋₁|, ε)
$$
:::

:::field{path="formulas.0.description" type="text"}
连续若干轮小于 tolerance 时可提前停止。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 每轮记录训练损失。
2. 检查 loss 和参数是否有限。
3. 计算相对损失变化。
4. 可同时计算梯度范数。
5. 连续 patience 轮满足条件才停止。
6. 设置最大轮数。
7. 用验证曲线确认没有过拟合。
:::


## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 耐心机制判断稳定
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
避免一次偶然的小变化导致过早停止。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
tolerance = 1e-8
patience = 10
stable_count = 0

relative_change = abs(old_loss - new_loss) / max(abs(old_loss), 1e-12)
stable_count = stable_count + 1 if relative_change < tolerance else 0

if stable_count >= patience:
    print("梯度下降已经收敛")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 使用相对变化适配不同损失量级。
- stable\_count 在变化重新变大时清零。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
连续 10 轮相对变化小于 1e-8 后打印收敛提示。
:::

## 实际应用 {#applications}

:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把训练收敛等同泛化成功
- 不设最大轮数
- 忽略 nan/inf
:::
