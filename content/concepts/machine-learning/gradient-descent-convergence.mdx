## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
损失不再明显变化，可能是已经接近驻点，也可能是学习率太小、梯度中断、数值精度限制或错误实现。仅凭最后两个损失相近就宣布“已经学好”，证据不足。

收敛诊断应把优化轨迹、停止规则与泛化表现分开，回答程序为什么停止，以及停止时实际满足了什么条件。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
优化中的收敛可以由损失变化、参数变化、梯度范数或特定算法条件描述。实际实现常采用带预算与耐心的近似停止规则，而不是证明已经达到全局最优。

早停根据验证表现控制训练轮数，是选择模型的一部分；它与训练损失数值稳定并不完全相同。两种停止依据都应明确记录。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
连续几次几乎不动像“停在某处”的信号，但还要问为什么不动。步幅极小的行走者也可能远离谷底；模型同样需要结合梯度、参数和验证误差判断。
:::

### 耐心为三轮时，计数如何累积

构造损失序列 [1,0.5,0.500000001,0.500000002,0.5000000021]，相对变化阈值取 1e-8。第一次明显变化后计数为 0，后面三个变化都足够小，计数依次为 1、2、3。

此时只能报告“损失变化满足本停止条件”，不能据此证明全局最优或泛化良好。示例甚至含小幅上升，说明使用绝对变化量与要求严格单调下降是不同规则。


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
同时检查绝对与相对变化有助于应对不同损失尺度。相对变化的分母接近零时需要稳定约定，不能让除零或巨大比值替代实际诊断。

耐心计数应跨迭代保存，出现明显变化时按规则重置。把 stable_count 每轮重新初始化，会使“连续若干轮”的条件永远无法真正成立。

梯度为零或很小也需要解释。在非凸问题中可能是局部极小、鞍点或平坦区域；梯度缺失、截断或错误 detach 则属于实现问题。

训练损失稳定不表示验证误差最低。应按事先选定的指标和协议保存合适检查点，并保留最大步数、时间和非有限值等终止条件。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 每轮记录训练损失。
2. 检查 loss 和参数是否有限。
3. 计算相对损失变化。
4. 可同时计算梯度范数。
5. 连续 patience 轮满足条件才停止。
6. 设置最大轮数。
7. 用验证曲线确认没有过拟合。
:::

### 完整循环保存连续稳定计数
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
核对一个明确的数值停止条件，避免把计数每轮重置。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
losses = [1.0, 0.5, 0.500000001, 0.500000002, 0.5000000021]
tolerance, patience = 1e-8, 3
stable_count = 0
for step, (old, new) in enumerate(zip(losses, losses[1:]), start=1):
    change = abs(old - new) / max(abs(old), 1e-12)
    stable_count = stable_count + 1 if change < tolerance else 0
    if stable_count >= patience:
        print(f"stop_step={step}, stable={stable_count}")
        break
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- stable_count 在循环外初始化，并根据每次变化累积或重置。
- 输出只说明构造序列满足所选变化阈值，不宣称训练已经达到最优。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
stop_step=4, stable=3
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把训练收敛等同泛化成功
- 不设最大轮数
- 忽略 nan/inf
:::
