## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
列错位、单位变化或 Series 降成一维会让预测报错或静默产生错误结果。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
输入契约是模型接受数据的明确结构与语义约束，不只是数组长度。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
模型只认识训练时那套表头和单位，不能靠猜测理解新格式。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
优先使用带列名 DataFrame；在 predict 前验证列集合、顺序、有限值、范围与模型版本。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 保存 expected\_columns
2. 检查缺失/多余列
3. 重排列顺序
4. 验证 dtype/单位/有限性
5. 保留二维
6. 记录版本
:::
