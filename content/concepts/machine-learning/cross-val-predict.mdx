## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
有时需要每个样本的一份未被该轮模型训练过的预测，用于观察残差、混淆或构建后续开发特征。cross_val_predict 将各验证折预测放回原样本顺序，形成折外预测。

这与返回每折平均分不同，也不是一个最终模型对全部数据的预测。生成结果的实际上是多个不同训练子集上的模型。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
每条预测来自不同折模型，不是一个最终部署模型的输出集合。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
每条样本都由没看过它的临时模型作答，最后把答案拼起来。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
标准使用要求每行恰好出现在一个验证折，形成完整分区。重复 K 折会让每行出现多次，某些时间划分会让早期行从未验证，因此不能不加处理地用于 cross_val_predict。

method 决定返回标签、概率或决策分数。predict_proba 输出列对应类别顺序，读取正类列前必须明确标签；多分类的每行概率应与类别集合匹配，而不是随意取第二列代表“正确概率”。

拼接预测计算的总体指标不一定等于每折指标的简单均值。折大小不同、F1 等非线性指标或每折类别分布不同，都可能导致差异；报告时应说明计算口径。

折外预测可以用于阈值开发或上层模型，但后续选择仍会利用这些标签，不能再把同一组上的最佳结果当作独立评价。堆叠与阈值选择需要额外独立验证或正确嵌套。
:::

### 案例：每朵花获得一份折外正类概率

取 Iris 的前两类共 100 行，按 3 折分层生成概率。每个样本由没训练过它的那个折模型预测，最终数组形状为 100 × 2，顺序与原始输入一致。

如果随后在这 100 个概率上找出 F1 最好的阈值，那么这批数据已被用于选阈值，所得最高 F1 不能作为独立最终评价。下方只核对形状、类别和概率和，不做阈值优化，也没有输出部署模型。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 固定 CV
2. 选择 method
3. 生成 out-of-fold 预测
4. 诊断错误/概率
5. 额外验证阈值或堆叠
6. 训练最终模型
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_val_predict
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_iris(return_X_y=True)
mask = y < 2
X, y = X[mask], y[mask]
cv = StratifiedKFold(3, shuffle=True, random_state=42)
pipeline = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
probability = cross_val_predict(pipeline, X, y, cv=cv, method="predict_proba")
assert np.allclose(probability.sum(axis=1), 1.0)
print("shape:", probability.shape)
print("class_order:", np.unique(y).tolist())
print("positive_probability_count:", len(probability[:, 1]))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 此数据类别是 0、1，因此第 1 列对应标签 1。
- 每行恰好在一个验证折中出现，不能用重复 K 折替换。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把拼接预测称为同一个最终模型的预测，或直接当成独立最终测试。
- 使用重复划分或不覆盖所有行的时间划分，却忽略每行必须恰好验证一次的要求。
- 不核对类别列顺序，或在同一组折外标签上选阈值并报告最优分数。
:::
