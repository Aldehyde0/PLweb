## 通俗直觉 {#intuition}

:::field{path="explanation" type="text"}
随机森林让许多不同的树投票；Boosting 则让后一棵树重点修正前面的残差。
:::


## 核心原理 {#core-principle}

:::field{path="principle" type="text"}
Bagging 并行训练多模型以降低方差；Boosting 串行添加弱模型以降低当前误差。
:::


## 数学公式 {#formulas}

:::field{path="formula.expression" type="math"}
$$
Fₘ(x)=Fₘ₋₁(x)+ηhₘ(x)
$$
:::

:::field{path="formula.description" type="text"}
梯度提升以学习率 η 逐步加入新树。
:::


## 工作流程 {#algorithm-steps}

:::field{path="workflow" type="list"}
- 明确输入、输出与评价方式
- 建立简单基线
- 实现并检查关键中间量
- 在验证数据上诊断和迭代
:::


## 代码示例 {#code}

:::field{path="code.language" type="text"}
Python
:::

:::field{path="code.source" type="code" trailing="0"}
```Python
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier

forest = RandomForestClassifier(n_estimators=300, min_samples_leaf=2, random_state=42)
boost = HistGradientBoostingClassifier(learning_rate=0.05, max_iter=200)
```
:::

:::field{path="code.highlights" type="list"}
- 先检查数据和张量形状
- 把会学习参数的步骤限制在训练数据内
:::

:::field{path="codeExplanation" type="text"}
两种方法都基于树，但训练关系、主要超参数和误差特性不同。
:::
