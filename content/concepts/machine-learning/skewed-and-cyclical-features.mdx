## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
金额和次数常有长尾；小时直接编码 0～23 会错误地认为 23 与 0 很远。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
偏态变换改变数值分布形状；周期编码把首尾相接的变量映射到单位圆。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
log1p 压缩大值而保留顺序；sin/cos 把钟表时间放在圆上，让 23 点与 0 点自然接近。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
log1p 适用于非负值；周期 T 的编码为 sin(2πx/T)、cos(2πx/T)，两列共同确定相位。
:::

### 周期编码
:::

:::field{path="formulas.1.expression" type="math"}
$$
xsin=sin(2πx/T)，xcos=cos(2πx/T)
$$
:::

:::field{path="formulas.1.description" type="text"}
T 是周期长度。
:::

::::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 检查变量定义与范围。
2. 非负长尾比较 log1p 前后分布。
3. 确定周期 T。
4. 同时生成 sin/cos 两列。
5. 在验证集比较效果。
:::

## 实际应用 {#applications}

:::field{path="applications" type="list"}
- 金额与访问次数
- 小时、星期与季节
:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 对含负数数据直接 log1p
- 只用 sin 或 cos 一列
- 没有明确真实周期
:::
