## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
单棵树对训练样本变化敏感；多个错误不完全相关的树平均后方差下降。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Bootstrap Aggregating 允许有放回抽样，每个基学习器看到不同样本集合。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
让多位略有不同的评审独立判断，再汇总意见。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
基模型需要有能力且保持差异。树越相关，平均收益越小。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 生成 B 个 bootstrap 样本
2. 独立训练基模型
3. 收集预测
4. 投票/平均
5. 用 OOB 或 CV 评价
:::
