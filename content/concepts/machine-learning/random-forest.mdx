## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
强特征若总被首先选择，所有树会相似；随机特征迫使树产生不同视角。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
每棵树使用 bootstrap 样本，节点分裂时从 max\_features 指定的随机子集中寻找最佳划分。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不仅给每位评审不同样本，也限制他们看到的特征清单。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
n\_estimators 增加主要提升平均稳定性；单树深度、min\_samples\_leaf、max\_features 控制偏差方差。OOB 提供近似验证。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. bootstrap 抽样
2. 节点随机选特征
3. 深树训练
4. 多数投票
5. 检查 OOB/CV
:::
