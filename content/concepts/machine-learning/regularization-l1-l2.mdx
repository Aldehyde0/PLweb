## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
高维或相关特征常让训练数据允许很多近似同样好的权重。若只追求训练误差，参数可能过大、对样本变化敏感；正则化在这些解之间加入偏好。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
L1 惩罚权重绝对值和，常产生精确零；L2 惩罚平方和，通常连续收缩；Elastic Net 将稀疏与收缩两种偏好组合。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
L2 让大家一起缩小，L1 还可能让较弱的权重彻底退出。退出的特征不一定没有科学意义，只是当前模型与惩罚下不被保留。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
一维平方损失加 L1 时，零点处的尖角形成软阈值：信号小于惩罚阈值时最优权重为零。L2 的导数连续，通常把非零权重缩小而不精确归零。两者改变目标最优点，允许训练拟合变差。

特征尺度决定同样预测贡献需要多大权重，未缩放时惩罚可能偏向某种计量单位。连续特征常先标准化，但哑变量、稀疏矩阵与截距的处理应遵从模型约定。相关特征下 L1 可能任意保留其中一个，Elastic Net 往往更倾向共同保留，但不保证稳定选择。

强度通过训练内交叉验证确定，所有变换留在 Pipeline 内。不同库的 alpha、C、样本归一化和 1/2 系数约定不同，不能按数字直接迁移；C 常是强度倒数，alpha 常与强度同向。
:::

### 一维解析解显示稀疏与收缩

- 数据项为 0.5×(w−a)²，a 为 3 或 0.2
- 比较 L1=|w|，L2=0.5w²
- 混合惩罚为 0.5|w|+0.5w²

a=3 时得到 2、1.5、1.25；a=0.2 时得到 0、0.1、0。

弱信号 0.2 在 L1 下归零，在 L2 下仍保留 0.1。这是目标几何与零点次梯度产生的效果，不是训练程序把小数手动截断。

本例是分离的一维问题。多特征设计矩阵存在相关性时，坐标不再独立，不能把每个未正则化系数单独套这个式子就当完整回归解。

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 说明损失与惩罚系数的归一化约定。
2. 在训练折内拟合缩放与正则模型，搜索强度和混合比例。
3. 比较验证误差、稀疏度与特征选择稳定性。
:::

### 一维解析解显示稀疏与收缩的最小验证
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
使用完整构造输入核对一维解析解显示稀疏与收缩，输出只表示本例计算。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```python
def soft(value, threshold):
    return max(value - threshold, 0.) if value >= 0 else -max(-value - threshold, 0.)
for a in [3., 0.2]:
    l1 = soft(a, 1.)
    l2 = a / 2
    elastic = soft(a, 0.5) / 2
    print(f"a={a:.1f} L1={l1:.2f} L2={l2:.2f} mixed={elastic:.2f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 解析解对应明确的一维平方目标。
- 不把一维闭式解推广到相关多特征设计。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
a=3.0 L1=2.00 L2=1.50 mixed=1.25
a=0.2 L1=0.00 L2=0.10 mixed=0.00
```
:::
