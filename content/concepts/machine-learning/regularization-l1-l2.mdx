## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
高维、小样本、噪声与共线性可能让线性模型权重过大且不稳定。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
L1 惩罚绝对值和并产生稀疏权重；L2 惩罚平方和并平滑收缩；Elastic Net 混合二者。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不仅要求答对训练题，还对过于极端的参数收费。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
特征需先标准化以保证惩罚公平。正则过强会欠拟合，强度必须在训练集内部交叉验证。
:::

## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 标准化
2. 选择惩罚类型
3. 设对数候选强度
4. 交叉验证
5. 检查训练/验证和非零权重
6. 最终测试
:::

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
model=make_pipeline(StandardScaler(),ElasticNet(alpha=0.1,l1_ratio=0.5))

:::field{path="pitfalls" type="list"}

- 正则越强越好
- 零权重解释为无因果作用
