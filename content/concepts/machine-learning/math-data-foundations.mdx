## 通俗直觉 {#intuition}

:::field{path="explanation" type="text"}
机器学习中的一行数据通常是一个向量，多行组成矩阵；模型通过距离、概率或梯度从这些数字中寻找规律。
:::


## 核心原理 {#core-principle}

:::field{path="principle" type="text"}
特征矩阵 X 的行对应样本、列对应特征；统计量描述分布，梯度指出损失增大的最快方向。
:::


## 数学公式 {#formulas}

:::field{path="formula.expression" type="math"}
$$
X ∈ ℝⁿˣᵈ，wᵀx = Σⱼwⱼxⱼ
$$
:::

:::field{path="formula.description" type="text"}
n 是样本数，d 是特征数；点积是线性模型和神经元的核心运算。
:::


## 工作流程 {#algorithm-steps}

:::field{path="workflow" type="list"}
- 明确输入、输出与评价方式
- 建立简单基线
- 实现并检查关键中间量
- 在验证数据上诊断和迭代
:::


## 代码示例 {#code}

:::field{path="code.language" type="text"}
NumPy
:::

:::field{path="code.source" type="code" trailing="0"}
```NumPy
import numpy as np

X = np.array([[1., 2.], [3., 6.], [5., 10.]])
print(X.shape)
print(X.mean(axis=0))
print(X.std(axis=0))
```
:::

:::field{path="code.highlights" type="list"}
- 先检查数据和张量形状
- 把会学习参数的步骤限制在训练数据内
:::

:::field{path="codeExplanation" type="text"}
shape 明确样本与特征维度；axis=0 表示沿样本方向统计每个特征。
:::
