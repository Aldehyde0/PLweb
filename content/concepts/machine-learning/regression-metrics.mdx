## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
回归误差既有大小，也有单位和业务含义。相同的数值在预测元、万元或温度时意义不同；一个平均值还可能掩盖少数极大错误。

比较模型前，应固定数据范围、目标尺度与基线，再决定更关心典型偏差、极端偏差还是相对基准的解释能力。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
三种指标回答不同问题，不能脱离目标单位、分布与基线比较。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
MAE 看平均错多少，RMSE 对大错更严厉，R² 看比“猜平均”进步多少。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
MAE 对绝对误差取平均，与目标同单位，每个误差按大小线性贡献。MSE 对大误差平方惩罚，RMSE 再开平方恢复目标单位，通常比 MAE 更受极端错误影响。

R² 将平方误差与在当前评价数据上恒预测其目标均值的基准比较。它不是准确率，也不是误差百分比；表现差时可以为负，目标恒定时还需要注意实现对非有限情形的处理。

MAPE 等相对误差在真实值接近零时可能极大，目标有零或负值时必须明确是否适用。若对目标做对数变换，训练损失的尺度与业务尺度也不同，最终需要在关心的尺度上核对误差。

scikit-learn 的 scoring 遵循越大越好，因此不少损失以负值返回。报告 MAE 时可将负 MAE 取反，但标准差不应随符号变成负数。分组与分位数误差有助于检查总体均值遗漏的差异。
:::

### 案例：四个预测的 MAE、RMSE 与 R²

构造真实值 10、20、30、40，预测值 12、18、33、37，误差为 2、−2、3、−3。MAE 为 10 / 4 = 2.5，均方误差为 26 / 4 = 6.5，RMSE 约为 2.550。

真实均值是 25，离均差平方和为 500，因此 R² 为 1 − 26 / 500 = 0.948。这个数不是“94.8% 样本预测正确”，也不说明未来数据一定有相同表现；它只是这组构造数据上的相对平方误差指标。

```Python
from sklearn.metrics import mean_absolute_error, root_mean_squared_error, r2_score

y_true = [10, 20, 30, 40]
y_pred = [12, 18, 33, 37]
print(f"mae={mean_absolute_error(y_true, y_pred):.3f}")
print(f"rmse={root_mean_squared_error(y_true, y_pred):.3f}")
print(f"r2={r2_score(y_true, y_pred):.3f}")
```

- MAE 和 RMSE 与 y 的单位相同；R² 无单位。
- 这里未训练模型，指标只描述给定预测与真实值的差异。

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 R² 当作分类准确率或统一误差百分比，忽略它可能为负。
- 比较不同目标单位、变换尺度或不同数据范围上的原始误差。
- 直接把 neg_mean_absolute_error 的负值当成负误差，或对接近零的目标盲用 MAPE。
:::
