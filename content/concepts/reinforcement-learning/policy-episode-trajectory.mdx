## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
同一个策略运行两次也会得到不同轨迹：策略可能随机采样，环境转移也可能随机。保存一串动作不足以复现实验，还需要初始状态、观察、奖励、边界和随机性。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
策略是根据当前信息选动作的规则，可以确定也可以随机。轨迹按时间排列状态、动作与反馈；episode 是从初始化到任务结束或采样边界的一段完整记录。持续任务也有轨迹，但没有天然的任务终点。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
菜谱是策略，一次实际烹饪记录是轨迹。菜谱相同，食材差异与操作随机性仍会改变结果；记录到一半停止也不等于菜已经完成。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
离散随机策略的各动作概率非负且和为 1。连续策略输出的是密度，某个精确实数动作的概率通常为零，不能把密度值直接当离散概率解释。

给定一条离散轨迹，其概率包含初始分布、沿途动作概率和环境转移概率的乘积。策略只能改变其中动作项；策略梯度正是利用这一结构，避免直接求未知环境动力学的导数。

训练时保存的旧动作对数概率必须对应实际生成数据的策略。更新后的策略重新算出的概率不能冒充旧概率，否则重要性比率失去意义。截断片段还应保留后继观察和 bootstrap 信息。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 一条两步轨迹的概率
:::

:::field{path="numericalExample.given" type="list"}
- 初始状态确定。
- 两次所选动作概率分别为 0.6 和 0.5；对应转移概率分别为 0.8 和 1。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 策略对这两个动作的联合因子是 0.6×0.5=0.3。
2. 加入环境转移后，轨迹概率为 0.6×0.8×0.5×1=0.24。
3. 0.24 是这条特定轨迹的概率，不是任意成功轨迹概率之和。
:::

:::field{path="numericalExample.result" type="text"}
动作因子为 0.300，完整轨迹概率为 0.240。
:::

:::field{path="numericalExample.comparison" type="list"}
- 策略随机性与环境随机性需要分别记录。
- 连续变量的轨迹密度不能直接解释为精确轨迹的概率质量。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
action_prob = [0.6, 0.5]
transition_prob = [0.8, 1.0]
policy_factor = action_prob[0] * action_prob[1]
trajectory_prob = policy_factor * transition_prob[0] * transition_prob[1]
print(f"policy_factor={policy_factor:.3f}, trajectory_prob={trajectory_prob:.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 策略对这两个动作的联合因子是 0.6×0.5=0.3。
- 加入环境转移后，轨迹概率为 0.6×0.8×0.5×1=0.24。
- 0.24 是这条特定轨迹的概率，不是任意成功轨迹概率之和。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把策略概率最大的动作当成随机策略每次必选的动作。
- 计算轨迹概率时漏掉环境转移概率。
- 用新策略概率覆盖采样时保存的旧概率。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把策略概率最大的动作当成随机策略每次必选的动作。
- 计算轨迹概率时漏掉环境转移概率。
- 用新策略概率覆盖采样时保存的旧概率。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### episode 和固定长度 rollout 一样吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不一样。rollout 可以只是 episode 的片段；在非终止边界通常需要后继价值来补足未采到的未来。
:::
