## 学习目标 {#learning-objectives}

:::field{path="learningObjectives" type="list"}
- 将双 Q 最小值、延迟更新和目标动作平滑分别对应到 DDPG 的失败来源。
- 独立复核“裁剪目标动作并取双 critic 较小值”的输入、计算和解释。
- 动作噪声先裁剪、动作边界后裁剪，限制对象不同。
:::

## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
确定性 actor 会追逐 critic 的局部高分，哪怕高分只是估计噪声形成的尖峰。TD3 在 DDPG 结构上加入三个机制，减少这种误差经过 actor 与 bootstrap 的反复放大。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
TD3 使用双 critic 的较小目标值，降低 actor 及目标网络的更新频率，并对目标动作添加有限平滑噪声。它仍是使用 replay 的确定性 off-policy actor-critic，行为探索噪声与目标平滑噪声用途不同。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先让两位评论家中较谨慎的给出目标，执行者不必每听一次新评分就改动作；评价附近一小片动作而非一个尖点，可减少追逐偶然高峰。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
目标动作先加裁剪后的噪声，再按合法动作范围裁剪。两个 target critic 评价同一动作，取较小值构造 TD 目标；这不是 Double DQN 的在线选动作、目标网评价。

critic 通常每步更新，actor 每隔若干 critic 步更新，目标网络也按相应延迟更新。延迟让 actor 使用相对成熟的价值估计，但过慢会拖累改进，不能认为越慢越稳越好。

双 Q 最小值会带来保守偏差，相关 critic 仍可共同出错。目标平滑依赖局部动作含义；若相近动作造成完全不同后果，平滑尺度过大可能抹去关键结构。
:::

### TD3 的 clipped double Q 目标

y=r+\gamma(1-d)\min_{i=1,2}\bar Q_i(s\prime,\tilde a),\quad\tilde a=\operatorname{clip}(\bar\mu(s\prime)+\operatorname{clip}(\epsilon,-c,c))

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 裁剪目标动作并取双 critic 较小值
:::

:::field{path="numericalExample.given" type="list"}
- 目标 actor 动作为 0.8，采样噪声 0.5，噪声裁剪到 ±0.2，动作上限 0.9。
- 两个 target Q 对最终动作的估计为 5 与 3；奖励 1，折扣 0.9。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 裁剪噪声得 0.2，加到动作后为 1.0，再按动作上限得到 0.9。
2. 双 critic 最小值为 3。
3. TD3 目标为 1+0.9×3=3.7。
:::

:::field{path="numericalExample.result" type="text"}
最终目标动作 0.900，双 Q 目标为 3.700。
:::

:::field{path="numericalExample.comparison" type="list"}
- 动作噪声先裁剪、动作边界后裁剪，限制对象不同。
- 该算术不包含延迟更新循环；延迟频率属于另一个机制。
:::

```Python
target_action, sampled_noise = 0.8, 0.5
noise = max(-0.2, min(0.2, sampled_noise))
smoothed_action = max(-0.9, min(0.9, target_action + noise))
target = 1.0 + 0.9 * min(5.0, 3.0)
print(f"target_action={smoothed_action:.3f}, target={target:.3f}")
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 混淆数据采集探索噪声与目标平滑噪声。
- 两个 critic 对不同目标动作评分后取最小。
- 认为取最小值便得到真实价值下界或安全保证。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### TD3 的双 critic 与 Double DQN 相同吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是。TD3 对同一目标动作取两 critic 的最小值；Double DQN 用在线网络选离散动作，再由目标网络评价。
:::
