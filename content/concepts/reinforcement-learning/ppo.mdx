## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
直接对同一批好动作大幅提高概率，可能让策略迅速失去原有能力。PPO 在新旧策略概率比率上构造裁剪代理目标，用有限轮小批量优化提高数据利用率，同时监测实际更新是否过大。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
PPO 的常见 clip 版本固定采样策略的旧对数概率与优势，优化新旧动作概率比率乘优势的保守代理目标。它通常配合 GAE、价值损失和熵项；数据来自近期策略，并不支持无限复用任意历史 replay。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
对好动作增加概率有收益，但增加到某程度后，这个样本不再给额外奖励；对坏动作也有对应的单侧限制。限制的是代理目标的激励，不是把整个新策略锁在固定距离球内。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
比率为 exp(new_log_prob−old_log_prob)，旧概率必须来自生成该数据的策略并保持固定。若每轮都重算并覆盖旧概率，比率会错误地回到 1，失去对更新幅度的参照。

优势为正时，过大的比率被截去额外收益；优势为负时，过小的比率被限制。min 作用和优势符号必须一起理解，不能先裁剪比率就宣称与原始 min 公式在所有方向等价。

裁剪不保证每个状态的概率比率或 KL 都被硬性约束。多轮更新、共享价值梯度和批外状态仍可能导致明显变化，所以常结合近似 KL、clip fraction、熵与早停诊断。
:::

### PPO clipped objective

L^{CLIP}(\theta)=\mathbb{E}_t[\min(r_t(\theta)\hat A_t,\operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t)]

:::field{path="numericalExample.title" type="text"}
### 正负优势下的裁剪方向不同
:::

:::field{path="numericalExample.given" type="list"}
- 两个样本概率比率为 1.5、0.5，优势为 +2、−2。
- 裁剪区间为 0.8 到 1.2。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 正优势项取 min(1.5×2,1.2×2)=2.4。
2. 负优势项取 min(0.5×−2,0.8×−2)=−1.6。
3. 两项平均代理目标为 0.4；这是构造批次的目标值。
:::

:::field{path="numericalExample.result" type="text"}
裁剪后两项为 2.4、−1.6，平均为 0.4。
:::

:::field{path="numericalExample.comparison" type="list"}
- 裁剪限制进一步改善方向上的激励。
- 示例输出的 policy loss 为负代理目标，符号来自最小化约定。
:::


## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 用 old policy 收集 rollout
2. 估计 returns/GAE
3. 保存 old log probability
4. 多 epoch mini-batch
5. 优化 clipped policy loss + value loss − entropy bonus
6. 丢弃旧 rollout 再采样
:::

### PPO clipped surrogate objective
:::

:::field{path="codeExamples.0.language" type="text"}
PyTorch
:::

:::field{path="codeExamples.0.purpose" type="text"}
直接计算概率比率、未裁剪目标和裁剪目标。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```PyTorch
import torch

old_log_prob = torch.log(torch.tensor([0.40, 0.55, 0.25]))
new_log_prob = torch.log(torch.tensor([0.52, 0.45, 0.50], requires_grad=True))
advantage = torch.tensor([1.2, -0.7, 0.4])
clip_range = 0.2

ratio = torch.exp(new_log_prob - old_log_prob)
unclipped = ratio * advantage
clipped_ratio = torch.clamp(ratio, 1 - clip_range, 1 + clip_range)
clipped = clipped_ratio * advantage
policy_loss = -torch.minimum(unclipped, clipped).mean()
policy_loss.backward()

print('ratio:', ratio.detach())
print('clipped ratio:', clipped_ratio.detach())
print('loss:', round(policy_loss.item(), 4))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- ratio 比较新旧策略对同一动作的概率。
- clamp 将比率限制在 \[1−ε,1+ε\]；minimum 构造保守代理目标。
- 真实 PPO 还组合 value loss、entropy bonus、GAE 与多轮 mini-batch 更新。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text

clipped ratio: tensor([1.2000, 0.8182, 1.2000])
loss: -0.4491
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 用新策略覆盖采样时的旧概率。
- 忽略负优势时 min 的符号效应。
- 把 clip 范围当作全策略 KL 的严格保证。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 用新策略覆盖采样时的旧概率。
- 忽略负优势时 min 的符号效应。
- 把 clip 范围当作全策略 KL 的严格保证。

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### PPO 能反复训练同一个数据集吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
通常只对近期 rollout 做有限轮优化，再重新采样。长期固定数据会出现策略分布与覆盖问题，PPO clip 本身不能将其变成可靠离线算法。
:::
