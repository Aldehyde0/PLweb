## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
PPO 交替采样当前策略数据并对 clipped surrogate objective 做多轮 mini-batch 优化。

本页使用“问题定义—数学目标—更新过程—代码—失败诊断”的顺序组织，避免只记算法缩写。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
允许策略改进，但若新策略偏离旧策略太远，就停止继续放大这部分收益。

把价值看作“未来累计收益的估计”，把策略看作“在状态下如何选动作的规则”；算法差异主要在估计谁、使用谁生成的数据以及如何更新。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
普通策略梯度更新过大会破坏策略。

ratio 比较新旧策略动作概率。

clip 不是硬性 KL 保证，但构造保守代理目标。

真实训练还组合 value loss、entropy bonus 与 GAE。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### PPO clipped objective
:::

:::field{path="formulas.0.expression" type="math"}
$$
L^{CLIP}(\theta)=\mathbb{E}_t[\min(r_t(\theta)\hat A_t,\operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t)]
$$
:::

:::field{path="formulas.0.description" type="text"}
取未裁剪与裁剪目标的较小值。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### PPO：Proximal Policy Optimization的最小计算
:::

:::field{path="numericalExample.given" type="list"}
- 即时奖励为 1
- 下一状态估计为 2
- 折扣因子 γ=0.9
- 当前估计为 0.5
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 计算 bootstrap 目标：1+0.9×2=2.8。
2. 目标与当前估计差为 2.8−0.5=2.3。
3. 若学习率 α=0.1，新估计为 0.5+0.1×2.3=0.73。
:::

:::field{path="numericalExample.result" type="text"}
一次更新后估计从 0.5 变为 0.73；是否收敛需要持续采样与满足相应条件。
:::

:::field{path="numericalExample.comparison" type="list"}
- 较大 α 更新快但噪声和震荡更强。
- 较大 γ 更重视远期奖励，但误差传播范围更长。
- 使用真实回报与 bootstrap 目标会带来不同偏差—方差权衡。
:::


## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 用 old policy 收集 rollout
2. 估计 returns/GAE
3. 保存 old log probability
4. 多 epoch mini-batch
5. 优化 clipped policy loss + value loss − entropy bonus
6. 丢弃旧 rollout 再采样
:::


## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### PPO clipped surrogate objective
:::

:::field{path="codeExamples.0.language" type="text"}
PyTorch
:::

:::field{path="codeExamples.0.purpose" type="text"}
直接计算概率比率、未裁剪目标和裁剪目标。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```PyTorch
import torch

old_log_prob = torch.log(torch.tensor([0.40, 0.55, 0.25]))
new_log_prob = torch.log(torch.tensor([0.52, 0.45, 0.50], requires_grad=True))
advantage = torch.tensor([1.2, -0.7, 0.4])
clip_range = 0.2

ratio = torch.exp(new_log_prob - old_log_prob)
unclipped = ratio * advantage
clipped_ratio = torch.clamp(ratio, 1 - clip_range, 1 + clip_range)
clipped = clipped_ratio * advantage
policy_loss = -torch.minimum(unclipped, clipped).mean()
policy_loss.backward()

print('ratio:', ratio.detach())
print('clipped ratio:', clipped_ratio.detach())
print('loss:', round(policy_loss.item(), 4))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- ratio 比较新旧策略对同一动作的概率。
- clamp 将比率限制在 \[1−ε,1+ε\]；minimum 构造保守代理目标。
- 真实 PPO 还组合 value loss、entropy bonus、GAE 与多轮 mini-batch 更新。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
超出 \[0.8,1.2\] 的 ratio 被截到边界，并打印可反向传播的 policy loss。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}

- 目标漂移
- 函数近似不稳定
