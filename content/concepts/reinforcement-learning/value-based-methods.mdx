## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
在有限棋盘上，每一步只有少量合法动作，可以给每个动作估一个分数再取最大。若动作是任意实数的机械臂力矩，价值网络虽能评分，却不能简单遍历所有候选；动作空间结构决定实现难度。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
价值方法以状态价值或动作价值为主要学习对象，再通过贪心、ε-greedy 或模型备份导出策略。Q-learning 与 DQN 是典型动作价值控制方法；动态规划也能通过状态价值和已知模型改进策略。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先建立路段总成本表，再按成本表选路线，类似价值方法。评分表会随新经验变化，因此“选当下最高分”依赖这张表有没有充分数据支撑。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
学习目标一般结合即时奖励与下一状态价值。控制算法的目标可能使用最大动作价值，而策略评价则使用当前策略期望；两者不能因为都写 Q 就混在一起。

贪心动作不一定是收集数据时唯一动作。ε-greedy 等探索机制会故意尝试其他行动，Q-learning 可以从这些数据学习贪心目标；SARSA 则把实际行为策略纳入备份。

函数近似下的最大化会偏好偶然高估值；双估计、目标网络和 replay 分别针对不同问题。它们是稳定化措施，不是任意神经网络设置下的收敛保证。
:::


## 数学表达 {#formulas}

### 由动作价值导出贪心动作
:::

:::field{path="formulas.0.expression" type="math"}
$$
a^*(s)\in\arg\max_{a\in\mathcal A(s)}Q(s,a)
$$
:::

:::field{path="formulas.0.description" type="text"}
最大化只能遍历合法动作；并列最优需要约定打破平局的方式。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 一次价值更新如何改变贪心动作
:::

:::field{path="numericalExample.given" type="list"}
- 当前两个动作 Q 值为 1 与 1.2。
- 动作 0 的目标为 2，学习率 0.5；动作 1 本次不更新。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 动作 0 更新为 1+0.5×(2−1)=1.5。
2. 动作 1 仍为 1.2。
3. 更新前贪心动作是 1，更新后变成 0。
:::

:::field{path="numericalExample.result" type="text"}
价值更新改变动作排序：贪心选择从动作 1 切换到动作 0。
:::

:::field{path="numericalExample.comparison" type="list"}
- 策略通过价值排序间接改变。
- 一次排序翻转不代表真实最优动作已被识别。
:::

## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 一次价值更新如何改变贪心动作
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
价值更新改变动作排序：贪心选择从动作 1 切换到动作 0。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
q = [1.0, 1.2]
before = max(range(2), key=q.__getitem__)
q[0] += 0.5 * (2.0 - q[0])
after = max(range(2), key=q.__getitem__)
print(f"before={before}, after={after}, updated_Q0={q[0]:.2f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 动作 0 更新为 1+0.5×(2−1)=1.5。
- 动作 1 仍为 1.2。
- 更新前贪心动作是 1，更新后变成 0。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
before=1, after=0, updated_Q0=1.50
```

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 价值方法是否都只能用离散动作？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是，但连续动作需要处理最大化问题，可能借助解析结构、候选搜索或 actor；普通 DQN 的有限输出枚举形式主要面向离散动作。
:::
