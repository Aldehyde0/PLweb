## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
离线数据中的 max Q 会主动查询未见动作，造成外推误差。IQL 试图在更新时不显式评价新的动作：先从数据动作的价值分布提取偏高状态价值，再偏向较好的数据动作拟合策略。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
IQL 先用非对称平方损失拟合状态条件 expectile V，再用 r+γV(s′) 回归数据动作 Q，最后以 exp(β(Q−V)) 加权数据动作对数似然。训练中的策略提取不需要在新动作上查询 critic，但部署策略仍会泛化。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
从同一地点的历史选择中，较重视表现好的记录，形成一个偏积极但仍基于记录的参考值；然后更多模仿超过该参考的动作。它不是在所有未见动作中寻找最高分。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
expectile 对正负残差使用不同平方权重，τ>0.5 更强调 Q 高于 V 的样本。它不是分位数：分位数对应非对称绝对误差，两个目标的数值和统计意义不同。

Q 回归、V 回归和 actor 回归各有固定目标与停止梯度边界。actor 的优势权重常裁剪，避免指数把少量高估或异常样本放大到支配整个批次；β 越大并不保证改进越好。

“不查询数据外动作”描述训练目标，不是整个策略的严格支持保证。数据缺乏关键状态、函数近似把多峰行为平均到无支持动作，或部署进入新区域时，IQL 仍可能失败。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### IQL 的三个目标
:::

:::field{path="formulas.0.expression" type="math"}
$$
L_V=\mathbb E_{(s,a)\sim\mathcal D}[L_2^\tau(\bar Q(s,a)-V(s))],\quad L_Q=\mathbb E_{\mathcal D}[(r+\gamma V(s\prime)-Q(s,a))^2],\quad L_\pi=-\mathbb E_{\mathcal D}[e^{\beta(\bar Q-V)}\log\pi(a|s)]
$$
:::

:::field{path="formulas.0.description" type="text"}
V 做 expectile regression，Q 只对数据 transition 做 TD，策略只对数据动作做优势加权最大似然。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 两个数据动作的上 expectile 不等于分位数
:::

:::field{path="numericalExample.given" type="list"}
- 同状态等频数据动作的 Q 为 1 与 3，τ=0.75。
- 假设拟合值位于 1 和 3 之间。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 较低动作残差用 0.25，较高动作残差用 0.75。
2. 令平方损失导数为零，得到 V=(0.25×1+0.75×3)/(0.25+0.75)=2.5。
3. 这两个原子分布的 0.75 分位数为 3，和 2.5 不同。
:::

:::field{path="numericalExample.result" type="text"}
上 expectile 为 2.5；下方 PyTorch 代码进一步核对 V、Q 和 actor 三项损失。
:::

:::field{path="numericalExample.comparison" type="list"}
- expectile 来自非对称平方损失，不是分位数。
- IQL 避免显式 OOD 动作查询，但不能突破状态覆盖限制。
:::


## 计算与实现步骤 {#algorithm-steps}

:::field{path="algorithmSteps" type="ordered"}
1. 从固定数据采样 batch
2. 冻结 Q 目标计算 Q(s,a)−V(s)
3. 用非对称平方损失更新 V
4. 用 r+γV(s′) 更新 Q
5. 计算数据动作 advantage
6. 用裁剪后的 exp(βA) 做行为克隆
7. 评测并可选在线微调
:::


## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### IQL 的 expectile、TD 与优势加权 BC
:::

:::field{path="codeExamples.0.language" type="text"}
PyTorch
:::

:::field{path="codeExamples.0.purpose" type="text"}
用固定 transition 批次对应 IQL 的 V、Q、policy 三个目标，全程不查询策略生成的新动作。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```PyTorch
import torch

tau, beta, gamma = 0.7, 3.0, 0.99
q_data = torch.tensor([1.4, 0.4, 2.0], requires_grad=True)
v = torch.tensor([0.9, 0.7, 1.3], requires_grad=True)
v_next = torch.tensor([0.6, 0.2, 0.0])
rewards = torch.tensor([0.5, 0.1, 2.0])
done = torch.tensor([0.0, 0.0, 1.0])
log_prob = torch.tensor([-0.8, -1.1, -0.5], requires_grad=True)
diff = q_data.detach() - v
expectile_weight = torch.where(diff > 0, tau, 1 - tau)
v_loss = (expectile_weight * diff.square()).mean()
td_target = rewards + gamma * (1 - done) * v_next
q_loss = (q_data - td_target).square().mean()
adv = q_data.detach() - v.detach()
policy_weight = torch.exp(beta * adv).clamp(max=100.0)
policy_loss = -(policy_weight * log_prob).mean()
(v_loss + q_loss + policy_loss).backward()
print('expectile weights:', expectile_weight)
print('policy weights:', policy_weight)
print('losses:', [round(x.item(), 3) for x in (v_loss,q_loss,policy_loss)])
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- V 用非对称平方损失逼近 Q(s,a) 的上 expectile。
- Q 的目标使用下一状态 V(s′)，不需要对策略动作求 Q。
- 策略只对数据动作做优势加权最大似然；指数权重需要裁剪。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
expectile weights: tensor([0.7000, 0.3000, 0.7000])
policy weights: tensor([4.4817, 0.4066, 8.1662])
losses: [0.182, 0.035, 2.705]
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 expectile 称为 τ 分位数。
- 让指数权重无限增长，使异常样本主导策略。
- 把只拟合数据动作夸大成部署永远不会产生数据外动作。
:::

## 算法属性与数据边界 {#algorithm-profile}

<ArticleFlags />
:::field{path="objectiveFunction" type="text"}
expectile V regression + TD Q regression + advantage-weighted behavioral cloning
:::
:::field{path="advantageEstimator" type="text"}
A(s,a)=Q(s,a)−V(s)，仅在数据动作上计算
:::
:::field{path="dataBoundary" type="list"}
- 训练需要固定 transition 和数据动作；策略目标不对新动作求 Q，但最终策略仍可能因泛化产生数据外动作。
- τ 与 β 决定保守—改进权衡，应随数据质量验证。
- 在线微调是单独阶段；一旦新增环境数据，必须与纯离线结果分开报告。
:::

## 与 DQN、SAC 及相邻方法对照 {#algorithm-comparison}

:::field{path="comparisonNotes" type="list"}
- DQN：使用 max\_a Q(s′,a)；IQL 改用 V(s′)，避免下一步 OOD max。
- SAC：actor 采样动作并通过 Q 更新；IQL actor 仅对数据动作做加权最大似然。
- CQL：显式惩罚可能的 OOD 高 Q；IQL 通过不查询这些动作来规避训练时外推。
:::


## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把 expectile 当成 quantile 实现
- Q/V target 未停止梯度导致耦合不稳
- exp(βA) 溢出或有效样本数过低
- 数据回报尺度变化后沿用原 β
:::

:::field{path="securityRisks" type="list"}
- 高优势历史动作可能来自奖励漏洞或越权行为。
- 部署仍需动作过滤、回退策略和分阶段放量。
:::

:::field{path="performanceNotes" type="list"}
- 无需为每个状态采样大量候选动作，通常比采样式 CQL 简洁。
- 报告 τ、β、权重上限、奖励归一化、target 更新与多 seed。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### IQL 不评价新动作就没有分布外问题了吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
没有。训练少了一类显式动作外推，但函数近似、状态覆盖、连续策略泛化和长期部署分布仍可能超出数据证据。
:::
