## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
动作采样后环境可能返回一个离散胜负分数，无法直接对“赢了这局”做普通监督反向传播。策略梯度利用被采样动作的概率变化，把回报转换成策略参数方向，适用于不可微或未知动力学环境。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
策略梯度优化参数化策略的期望回报。score-function 形式将采样动作的对数概率梯度乘以回报或优势估计；环境转移不依赖策略参数时，推导中不需要对转移函数求导。严格目标还需对齐折扣占用分布或相应时间权重。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
一次动作比预期好，就增加在相似条件下选它的倾向；比预期差就减小。信号是相对好坏，不是“奖励为正就永远加概率”，因为一个得 2 分的动作可能低于 5 分的基线。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
对两动作 sigmoid 策略，选中动作 1 时 log 概率对 logit 的导数是 1−p；选中动作 0 时是 −p。方向来自概率参数化，而非直接把奖励加到概率上，否则容易破坏概率归一化。

只依赖状态的基线，其 score-function 期望贡献为零，因此可降低方差而不改变理想梯度。若基线依赖采样动作，或在 actor 更新中不恰当地穿过优势反向传播，需要额外修正，不能直接宣称无偏。

有限批次梯度很嘈杂，策略又会改变未来数据分布。记录熵、优势尺度与更新幅度比只看最后一批奖励更能诊断训练；局部改进方向也不构成全局最优保证。
:::

### Policy Gradient
:::

:::field{path="formulas.0.expression" type="math"}
$$
\nabla_\theta J(\theta)=\mathbb{E}[\nabla_\theta\log\pi_\theta(A_t|S_t)\,A_t^\pi]

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 一个 Bernoulli logit 的策略上升更新
:::

:::field{path="numericalExample.given" type="list"}
- 选动作 1 的概率 p=0.25，对应 logit 为 log(1/3)。
- 本次选中动作 1，优势为 2，学习率 0.1。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. score 导数为 1−0.25=0.75。
2. logit 增量为 0.1×2×0.75=0.15。
3. 将新 logit 经 sigmoid 得到约 0.279164。
:::

:::field{path="numericalExample.result" type="text"}
好于预期的动作 1 概率从 0.250000 提高到约 0.279164。
:::

:::field{path="numericalExample.comparison" type="list"}
- 更新的是 logit，概率变化由 sigmoid 决定。
- 单样本方向有噪声，不能保证一次更新后真实回报必涨。
:::

:::

:::field{path="codeExamples.0.language" type="text"}

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import math
p, advantage, learning_rate = 0.25, 2.0, 0.1
logit = math.log(p / (1 - p))
logit += learning_rate * advantage * (1 - p)
new_p = 1 / (1 + math.exp(-logit))
print(f"old_probability={p:.6f}, new_probability={new_p:.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- score 导数为 1−0.25=0.75。
- logit 增量为 0.1×2×0.75=0.15。
- 将新 logit 经 sigmoid 得到约 0.279164。
:::


## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 直接将奖励加到概率，破坏参数与归一化关系。
- 让 actor 梯度任意穿过未分离的价值目标。
- 忽略折扣目标与采样时间权重的约定。
:::

:::field{path="failureModes" type="list"}

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 环境不可微还能算梯度吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
可以对策略动作概率求 score-function 梯度，不要求对环境本身求导；但需要从策略分布采样，并使用正确回报与数据权重。
