## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
仓库控制器看见“库存 2”，却不知道货物明天还是下周到达，会对同一观察做出相同决策。若补货在途时间影响未来，这样的状态表示就丢了关键信息；算法再复杂也不能恢复从未提供的信息。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
状态是为预测未来并做决策保留的信息；动作是智能体在当前条件下允许选择的控制量；奖励是执行动作、发生转移后收到的标量。观察可能只是状态的一部分。奖励表达优化偏好，不能自动替代成本约束或真实目标。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
库存数字像照片，在途订单与交期像照片背后的日程。只给照片可能不足以决定订货量；动作还要受仓容和预算约束，不能让网络随意输出任何数字。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
状态设计先检查相同表示下，后继和奖励分布是否仍因遗漏历史而不同。订单年龄、剩余预算、时间等可能需要加入；加入过多无关特征又会增加学习难度。

离散动作可以枚举合法选项并计算 Q 的最大值；连续动作如转向角需要显式边界与适当策略参数化。非法动作掩码必须在训练和执行时保持一致，否则策略可能依赖部署时不可用的动作。

奖励的索引应对齐转移：状态与动作是输入，奖励和下一状态是结果。把后一轮奖励错配给前一轮的另一动作，会让 TD 目标和策略梯度都学错因果对应关系。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 库存转移与奖励逐项核算
:::

:::field{path="numericalExample.given" type="list"}
- 库存 2，订货 3，收到需求 4；订货当期到达。
- 每售出一件收入 5，进货成本每件 2，剩余库存保管成本每件 1。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 可售库存为 2+3=5，售出 min(5,4)=4。
2. 下一库存为 5−4=1。
3. 奖励为 5×4−2×3−1=13。
:::

:::field{path="numericalExample.result" type="text"}
这次转移的下一库存是 1，奖励是 13；交货延迟改变时必须修改状态和转移。
:::

:::field{path="numericalExample.comparison" type="list"}
- 本例奖励是利润定义，不代表所有库存任务都应忽略缺货风险。
- 订货动作和售出数量是不同变量，后者由需求与转移共同决定。
:::

```Python
stock, order, demand = 2, 3, 4
sold = min(stock + order, demand)
next_stock = stock + order - sold
reward = 5 * sold - 2 * order - next_stock
print(f"sold={sold}, next_stock={next_stock}, reward={reward}")
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 漏掉影响交期或剩余资源的状态变量。
- 把连续控制量简单取整，却没有重新定义环境。
- 只惩罚不合法动作而未执行必要的动作约束。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 漏掉影响交期或剩余资源的状态变量。
- 把连续控制量简单取整，却没有重新定义环境。
- 只惩罚不合法动作而未执行必要的动作约束。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::
