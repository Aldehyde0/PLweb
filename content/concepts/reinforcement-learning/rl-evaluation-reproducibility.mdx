## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
一条漂亮训练曲线可能来自幸运初始化，末次评测也可能恰巧遇到容易任务。RL 的数据与策略相互影响，种子之间差异往往很大；只报告最好运行会系统性夸大可靠性。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
强化学习评测是在预先固定的环境、任务分布、交互预算和策略选择协议下，估计策略回报与其他目标。可复现记录包括环境与包装器版本、配置、种子、数据版本、检查点和评测动作方式，而不仅是一个随机种子数字。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
同一名运动员在多个场次的成绩，不能和多个独立训练出的运动员混为一谈。episode 波动是环境随机性，训练种子波动还包含学到不同策略的差异。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
每个训练种子可以有多个评测 episode，先明确统计单位再汇总。把全部 episode 当独立训练样本，会夸大有效样本量；不确定性估计需保留种子或任务层级，可按协议使用分层 bootstrap 等方法。

评测通常关闭训练探索噪声或明确使用采样策略，并保持无梯度、固定归一化统计。训练环境回报与独立评测回报分开，频繁根据测试分数选检查点会引入选择偏差。

样本效率以真实交互量衡量，墙钟时间还包括计算和模拟器开销，离线方法则需说明数据规模与调参边界。不同预算、环境版本和终止规则下的数字不能直接排成排行榜。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 按训练种子汇总均值
:::

:::field{path="formulas.0.expression" type="math"}
$$
\bar J=\frac1N\sum_{i=1}^N\hat J_i
$$
:::

:::field{path="formulas.0.description" type="text"}
每个 Ĵ_i 是独立训练种子的评测估计；仍需报告不确定性与失败分布。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 相同均值可以掩盖不同种子稳定性
:::

:::field{path="numericalExample.given" type="list"}
- 三次训练结果 A 为 [0,0,30]，B 为 [9,10,11]。
- 每个数字已是一个种子的平均评测回报。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 两种方法的种子均值都为 10。
2. A 的样本标准差约 17.3205，B 为 1。
3. 报告最好一次会把 A 的 30 当优势，却隐去两次失败。
:::

:::field{path="numericalExample.result" type="text"}
A、B 均值均为 10，但种子间样本标准差约 17.321 与 1.000。
:::

:::field{path="numericalExample.comparison" type="list"}
- 均值相同不等于失败风险相同。
- 三个种子只适合教学，不能据此给出精确可靠的性能结论。
:::

```Python
from statistics import mean, stdev
for name, seed_scores in [("A", [0.0, 0.0, 30.0]), ("B", [9.0, 10.0, 11.0])]:
    print(f"{name} mean={mean(seed_scores):.3f} sample_std={stdev(seed_scores):.3f} best={max(seed_scores):.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 两种方法的种子均值都为 10。
- A 的样本标准差约 17.3205，B 为 1。

:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 只报告最好种子或最好检查点，不说明选择协议。
- 把同一策略的多个 episode 当多个独立训练结果。
- 只比较最终回报，不对齐交互和计算预算。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 只报告最好种子或最好检查点，不说明选择协议。
- 把同一策略的多个 episode 当多个独立训练结果。
- 只比较最终回报，不对齐交互和计算预算。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 固定一个 seed 就完全可复现吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不一定。并行调度、硬件算子、库与环境版本仍可能影响结果；应保存配置与版本，并区分数值确定性和统计结论可重复。
:::

:::field{path="commonQuestions.1.question" type="text"}
### 网页是否会训练模型？
:::

:::field{path="commonQuestions.1.answer" type="text"}
不会。所有图表使用固定种子或解析公式在浏览器本地计算，不执行页面中的示例代码。
