## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
REINFORCE 等到任务结束才能用完整回报，而控制任务常需要每步更新。Actor-Critic 让 critic 学习后续收益估计，actor 用它判断所选动作好于还是差于预期，可以较早获得学习信号。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Actor 参数化策略，critic 估计状态价值或动作价值，并提供策略更新所需的优势或梯度信号。它是一种结构家族，不是唯一算法；既包括 A2C 等 on-policy 形式，也包括 DDPG、TD3、SAC 等 off-policy 形式。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
执行者负责尝试，评论家用当前经验评价这次尝试。评论家不必等所有长期结果出现，但它的猜测可能有偏，执行者也可能学会利用评分漏洞。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
状态价值 critic 的一步 TD error 可作为优势估计：用奖励加后继价值减当前价值。critic 准确且数据条件合适时，它提供合理的相对行为信号；critic 尚未学准时，actor 可能被错误方向引导。

critic 的回归目标通常停止梯度，actor 更新也常将优势当固定信号。共享编码器可以省参数，但两种损失可能冲突，权重、更新频率与梯度尺度需要一起监测。

本页小例使用 on-policy 状态价值结构。不能把它的 δ×log_prob 更新直接套进确定性 DDPG 或最大熵 SAC；这些算法虽然也有 actor 和 critic，目标、数据使用和梯度路径不同。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### TD 信号怎样同时更新 critic 和 actor
:::

:::field{path="numericalExample.given" type="list"}
- V(s)=0.5，后继 V=2，奖励 1，折扣 0.9。
- critic 学习率 0.1；本次动作的 log 概率梯度为 0.4，actor 学习率 0.05。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. TD error 为 1+0.9×2−0.5=2.3。
2. critic 的表格值更新为 0.5+0.1×2.3=0.73。
3. actor 参数上升增量为 0.05×2.3×0.4=0.046。
:::

:::field{path="numericalExample.result" type="text"}
同一 δ=2.3 让 critic 值变为 0.730，actor 参数沿 score 方向增加 0.046。
:::

:::field{path="numericalExample.comparison" type="list"}
- critic 在拟合价值，actor 在改变动作分布，两者目标不同。
- 只有本例的表格 critic 能直接按标量更新，神经网络需通过损失求梯度。
:::

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### TD 信号怎样同时更新 critic 和 actor
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
同一 δ=2.3 让 critic 值变为 0.730，actor 参数沿 score 方向增加 0.046。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
value, next_value, reward = 0.5, 2.0, 1.0
delta = reward + 0.9 * next_value - value
new_value = value + 0.1 * delta
actor_increment = 0.05 * delta * 0.4
print(f"delta={delta:.3f}, critic_value={new_value:.3f}")
print(f"actor_increment={actor_increment:.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- TD error 为 1+0.9×2−0.5=2.3。
- critic 的表格值更新为 0.5+0.1×2.3=0.73。
- actor 参数上升增量为 0.05×2.3×0.4=0.046。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
delta=2.300, critic_value=0.730
actor_increment=0.046
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 Actor-Critic 家族全部归为 on-policy。
- critic 误差很大时仍让 actor 大步追逐其评分。
- 忽略策略与价值共享网络时的梯度和尺度冲突。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把 Actor-Critic 家族全部归为 on-policy。
- critic 误差很大时仍让 actor 大步追逐其评分。

:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::
