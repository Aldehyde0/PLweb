## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
强化学习面对序贯决策：动作会改变之后能看到的状态和奖励，因此样本通常并非独立同分布。

同一算法的效果取决于环境、探索策略、函数近似、随机种子和评测协议，单次曲线不足以下结论。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
离线数据由未知或混合行为策略 β 生成，而学习策略 π 会改变状态—动作占用分布；当 π 查询数据低密度区域的 Q 值时，函数近似误差可能经 Bellman backup 被反复放大。

本页使用“问题定义—数学目标—更新过程—代码—失败诊断”的顺序组织，避免只记算法缩写。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
数据像一张只标出走过道路的地图。普通 greedy 更新可能把地图空白处的随机高分当成捷径，并在每次 bootstrap 中继续抬高它。

把价值看作“未来累计收益的估计”，把策略看作“在状态下如何选动作的规则”；算法差异主要在估计谁、使用谁生成的数据以及如何更新。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
分布偏移同时发生在动作条件分布 π(a\|s) 与长期状态访问分布 d^π(s)。

监督学习式训练误差小，不代表策略选择的动作上误差小。

DQN 的 max\_a Q(s′,a) 与 SAC 的 actor 采样都会主动寻找 critic 的高值，因而可能放大 OOD 乐观误差。

覆盖是可辨识边界：没有数据或结构假设，就不能可靠比较任意未见动作。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 占用分布密度比
:::

:::field{path="formulas.0.expression" type="math"}
$$
w(s,a)=\frac{d^\pi(s,a)}{d^\beta(s,a)}
$$
:::

:::field{path="formulas.0.description" type="text"}
当行为占用 d^β(s,a) 接近 0 而目标策略仍访问该区域时，密度比不可稳定估计，离线数据无法支持该决策。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 离线数据分布偏移与外推误差的最小计算
:::

:::field{path="numericalExample.given" type="list"}
- 即时奖励为 1
- 下一状态估计为 2
- 折扣因子 γ=0.9
- 当前估计为 0.5
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 计算 bootstrap 目标：1+0.9×2=2.8。
2. 目标与当前估计差为 2.8−0.5=2.3。
3. 若学习率 α=0.1，新估计为 0.5+0.1×2.3=0.73。
:::

:::field{path="numericalExample.result" type="text"}
一次更新后估计从 0.5 变为 0.73；是否收敛需要持续采样与满足相应条件。
:::

:::field{path="numericalExample.comparison" type="list"}
- 较大 α 更新快但噪声和震荡更强。
- 较大 γ 更重视远期奖励，但误差传播范围更长。
- 使用真实回报与 bootstrap 目标会带来不同偏差—方差权衡。
:::

:::field{path="codeExamples.0.purpose" type="text"}

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```NumPy
import numpy as np

actions = np.array([0, 0, 0, 1, 0, 1])  # 数据里没有动作 2
counts = np.bincount(actions, minlength=3)
support = counts > 0
q_estimate = np.array([1.0, 1.3, 4.8])
naive_action = int(q_estimate.argmax())
masked_q = np.where(support, q_estimate, -np.inf)
supported_action = int(masked_q.argmax())
print('counts:', counts)
print('naive greedy:', naive_action)
print('support-aware:', supported_action)
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- counts 是经验数据在该状态附近的动作覆盖代理。
- 普通 max 会选择没有样本证据的动作 2。
- support mask 只是离散教学示例；连续空间需要密度、距离、生成模型或保守价值方法。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
naive greedy 选择未覆盖动作 2；support-aware 只在数据动作中选择 1。
:::

## 算法属性与数据边界 {#algorithm-profile}

<ArticleFlags />
:::field{path="objectiveFunction" type="text"}
识别并限制 d^π 相对 d^β 的不受支持偏移
:::
:::field{path="dataBoundary" type="list"}
- 行为策略 β 可能未知、非平稳或由多策略混合。
- 覆盖统计只能证明看见过，不能证明奖励正确、长时序后果充分或部署安全。
- 离线调参若反复依据在线回报，会把评测环境变成隐式训练数据。
:::

## 与 DQN、SAC 及相邻方法对照 {#algorithm-comparison}

:::field{path="comparisonNotes" type="list"}
- DQN 的离散 max backup 明确枚举并偏好最高估动作。
- SAC 的 actor 在连续空间优化 Q−αlogπ，可能找到数据外的 critic 漏洞。
- CQL 压低广泛动作的 Q；IQL 避免对策略生成的新动作求 Q。
:::


## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把 replay buffer 大误当作覆盖充分
- 只看边际动作频率，忽略状态条件覆盖
- 终止/超时标记错误导致虚假 bootstrap
- 用训练集 Q 值代替策略价值评测
:::

:::field{path="securityRisks" type="list"}
- 历史日志可能含隐私、异常操作或已废止权限。
- 策略会利用日志中的奖励漏洞，数据清洗不能替代环境侧硬约束。
:::

:::field{path="performanceNotes" type="list"}
- 报告数据规模、轨迹数、行为策略混合和 return 分布。
- 按数据子集与随机种子报告不确定性；OOD 分数本身也需校准。
:::
