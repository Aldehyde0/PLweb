## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
连续控制中，多个动作都可能有不错收益。过早只保留一个动作会削弱探索，也可能更容易追逐 critic 的局部误差。SAC 通过最大熵目标保留随机性，再从 replay 复用经验。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Soft Actor-Critic 是最大熵 off-policy actor-critic 方法，目标同时奖励回报与条件动作熵。常见连续版本使用随机重参数化 actor、双 Q、目标 critic 与可学习温度；离散 SAC 也存在，但不能把两者损失细节无条件混用。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不只问“这个动作分数高不高”，也问“保留合理选择余地是否值得”。温度控制对多样性的重视程度；它不是环境温度，也不是学习率。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
soft bootstrap 通常含 min Q(s′,a′)−α log π(a′|s′)。因为 log 概率常为负，减去它会提供正的熵贡献；actor 则最小化 α log π−Q，符号必须与优化方向一致。

连续动作常用 Gaussian 经 tanh 限幅，计算 log density 时需要 Jacobian 修正。忽略变换会让熵、温度和 actor 梯度都对应错误分布；密度大于 1 也并非概率非法。

自动温度调节追踪目标熵，但目标熵是设计选择，并非真实任务最佳随机性的保证。部署用均值动作还是采样动作、训练和评测是否相同，都应记录。固定离线 replay 仍会有覆盖与外推风险。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 两动作 soft 价值中的熵贡献
:::

:::field{path="numericalExample.given" type="list"}
- 为便于手算使用离散策略 π=[0.5,0.5]，双 Q 最小值为 1、3。
- 温度 α=0.2，奖励 0，折扣 0.9。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 期望 Q 为 2。
2. 熵为 ln2，soft 价值为 2+0.2 ln2≈2.138629。
3. bootstrap 目标为 0.9×2.138629≈1.924766。
:::

:::field{path="numericalExample.result" type="text"}
熵贡献约 0.138629，soft 目标约 1.924766。
:::

:::field{path="numericalExample.comparison" type="list"}
- 本例是离散期望算术，连续版本需要采样密度与变换修正。
- 熵贡献提高的是最大熵目标，不是额外获得的环境奖励。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import math
probabilities, min_q = [0.5, 0.5], [1.0, 3.0]
alpha, gamma = 0.2, 0.9
soft_value = sum(p * (q - alpha * math.log(p)) for p, q in zip(probabilities, min_q))
print(f"soft_value={soft_value:.6f}, target={gamma*soft_value:.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 期望 Q 为 2。
- 熵为 ln2，soft 价值为 2+0.2 ln2≈2.138629。
- bootstrap 目标为 0.9×2.138629≈1.924766。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- soft target 的 log 概率项符号写反。
- tanh 后仍使用未变换 Gaussian 的 log density。
- 认为自动温度调节可以替代数据覆盖与安全约束。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- soft target 的 log 概率项符号写反。

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。

:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 温度 α 越高回报越好吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不一定。较高温度更重视熵，可能改善探索，也可能让策略持续选择低收益动作；环境回报与最大熵训练目标应分别评价。
:::
