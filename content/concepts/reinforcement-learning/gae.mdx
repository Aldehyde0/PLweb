## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
一步优势估计依赖 critic 精度，完整回报又可能方差很大。GAE 用 λ 控制未来 TD 残差的贡献，形成从短期 bootstrap 到较长真实轨迹之间的连续折中，在 PPO 等算法中很常见。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
广义优势估计 GAE 是折扣 TD error 的加权和，常通过从后向前递推计算。γ 定义回报折扣，λ 控制残差传播长度；二者都让远处残差衰减，但不能在任务语义上互相替代。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
一次评价不只听“这一步比预期好多少”，还部分听后面几步不断修正后的评价。λ 越大，越愿意让较远的实际结果影响当前动作，但也会接收更多随机波动。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
先用同一组固定价值估计计算 δ，再倒序递推 $A_t=\delta_t+\gamma\lambda A_{t+1}$。若本步真正终止，后续递推为零；纯采样截断仍可用最后观察价值构造本步 δ，但不能把下一局优势接过来。

λ=0 只保留当前一步 TD error；在完整终止轨迹上 λ=1 会望远镜式化为采样折扣回报减当前价值。有限 rollout 或不准确末端 bootstrap 仍可能带来误差，不能将 λ=1 简写成任何条件下无偏。

优势通常在 actor 损失里停止梯度，有些实现还做批内标准化。critic 的回归目标可用优势加旧价值构造，但这个 target 应固定，不能随着同一轮在线价值变化而任意重算。
:::

### GAE
:::

:::field{path="formulas.0.expression" type="math"}
$$
\hat A_t^{GAE(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 两步轨迹的 GAE 倒序计算
:::

:::field{path="numericalExample.given" type="list"}
- 奖励为 0、1，价值为 0.5、0.6、0；最后一步真正终止。
- γ=0.9，λ=0.8。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 两个 TD error 为 0+0.9×0.6−0.5=0.04，以及 1−0.6=0.4。
2. 末步优势为 0.4。
3. 首步优势为 0.04+0.9×0.8×0.4=0.328。
:::

:::field{path="numericalExample.result" type="text"}
GAE 优势为 0.328、0.400；若 λ=0，首步只剩 0.040。
:::

:::field{path="numericalExample.comparison" type="list"}
- λ 改变估计器使用未来残差的长度。
- 真正终止末端值为零，时间截断末端值需要另行处理。
:::

### 两步轨迹的 GAE 倒序计算
:::

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
GAE 优势为 0.328、0.400；若 λ=0，首步只剩 0.040。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
rewards, values = [0.0, 1.0], [0.5, 0.6, 0.0]
gamma, lam = 0.9, 0.8
advantages = [0.0] * len(rewards)
carry = 0.0
for t in reversed(range(len(rewards))):
    delta = rewards[t] + gamma * values[t + 1] - values[t]
    carry = delta + gamma * lam * carry
    advantages[t] = carry
print("advantages=" + ",".join(f"x={x:.3f}" for x in advantages))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 两个 TD error 为 0+0.9×0.6−0.5=0.04，以及 1−0.6=0.4。
- 末步优势为 0.4。
- 首步优势为 0.04+0.9×0.8×0.4=0.328。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
advantages=x=0.328,x=0.400
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 正序递推时错误使用尚未计算的未来优势。
- 跨 episode 传播优势，把新一局奖励接到上一局。
- 将 λ 与 γ 当成可以随意交换的同义参数。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### λ 越大是否一定更好？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不一定。较大 λ 更多依赖长轨迹实际结果，通常降低部分 bootstrap 偏差但提高方差；合适取值与 critic 质量、任务长度和数据预算有关。
:::
