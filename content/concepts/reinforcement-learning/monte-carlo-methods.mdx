## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
打完一局牌后，可以回看每个决策点到结束实际拿到了多少分，不需要知道所有转移概率。不同对局结果很随机，因此不能把一次好结果直接当成这个状态的价值。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Monte Carlo 策略评价用实际采样到的完整回报作为目标，不用价值估计补足未来。首次访问方法在每个 episode 仅使用某状态首次出现的回报；每次访问方法使用该状态各次出现的回报。两者计数不同，有限样本估计也可能不同。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
用多次完整旅程的实际总费用评价一个出发点，而不是走一步就借助另一个估计猜剩余费用。旅程越长、路况越随机，总费用样本的波动可能越大。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
对固定策略，可累加回报再除以访问次数，也可用增量平均更新。固定步长会更重视近来的样本，适应变化较快，但不等价于所有历史回报的算术平均。

完整回报避免了 bootstrap 引入的估计误差，却仍受奖励噪声、轨迹方差和策略分布影响。off-policy MC 还需满足支持条件并处理重要性采样的高方差，不能仅说“不自举所以无任何偏差”。

标准 episodic MC 需要获得终止回报。把未完成的片段剩余回报直接设零，会低估持续任务价值；使用后继估计补足后，目标已变为 n-step 或其他 bootstrap 方法。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 折扣回报
:::

:::field{path="formulas.0.expression" type="math"}
$$
G_t=R_{t+1}+\gamma G_{t+1}
$$
:::

:::field{path="formulas.0.description" type="text"}
当前回报由下一奖励与折扣后的未来回报组成。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 同一 episode 重访状态时的两种统计
:::

:::field{path="numericalExample.given" type="list"}
- 一局中状态 s 出现在时刻 0 与 2，对应完整回报为 4 与 2。
- 另一局只出现一次，对应回报为 6。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 首次访问仅收集第一局的 4 和第二局的 6，均值为 5。
2. 每次访问收集 4、2、6，均值为 4。
3. 这只是两局的有限样本差异，不说明哪种估计总是更好。
:::

:::field{path="numericalExample.result" type="text"}
首次访问估计为 5.000，每次访问估计为 4.000。
:::

:::field{path="numericalExample.comparison" type="list"}
- 首次访问是每个 episode 内的规则。
- 回报目标直接来自完整轨迹，不是 TD 后继估计。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把首次访问解释成整个训练过程只更新一次。
- 时间截断后把未见未来全部当作真实零回报。
- 把固定步长更新称为精确历史平均。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把首次访问解释成整个训练过程只更新一次。
- 时间截断后把未见未来全部当作真实零回报。

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### MC 的目标无 bootstrap，估计就一定无偏吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
完整同策略回报有对应的期望解释，但有限样本、访问选择、重要性比率归一化与函数逼近仍需要分别分析，不能笼统保证所有实现无偏。
:::
