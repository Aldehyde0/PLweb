## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
机器人每秒都收到反馈，等到数小时任务结束才更新会很慢。TD 在得到一个后继状态后就使用当前价值估计补足未来，使持续任务也能边交互边学习；代价是目标本身含有估计误差。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
时序差分学习用实际一步奖励与后继价值构造目标，比较目标和当前预测得到 TD error。TD(0) 是一步方法；n-step 方法使用更长真实奖励片段后再 bootstrap。该思想既可评价状态价值，也可进入动作价值与 actor-critic 算法。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
原来预计路还要走 10 分钟，走了一段后用时 2 分钟、剩余估计变成 9 分钟，就发现先前估计偏低 1 分钟。TD error 是相邻预测在新证据下的不一致。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
更新前需要固定当前价值与后继价值，先构造目标，再按学习率缩小误差。若共享网络同时变化，目标会随参数漂移；表格收敛条件不能直接涵盖任意非线性网络。

真实终止状态没有后续回报，bootstrap 项为零。纯采样截断的持续任务通常仍保留最后观察的价值；mask 错误会系统性扭曲所有接近时间边界的状态。

TD 通常比完整回报的方差更低，但会利用不准确的后继估计。目标误差、采样噪声与函数逼近需要区分；增大学习率可以更快传播信息，也可能放大震荡。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 非终止与终止转移的 TD(0) 更新
:::

:::field{path="numericalExample.given" type="list"}
- 当前价值 4，奖励 1，后继价值 5，折扣 0.9。
- 学习率 0.2；对比同样奖励下真正终止的转移。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 非终止目标为 1+0.9×5=5.5，误差为 1.5。
2. 新价值为 4+0.2×1.5=4.3。
3. 真正终止时目标为 1，新价值为 4+0.2×(1−4)=3.4。
:::

:::field{path="numericalExample.result" type="text"}
相同奖励下，非终止更新为 4.300，终止更新为 3.400。
:::

:::field{path="numericalExample.comparison" type="list"}
- bootstrap 改变目标，终止标记不是可忽略的日志字段。
- TD error 是学习残差，不是真实价值误差的直接测量。
:::

### 非终止与终止转移的 TD(0) 更新
:::

:::field{path="codeExamples.0.language" type="text"}

:::

:::field{path="codeExamples.0.purpose" type="text"}
相同奖励下，非终止更新为 4.300，终止更新为 3.400。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
value, reward, next_value = 4.0, 1.0, 5.0
alpha, gamma = 0.2, 0.9
for terminal in [False, True]:
    target = reward + gamma * (not terminal) * next_value
    updated = value + alpha * (target - value)
    print(f"terminal={terminal} target={target:.3f} updated={updated:.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 非终止目标为 1+0.9×5=5.5，误差为 1.5。
- 新价值为 4+0.2×1.5=4.3。
- 真正终止时目标为 1，新价值为 4+0.2×(1−4)=3.4。
:::

```text
terminal=False target=5.500 updated=4.300
terminal=True target=1.000 updated=3.400
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 用更新后的值重新计算同一次目标，改变预期备份。
- 真正终止后仍加上价值网络预测。
- 把 TD error 为零当成真实价值已经正确。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### TD 是模型方法吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
通常不需要显式转移模型；它使用采样转移加价值 bootstrap。价值预测未来回报，不等于预测下一状态的动力学模型。
:::
