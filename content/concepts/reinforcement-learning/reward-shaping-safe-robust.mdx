## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
让机器人更接近目标就加分，可能加速学习，也可能鼓励来回移动刷奖励。把碰撞写成大负分又不一定禁止碰撞；针对随机扰动训练也未必涵盖真实极端情况。三种设计必须分别定义与验证。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
奖励塑形改变反馈以辅助学习；安全强化学习把成本或禁止条件纳入约束；鲁棒强化学习针对一组模型或扰动优化。它们可以组合，但更高塑形回报、满足平均成本和抵御最坏情形是不同结论。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
给练车者过程鼓励，不等于给车装上防撞系统；在雨天练习，也不等于能应对任意天气。训练信号、执行约束和环境变化是三层不同的问题。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
势函数塑形使用 γΦ(s′)−Φ(s)。折扣和边界条件正确时，整条轨迹的差值会望远镜式消去，留下与起点有关的常数，从而保持原策略排序；终点势或未处理的时限可能破坏这一结论。

成本约束可以限制期望累计违规，但期望约束仍允许某些轨迹违规。必须禁止的行动通常还需可行集合、屏障或执行层检查，不能只靠一个“足够大”的负奖励。

鲁棒性结论相对于选定扰动集合成立。集合太窄漏掉部署变化，太宽可能过度保守；应报告扰动类型、范围、最坏情形指标与常规回报，而非笼统称策略安全鲁棒。
:::

### 势函数奖励塑形
:::

:::field{path="formulas.0.expression" type="math"}
$$
r\prime(s,a,s\prime)=r(s,a,s\prime)+\gamma\Phi(s\prime)-\Phi(s)
$$
:::

:::field{path="formulas.0.description" type="text"}
无限折扣有界势或正确处理的 episodic 边界下，额外回报不改变固定起点的策略排序。

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 势函数塑形的折扣望远镜效应
:::

:::field{path="numericalExample.given" type="list"}
- 两步奖励为 0、1，γ=0.9。
- 状态势为 −2、−1、0，终点势为零。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 塑形项依次为 0.9×(−1)−(−2)=1.1 与 0−(−1)=1。
2. 新奖励为 1.1、2，折扣回报为 2.9。
3. 原回报为 0.9，差值为 2，正好等于 −Φ(s0)。
:::

:::field{path="numericalExample.result" type="text"}
原回报 0.900，塑形后 2.900；固定起点下该差值与路径动作无关。
:::

:::field{path="numericalExample.comparison" type="list"}
- 策略不变结论依赖折扣、势函数及终止边界条件。
- 塑形不自动提供硬安全或任意扰动鲁棒性。
:::

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### 势函数塑形的折扣望远镜效应
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
原回报 0.900，塑形后 2.900；固定起点下该差值与路径动作无关。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
rewards, potential, gamma = [0.0, 1.0], [-2.0, -1.0, 0.0], 0.9
shaped = [r + gamma * potential[t+1] - potential[t] for t, r in enumerate(rewards)]
original_return = sum(gamma ** t * r for t, r in enumerate(rewards))
shaped_return = sum(gamma ** t * r for t, r in enumerate(shaped))
print(f"original={original_return:.3f}, shaped={shaped_return:.3f}, difference={shaped_return-original_return:.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 塑形项依次为 0.9×(−1)−(−2)=1.1 与 0−(−1)=1。
- 新奖励为 1.1、2，折扣回报为 2.9。
- 原回报为 0.9，差值为 2，正好等于 −Φ(s0)。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
original=0.900, shaped=2.900, difference=2.000
```
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 任意距离奖励都声称保持原最优策略。
- 把低平均违规率当作每条轨迹零违规保证。
- 训练只见少量扰动却声称抵御任意环境变化。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 任意距离奖励都声称保持原最优策略。
- 把低平均违规率当作每条轨迹零违规保证。
- 训练只见少量扰动却声称抵御任意环境变化。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::
