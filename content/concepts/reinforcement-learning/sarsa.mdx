## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
强化学习面对序贯决策：动作会改变之后能看到的状态和奖励，因此样本通常并非独立同分布。

同一算法的效果取决于环境、探索策略、函数近似、随机种子和评测协议，单次曲线不足以下结论。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
SARSA 名称来自 S,A,R,S′,A′ 五个更新元素。

本页使用“问题定义—数学目标—更新过程—代码—失败诊断”的顺序组织，避免只记算法缩写。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
它评价“我实际会继续探索”的策略，因此会把探索跌落悬崖的风险算进去。

把价值看作“未来累计收益的估计”，把策略看作“在状态下如何选动作的规则”；算法差异主要在估计谁、使用谁生成的数据以及如何更新。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
下一动作来自当前行为策略。

epsilon-greedy 会直接影响目标。

Cliff Walking 中常比 Q-Learning 更保守。
:::


## 数学表达 {#formulas}

::::formula{index="0"}

### SARSA 更新
:::

:::field{path="formulas.0.expression" type="math"}
$$
Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)]
$$
:::

:::field{path="formulas.0.description" type="text"}
目标包含实际下一动作。

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### SARSA 与 Cliff Walking的最小计算
:::

:::field{path="numericalExample.given" type="list"}
- 即时奖励为 1
- 下一状态估计为 2
- 折扣因子 γ=0.9
- 当前估计为 0.5
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 计算 bootstrap 目标：1+0.9×2=2.8。
2. 目标与当前估计差为 2.8−0.5=2.3。
3. 若学习率 α=0.1，新估计为 0.5+0.1×2.3=0.73。
:::

:::field{path="numericalExample.result" type="text"}
一次更新后估计从 0.5 变为 0.73；是否收敛需要持续采样与满足相应条件。
:::

:::field{path="numericalExample.comparison" type="list"}
- 较大 α 更新快但噪声和震荡更强。
- 较大 γ 更重视远期奖励，但误差传播范围更长。
- 使用真实回报与 bootstrap 目标会带来不同偏差—方差权衡。
:::

## 代码实现 {#code}

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### SARSA：同一行为策略生成动作并参与目标
:::

:::field{path="codeExamples.0.language" type="text"}
NumPy
:::

:::field{path="codeExamples.0.purpose" type="text"}
展示 S,A,R,S′,A′ 五元组与 on-policy 更新。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```NumPy
import numpy as np

rng = np.random.default_rng(7)
Q = np.zeros((6, 2))
alpha, gamma, epsilon = 0.2, 0.95, 0.2

def choose(state):
    return rng.integers(2) if rng.random() < epsilon else int(np.argmax(Q[state]))

def step(state, action):
    next_state = np.clip(state + (-1 if action == 0 else 1), 0, 5)
    return next_state, (1.0 if next_state == 5 else -0.01), next_state == 5

for episode in range(300):
    state, action = 0, choose(0)
    for _ in range(30):
        next_state, reward, done = step(state, action)
        next_action = choose(next_state)
        bootstrap = 0.0 if done else Q[next_state, next_action]
        Q[state, action] += alpha * (reward + gamma * bootstrap - Q[state, action])
        state, action = next_state, next_action
        if done:
            break

print(np.argmax(Q, axis=1))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 当前 action 与 next\_action 都来自同一 epsilon-greedy 行为策略。
- 目标使用 Q(S′,A′)，而非 max Q。
- 探索动作的风险会进入价值估计，因此 Cliff Walking 中往往更保守。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
非终止状态主要选择向右；在含悬崖风险的环境中通常学到离悬崖更远的路径。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 探索不足
- 目标漂移
- 函数近似不稳定
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。

:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
