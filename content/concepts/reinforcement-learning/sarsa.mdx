## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
悬崖边的最短路线在完全贪心执行时很快，但带随机探索的智能体可能踩空。SARSA 评价的后续行为包含探索，因此会考虑当前行为策略在危险区域的代价；这与只评价理想贪心未来的目标不同。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
SARSA 使用当前状态、动作、奖励、下一状态和下一动作五项更新动作价值。下一动作由当前行为策略采样，并且非终止时应成为真正执行的下一动作。因此标准 SARSA 是 on-policy 控制。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
不是问“接下来如果永远不犯探索错误会怎样”，而是问“照我当前会探索的行动方式继续会怎样”。这种区别只有在后续策略包含随机性时才特别明显。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
先在状态 s 执行动作 a，再在 s′ 按同一行为策略选 a′，用 Q(s′,a′) 构造目标。若更新时采样一个 a′，执行时却重新抽另一个动作，代码已经偏离标准五元组更新语义。

ε-greedy 中 ε 改变了未来动作分布，也就改变 SARSA 评价的策略。维持固定 ε 时学习的是带探索策略；满足其他条件并逐渐变得贪心的方案才可讨论相应的最优控制收敛结论。

SARSA 的下一动作采样增加目标方差。Expected SARSA 对这些动作求策略期望，Q-learning 则换成最大值；三者只差一个目标项，但评价对象和学习行为可能不同。
:::

::::code-example{index="0"}
:::field{path="codeExamples.0.title" type="text"}
### SARSA：同一行为策略生成动作并参与目标
:::

:::field{path="codeExamples.0.language" type="text"}
NumPy
:::

:::field{path="codeExamples.0.purpose" type="text"}
展示 S,A,R,S′,A′ 五元组与 on-policy 更新。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```NumPy
import numpy as np

rng = np.random.default_rng(7)
Q = np.zeros((6, 2))
alpha, gamma, epsilon = 0.2, 0.95, 0.2

def choose(state):
    return rng.integers(2) if rng.random() < epsilon else int(np.argmax(Q[state]))

def step(state, action):
    next_state = np.clip(state + (-1 if action == 0 else 1), 0, 5)
    return next_state, (1.0 if next_state == 5 else -0.01), next_state == 5

for episode in range(300):
    state, action = 0, choose(0)
    for _ in range(30):
        next_state, reward, done = step(state, action)
        next_action = choose(next_state)
        bootstrap = 0.0 if done else Q[next_state, next_action]
        Q[state, action] += alpha * (reward + gamma * bootstrap - Q[state, action])
        state, action = next_state, next_action
        if done:
            break

print(np.argmax(Q, axis=1))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 当前 action 与 next\_action 都来自同一 epsilon-greedy 行为策略。
- 目标使用 Q(S′,A′)，而非 max Q。
- 探索动作的风险会进入价值估计，因此 Cliff Walking 中往往更保守。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 目标里用最大 Q，却仍称为 SARSA。
- 更新使用的下一动作与随后实际执行动作不一致。
- 把悬崖示例的保守行为推广为任何环境都更安全。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 目标里用最大 Q，却仍称为 SARSA。

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### SARSA 总是比 Q-learning 安全吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是。它考虑当前行为策略的探索后果，但没有硬安全保证；是否避开风险还取决于奖励、探索方式、状态表示和训练证据。
:::
