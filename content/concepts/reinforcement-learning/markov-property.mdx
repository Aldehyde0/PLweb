## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
球在相同位置，向左运动和向右运动会到达不同下一位置。只用位置作为状态，历史轨迹仍能提供速度信息；这说明表示不充分，而不是说物理系统不能用状态建模。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
马尔可夫性质要求：给定当前状态与动作后，更早的历史不再改变下一状态及奖励的条件分布。它是关于所选状态表示与任务动力学的条件独立假设，不是下一步必然确定，也不是当前状态与过去完全无关。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
位置与速度一起像一份足够完整的快照。只看一张位置照片可能无法预测下一秒；再看上一帧能估计速度，说明照片里漏了决策所需的变量。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
状态可以概括历史，例如累计库存、剩余时间或对隐藏变量的后验分布。关键是压缩后是否保留预测所需信息，而非强行只用传感器当前读数。

环境即使满足马尔可夫性质，也可以有随机转移：同一状态与动作可能以固定概率到多个后继。性质要求这些概率在给定状态后不再依赖更早历史，不能把马尔可夫性误写成确定性。

在真实任务中无法靠少量样本严格证明状态充分。可以比较加入历史前后的预测误差，寻找状态混叠；帧堆叠、循环网络和 belief state 是补救方式，但有限记忆不保证解决所有部分可观测问题。
:::

### 马尔可夫性质
:::

:::field{path="formulas.0.expression" type="math"}
$$
p(s_{t+1}|s_t,a_t,s_{t-1},\ldots)=p(s_{t+1}|s_t,a_t)
$$
:::

:::field{path="formulas.0.description" type="text"}
历史在给定当前状态动作后不再提供额外转移信息。

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 相同位置、不同速度的状态混叠
:::

:::field{path="numericalExample.given" type="list"}
- 简化运动为下一位置等于当前位置加上速度；这里时间步长为 1，速度在一步内不变。
- 两个历史都到位置 0，但当前速度分别是 +1 与 −1。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 若状态只记位置 0，两个样本会被合并。
2. 加上速度后，后继位置分别为 1 与 −1。
3. 更早一帧可揭示速度，因此位置表示还不充分。
:::

:::field{path="numericalExample.result" type="text"}
位置同为 0 的两段历史得到不同后继；加入速度可区分它们。
:::

:::field{path="numericalExample.comparison" type="list"}
- 预测分布需要历史信息时，应检查状态遗漏。
- 本例用确定性运动说明混叠；随机系统也可以满足马尔可夫性。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把随机转移当成违反马尔可夫性质。
- 只给位置却忽略速度、计时或隐藏模式。
- 认为加一个 RNN 就严格恢复了真实状态。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 马尔可夫性质意味着历史没有用吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
历史可以用于构造充分状态；性质只说在已经给出充分状态后，额外历史不再改变下一步条件分布。
:::
