## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
同一个路口可以按不同路线策略继续行驶，长期收益也就不同。只说“这个路口价值 5”缺少策略与时间范围；价值不是状态固有的标签，而是对某种后续行为的条件期望。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
状态价值 Vπ(s) 是从状态 s 开始、之后按策略 π 行动的期望回报。动作价值 Qπ(s,a) 先固定第一步动作 a，此后仍按 π 行动。一次轨迹的回报是随机样本，价值函数则对相应未来随机性求期望。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
V 像评价“到这个路口后照现有习惯走有多好”，Q 像评价“先向右，再照现有习惯走有多好”。评价已有习惯与寻找最优路线是不同问题。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
离散策略下，Vπ 是各动作 Qπ 按 π 加权的平均，而不是最大值。只有切换到贪心改进或讨论最优价值时，最大值才进入相应表达式。

仅有 V 通常不能直接比较动作，还需要环境模型预测后继，或由 actor 给动作。Q 为每个动作提供比较分数，但连续动作的最大化可能需要额外优化，不能简单枚举。

估计误差与数据覆盖会影响动作排序。高 Q 可能是真高回报，也可能是模型在缺乏证据动作上的乐观误差；价值预测应结合固定策略评估与独立数据诊断。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 同一 Q 下，策略平均与贪心价值不同
:::

:::field{path="numericalExample.given" type="list"}
- 两动作价值为 2 与 6。
- 当前策略概率为 0.75 与 0.25。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 按当前策略求状态价值：0.75×2+0.25×6=3。
2. 贪心选择第二动作，其动作价值是 6。
3. 改变策略后长期 Q 也可能变化；本次只比较给定 Q 的一步策略改进。
:::

:::field{path="numericalExample.result" type="text"}
当前策略价值是 3，给定 Q 的贪心动作价值是 6。
:::

:::field{path="numericalExample.comparison" type="list"}
- Vπ 是策略加权平均，不是 max Qπ。
- 策略改进后需要重新评价，不能永远沿用旧策略的全部价值。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 Vπ 写成所有动作 Q 的最大值。
- 比较不同策略或折扣下的数值，却没有对齐定义。
- 用单次幸运回报宣称价值估计已经准确。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把 Vπ 写成所有动作 Q 的最大值。
- 比较不同策略或折扣下的数值，却没有对齐定义。

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 价值高就是动作一定好吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
价值是特定策略、状态和奖励定义下的期望估计，还包含采样与逼近误差；不能替代安全约束或对分布外动作的证据。
:::
