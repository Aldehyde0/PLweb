## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
两个真实价值相近的动作，各有带噪声的估计。选择最大估计会更容易挑中被噪声抬高的那个，因此平均噪声为零也不保证最大值估计无偏。Double Q 通过两个估计器减少这种选择与评价的耦合。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
表格 Double Q-learning 维护 QA 和 QB，随机选择其中一个更新。更新 QA 时用 QA 选择下一动作，再由 QB 评价；更新 QB 时反过来。行为可以基于两表的和或平均进行 ε-greedy 探索。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
一位评委提名，另一位评委评分，避免同一个人的偶然高估既决定候选又决定最终分数。不过两位评委若犯相似错误，仍可能保留偏差。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
核心是交叉评价，不是简单把两个最大值平均。先确定本次更新哪一张表，用该表的 argmax 选动作，然后查询另一张表同一动作的价值。

分离估计可以缓解正向最大化偏差，但不保证任何时候都比单表更准确。两个估计的相关性、数据覆盖和有限采样会影响效果，某些情形还可能出现低估。

两张表在开始时可相同，但后续更新路径不同。终止标记、学习率和探索仍需正确；Double Q 不会自动解决没有成功样本、非马尔可夫状态或错误奖励的问题。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 提名动作与评价动作分开
:::

:::field{path="numericalExample.given" type="list"}
- 下一状态 QA=[5,4]，QB=[1,3]。
- 本次更新 QA，奖励 0，折扣 0.9。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. QA 选出动作 0。
2. 用 QB 评价动作 0，得到 1；目标为 0.9。
3. 若误用 max QA，目标为 4.5；若用 max QB，目标为 2.7，都不是本次 Double Q 目标。
:::

:::field{path="numericalExample.result" type="text"}
选择动作 0，交叉评价后的目标为 0.900。
:::

:::field{path="numericalExample.comparison" type="list"}
- Double Q 是选择与评价分离，不是最大值平均。
- Double DQN 用在线网络与延迟目标网络实现相似思想，但更新结构不同。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 对 QA 和 QB 各取最大值再平均，误称交叉评价。
- 用 QB 选择动作后又用 QB 评价本应更新 QA 的目标。
- 把缓解过估计说成完全消除所有价值偏差。
:::

:::field{path="failureModes" type="list"}

:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### Double Q 和两个 critic 取最小值一样吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是。Double Q 强调选动作与评价分离；TD3 等方法用双 critic 的最小值构造保守目标，目的相关但具体算子不同。
:::
