## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
机械臂动作是连续力矩，直接枚举所有动作不现实；而在不完全信息游戏中，随机行动本身也可能必要。直接输出动作分布的策略网络，可以表达这些控制方式，并按回报改善分布参数。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
策略方法直接学习带参数的随机策略 πθ 或确定性动作映射 μθ。策略可由 logits、Gaussian 均值与尺度等表示；学习目标是提高期望回报。critic 可以辅助估计梯度信号，所以“policy-based”与“actor-critic”不是互斥概念。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
价值方法像先给所有菜评分再点菜，策略方法像直接调整点单偏好。偏好参数本身不是概率，必须经 softmax 等变换形成满足约束的分布。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
离散策略通常用 softmax 把 logits 转为概率；所有 logits 加上同一常数不改变分布。连续策略需明确密度、动作边界与变换修正，简单截断动作会影响概率计算。

策略梯度利用被采样动作的对数概率导数乘以回报或优势。好于预期的动作概率上升，差于预期的动作概率下降；并不是让所有高原始奖励动作一律上升。

随机梯度方差可能很大，因此使用基线、critic 和批量采样。策略直接更新也可能过快失去探索，通常要监测熵、概率比率和 KL；这些诊断不保证得到全局最优。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 离散 softmax 策略
:::

:::field{path="formulas.0.expression" type="math"}
$$
\pi_\theta(a\mid s)=\frac{e^{z_\theta(s,a)}}{\sum_b e^{z_\theta(s,b)}}
$$
:::

:::field{path="formulas.0.description" type="text"}
logits 的相对差异决定动作分布，稳定实现会先减去最大 logit。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 相同偏移不改变 softmax 策略
:::

:::field{path="numericalExample.given" type="list"}
- 两动作 logits 为 0 与 log 3。
- 给两个 logits 同时加 5。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 指数比例为 1∶3，归一化概率为 0.25 和 0.75。
2. 共同平移会给分子分母乘同一常数，概率不变。
3. 只有相对 logits 改变才影响离散策略。
:::

:::field{path="numericalExample.result" type="text"}
原 logits 和共同平移后的概率均为 0.2500、0.7500。
:::

:::field{path="numericalExample.comparison" type="list"}
- 策略参数不是动作价值。
- 给所有 logits 同时加常数不能提高任何动作的相对概率。
:::

### 相同偏移不改变 softmax 策略
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
原 logits 和共同平移后的概率均为 0.2500、0.7500。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import math
def softmax(logits):
    maximum = max(logits)
    weights = [math.exp(x - maximum) for x in logits]
    return [x / sum(weights) for x in weights]
for shift in [0.0, 5.0]:
    probs = softmax([shift, math.log(3) + shift])
    print("probabilities=" + ",".join(f"{p:.4f}" for p in probs))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 指数比例为 1∶3，归一化概率为 0.25 和 0.75。
- 共同平移会给分子分母乘同一常数，概率不变。
- 只有相对 logits 改变才影响离散策略。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 logits 当作已经归一化的动作概率。
- 把动作裁剪后仍用裁剪前密度当真实动作概率。
- 认为直接优化策略就不需要价值估计或探索诊断。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把 logits 当作已经归一化的动作概率。
- 把动作裁剪后仍用裁剪前密度当真实动作概率。
- 认为直接优化策略就不需要价值估计或探索诊断。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::

### 有 actor 就一定是 on-policy 吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是。PPO 常按 on-policy 数据组织，DDPG、TD3、SAC 则使用 replay 做 off-policy actor-critic 学习。
