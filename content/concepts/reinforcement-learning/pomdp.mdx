## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
机器人隔着噪声传感器判断门是否开启，读数为“开”并不保证门真的开。若按一次读数立即冲过去，策略可能忽略传感器可靠性和先前观察；部分可观测模型让这种不确定性进入决策。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
POMDP 在状态、动作、转移与奖励之外加入观测及观测模型。智能体只能通过历史动作和观察推断隐藏状态。belief 是各隐藏状态的条件概率分布；在已知模型下，更新后的 belief 可以作为决策所需的信息状态。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
医生收到阳性检测，要结合先验患病率与检测误报率更新判断。检测结果是观察，真实是否患病是隐藏状态；重复检查还可能是为了获得信息而采取的动作。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
belief 更新先用动作转移模型预测下一隐藏状态分布，再乘以新观察在各状态下的似然，最后归一化。忘记转移预测或归一化，都会把不完整证据误当确定状态。

控制动作可能同时改变物理状态与未来信息，例如绕到另一个角度看障碍。只将最可能状态代入完全可观测控制器会丢掉不确定性，可能选择需要更多确信才安全的动作。

精确 belief 的维度随状态空间增长，已知观测模型也常不现实。粒子滤波、循环策略或有限历史是近似方法；它们的估计质量与训练分布、记忆长度和模型误差有关。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 静态隐藏状态的 Bayes 更新
:::

:::field{path="formulas.0.expression" type="math"}
$$
b(s\mid o)=\frac{p(o\mid s)b(s)}{\sum_{\tilde s}p(o\mid\tilde s)b(\tilde s)}
$$
:::

:::field{path="formulas.0.description" type="text"}
本式为没有状态变化的特例；一般 POMDP 需先按动作预测隐藏状态。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 用带噪声观察更新门开启的概率
:::

:::field{path="numericalExample.given" type="list"}
- 门开启先验概率 0.3。
- 开门时报告“开”的概率 0.8，关门时误报概率 0.2。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. “开且报告开”的质量是 0.3×0.8=0.24。
2. 报告开的总质量为 0.24+0.7×0.2=0.38。
3. 后验开门概率为 0.24/0.38≈0.631579。
:::

:::field{path="numericalExample.result" type="text"}
看到“开”后，belief 从 0.3 升至约 0.6316，而不是变成 1。
:::

:::field{path="numericalExample.comparison" type="list"}
- 后验结合先验与似然，不能只使用检测准确率。
- 本例无状态变化；有动作转移时要先做预测步骤。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
prior_open = 0.3
open_mass = prior_open * 0.8
closed_mass = (1 - prior_open) * 0.2
posterior_open = open_mass / (open_mass + closed_mass)
print(f"posterior_open={posterior_open:.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- “开且报告开”的质量是 0.3×0.8=0.24。
- 报告开的总质量为 0.24+0.7×0.2=0.38。
- 后验开门概率为 0.24/0.38≈0.631579。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### belief 是真实状态吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
它是对真实状态的概率估计。正确模型下它概括观测历史，但仍保留不确定性，不能当作已经观察到的真值。
:::
