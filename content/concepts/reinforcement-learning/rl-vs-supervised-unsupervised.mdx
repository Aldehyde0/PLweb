## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
同一个商店问题可以有不同建模方式：预测用户是否点击属于监督任务，按行为聚类属于无监督任务，连续调价影响库存和未来需求则可能需要序贯决策。问题的时间结构与反馈方式，比“是否使用神经网络”更能决定范式。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
监督学习利用输入与目标标签学习映射；无监督学习从未标注数据中发现结构或学习表示。强化学习学习行动策略，收到的是动作后果的评价，通常没有每一步最优动作的标准答案。三者可以组合，例如先无监督学习表示，再用强化学习优化控制。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
老师指出“这一题答案是 B”相当于标签；只给一组没有答案的试卷可用于发现题型；让你选择复习顺序，最后用考试结果评价计划，则出现行动、延迟反馈和归因问题。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
分类标签直接约束单个输入的预测。奖励 1 只表示某次后果按评分规则较好，无法说明所有未选动作会得多少分；把奖励当成正确动作标签会丢掉反事实信息缺失。

如果每次决策互不影响未来状态，问题可能是上下文老虎机。若今天的调价改变明天库存，就需要对后续机会建模；这是从单次反馈走向完整强化学习的关键。

离线强化学习虽用固定数据，仍通过策略改进询问“采取不同动作会怎样”。行为克隆则直接拟合历史动作；两者都能使用监督式损失，但目标和覆盖风险不同。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 预测损失与策略目标
:::

:::field{path="formulas.0.expression" type="math"}
$$
\mathcal L_{sup}=\frac1n\sum_i\ell(f_\theta(x_i),y_i),\qquad J_{RL}(\pi)=\mathbb E_{\tau\sim\pi}\left[\sum_t\gamma^t r_{t+1}\right]
$$
:::

:::field{path="formulas.0.description" type="text"}
监督目标基于标签损失；RL 目标基于策略诱导轨迹的回报。无监督目标依具体表示、密度或聚类任务定义。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 动作模仿准确率不能代替策略价值
:::

:::field{path="numericalExample.given" type="list"}
- 历史标签为左、左、左、右。
- 始终向左准确率为 75%；构造环境中左得 1，右得 2，动作后均结束。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 模仿历史最常见动作会选择左。
2. 该策略回报是 1；始终右的回报是 2。
3. 本例结束后无后续状态影响，更准确地说是单步决策示例。
:::

:::field{path="numericalExample.result" type="text"}
监督模仿准确率 0.75 与奖励最优动作“右”回答不同问题。
:::

:::field{path="numericalExample.comparison" type="list"}
- 行为标签的频率不等于动作收益。
- 若不知道动作收益，不能仅凭这四个标签得出右更优。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}

```Python
labels = ["left", "left", "left", "right"]
accuracy = sum(a == "left" for a in labels) / len(labels)
rewards = {"left": 1.0, "right": 2.0}
print(f"imitate_accuracy={accuracy:.2f}")
print("reward_best=" + max(rewards, key=rewards.get))
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把所有带奖励的预测问题都叫强化学习。
- 看到离线数据就认定任务只能属于监督学习。
- 用历史动作准确率代替新策略的长期回报评价。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把所有带奖励的预测问题都叫强化学习。
- 看到离线数据就认定任务只能属于监督学习。
- 用历史动作准确率代替新策略的长期回报评价。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 监督学习能用于强化学习内部吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
可以。价值回归、环境模型和奖励模型常用监督损失，但最终策略仍按序贯决策目标与数据边界评价。
:::
