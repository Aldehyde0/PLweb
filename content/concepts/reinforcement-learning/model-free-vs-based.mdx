## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
机器人可以直接从试错学习哪个动作价值更高，也可以先学习“推一下会移动多远”，再在预测模型里比较动作。后者可能节省真实试验，但错误模型会把规划引向不存在的捷径。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
model-free 方法直接学习价值、策略或其组合，不要求显式的环境转移模型。model-based 方法利用已知或学习到的动力学与奖励模型进行规划、产生模拟数据或构造训练目标。是否使用神经网络、是否有 critic，都不能单独决定归属。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
直接学会熟练骑车是一种经验控制；在脑中预测“向左打把后车会怎么走”再选择动作类似模型规划。两种能力可以同时存在，并非互斥的身份标签。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
环境模型可以预测下一状态分布、潜在状态或奖励；价值函数预测的是未来累计收益。一个 critic 并不因此成为 world model，二者预测对象和使用方式不同。

规划会反复查询模型，也会搜索模型最乐观的区域。因此训练集单步预测误差小，未必保证规划后策略好；长 rollout 中误差累积，分布外查询可能尤其严重。

Dyna 类方法混用真实与模型生成数据，MPC 每一步执行短期计划的首个动作再重规划。它们能提高部分任务的样本利用率，但要付出模型训练、规划计算与模型偏差的代价。
:::

### 确定性动力学模型的预测示例
:::

:::field{path="formulas.0.expression" type="math"}
$$
\hat s_{t+1}=f_\psi(s_t,a_t),\qquad \mathcal L_{model}=\mathbb E_{\mathcal D}\lVert f_\psi(s,a)-s\prime\rVert^2
$$
:::

:::field{path="formulas.0.description" type="text"}
这是连续状态确定性均值模型的教学目标；随机动力学可需要概率模型，价值函数不等于下一状态模型。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 微小一步误差如何随预测长度积累
:::

:::field{path="numericalExample.given" type="list"}
- 真实系统为下一位置等于当前位置加动作。
- 模型每一步额外高估 0.1，连续施加三次动作 1。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 真实预测序列是 1、2、3。
2. 模型预测序列是 1.1、2.2、3.3。
3. 三步误差达到 0.3；非线性系统可能更复杂。
:::

:::field{path="numericalExample.result" type="text"}
构造线性例中，单步偏差 0.1 累积为三步位置误差 0.3。
:::

:::field{path="numericalExample.comparison" type="list"}
- 模型能减少真实采样，但预测误差会影响规划。
- 本例是线性累加，不是所有系统误差增长率的通用公式。
:::

```Python
true_state = model_state = 0.0
for step in range(1, 4):
    true_state += 1.0
    model_state += 1.1
    print(f"step={step} true={true_state:.1f} model={model_state:.1f} error={model_state-true_state:.1f}")
```
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把所有神经网络控制器都称为 model-free。
- 把价值网络误认成预测下一状态的动力学模型。
- 只评估单步模型误差，不验证规划产生的状态分布。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把所有神经网络控制器都称为 model-free。
- 把价值网络误认成预测下一状态的动力学模型。

:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。

:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 学到了世界模型就一定更省样本吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不一定。优势取决于模型能否在策略查询区域准确预测、规划预算是否足够，以及训练模型所需的数据成本。
:::
