## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
均匀 replay 可能反复抽到已很容易预测的转移，却很少抽到重要的新错误。PER 根据优先级调整抽样概率，让高残差转移更常出现；但训练分布也随之改变，不能无视采样偏差。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
比例式 PER 通常令优先级为绝对 TD error 加小正数，再取指数 α 形成采样概率。训练损失使用与采样概率相关的重要性权重，β 控制修正程度。优先级需在重新计算误差后刷新，避免永远沿用过时判断。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
错题本会多练常错题，但如果只练噪声很大的错题，可能忽略整体题目分布。重要性权重减少高频题对总体目标的过度支配。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
α=0 对应均匀抽样；α 越大越集中于高优先级样本。小正数保证低误差样本仍有机会被抽到，不能把当前残差小误解成永远不需要学习。

若目标仍是均匀数据平均，理想单样本修正包含 1/(N P(i))；常用 β 次幂及批内或全缓冲归一化控制尺度。β 小于 1 时是部分修正，不应声称严格消除了偏差。

高 TD error 可能来自真正新信息，也可能来自奖励噪声、异常记录或永远不可预测的转移。只追残差会过度抽样噪声，需检查优先级分布、有效样本量和覆盖。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### 比例式 PER
:::

:::field{path="formulas.0.expression" type="math"}
$$
P(i)=\frac{p_i^\alpha}{\sum_jp_j^\alpha},\qquad w_i=(N P(i))^{-\beta}
$$
:::

:::field{path="formulas.0.description" type="text"}
常用 p 为绝对 TD error 加 ε；实际还可能归一化 w。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 优先采样概率与逆概率权重
:::

:::field{path="numericalExample.given" type="list"}
- 两个样本优先级为 1、3，α=1。
- 缓冲大小 N=2，β=1；本例不做最大值归一化。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 采样概率为 0.25、0.75。
2. 重要性权重为 1/(2×0.25)=2 与 1/(2×0.75)=2/3。
3. 加权后的期望贡献概率均为 0.5。
:::

:::field{path="numericalExample.result" type="text"}
样本概率为 0.250、0.750，权重为 2.000、0.667。
:::

:::field{path="numericalExample.comparison" type="list"}
- 权重校正采样分布，并不消除 TD 目标本身的估计误差。
- 实际实现常归一化权重，损失整体尺度会随之变化。
:::

### 优先采样概率与逆概率权重
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
样本概率为 0.250、0.750，权重为 2.000、0.667。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
priority = [1.0, 3.0]
probabilities = [p / sum(priority) for p in priority]
weights = [1 / (len(priority) * p) for p in probabilities]
for p, weight in zip(probabilities, weights):
    print(f"P={p:.3f}, weight={weight:.3f}, contribution={p*weight:.3f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 采样概率为 0.25、0.75。
- 重要性权重为 1/(2×0.25)=2 与 1/(2×0.75)=2/3。
- 加权后的期望贡献概率均为 0.5。
:::

P=0.750, weight=0.667, contribution=0.500

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 使用优先采样，却仍宣称训练等价于均匀平均。
- 抽样后不刷新优先级，长期追逐陈旧残差。
- 把高残差直接当作有益学习价值或高回报。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### PER 总能提升样本效率吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不保证。若高残差主要是不可约噪声或异常数据，优先采样会浪费预算；还需要考虑优先级维护和树结构采样的开销。
:::
