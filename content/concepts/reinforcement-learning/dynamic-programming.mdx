## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
小型调度问题中，所有转移概率和成本可能已经给定。此时不必先通过随机试验估计每一步结果，可以直接枚举后继状态并计算期望；这正是动态规划成为强化学习基准和概念起点的原因。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
动态规划在已知转移与奖励模型下，对价值函数反复应用 Bellman 备份。策略迭代交替做给定策略的评价和贪心改进；价值迭代直接应用最优备份。它不是从固定轨迹直接求平均，也不要求训练一个神经网络。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
如果有完整路线图和每段路的通行概率，可以在地图上反复更新“从这里出发还要花多少成本”，不必真的把每条路线都走一遍。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
策略评价对动作按当前策略加权，并对各后继按模型概率加权。策略改进比较动作价值后改变策略；混用两个步骤会把“评价旧策略”误写成“寻找最优策略”。

同步备份用同一份旧价值计算所有新值，原地异步备份立即使用刚更新的值。它们在适当条件下可以接近同一固定点，但每轮中间数值不同，手算与代码必须说明更新顺序。

有限折扣 MDP 的 Bellman 最优算子具有压缩性质，可支持相应收敛结论；不折扣持续任务、近似模型和任意非线性逼近需要额外条件。全状态与动作扫描也会遇到维数灾难。
:::


## 数学表达 {#formulas}

::::formula{index="0"}
:::field{path="formulas.0.label" type="text"}
### Bellman 最优备份
:::

:::field{path="formulas.0.expression" type="math"}
$$
V_{k+1}(s)=\max_a\sum_{s\prime,r}p(s\prime,r\mid s,a)[r+\gamma V_k(s\prime)]
$$
:::

:::field{path="formulas.0.description" type="text"}
在终止状态未来价值设为零；本式展示同步价值迭代。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 随机后继下的一次最优备份
:::

:::field{path="numericalExample.given" type="list"}
- 动作 stop 立即得 2 并终止。
- 动作 try 奖励为 0，以 0.5 到达价值 4 的状态，以 0.5 到达价值 0 的状态；折扣 0.9。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 先求 try 的后继价值期望：0.5×4+0.5×0=2。
2. try 的备份值为 0+0.9×2=1.8。
3. 比较 stop=2 与 try=1.8，选择 stop。
:::

:::field{path="numericalExample.result" type="text"}
一次最优备份得到 V(s)=2.000，贪心动作为 stop。
:::

:::field{path="numericalExample.comparison" type="list"}
- 必须对随机后继求期望，不能只挑最好后继。
- 有限一次备份并不代表全部状态已达到固定点。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
gamma = 0.9
q = {"stop": 2.0, "try": gamma * (0.5 * 4.0 + 0.5 * 0.0)}
print(f"Q_stop={q['stop']:.3f}, Q_try={q['try']:.3f}")
print("best=" + max(q, key=q.get))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 先求 try 的后继价值期望：0.5×4+0.5×0=2。
- try 的备份值为 0+0.9×2=1.8。
- 比较 stop=2 与 try=1.8，选择 stop。
:::

:::field{path="codeExamples.0.expectedOutput" type="text"}
```text
Q_stop=2.000, Q_try=1.800
best=stop
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 模型未知时仍声称做了精确 Bellman 期望。
- 手算用同步更新，代码却原地更新而不说明。
- 把折扣有限表格结论推广到任意函数逼近。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 模型未知时仍声称做了精确 Bellman 期望。

- 奖励函数与真实目标不一致会诱发奖励黑客。

## 常见问题 {#common-questions}

### 动态规划是否需要环境交互数据？
:::

:::field{path="commonQuestions.0.answer" type="text"}
若模型完全已知，可以直接规划；若模型由数据估计，规划虽仍可执行，但误差与收敛结论须考虑估计模型的可靠性。
