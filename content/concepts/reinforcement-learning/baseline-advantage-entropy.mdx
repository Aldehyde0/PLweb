## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
一个任务里所有轨迹奖励都很大，但动作之间只差一点。直接乘原始回报会使梯度波动很强；同时策略过早只选一个动作可能失去探索。baseline、advantage 与 entropy 针对的是不同现象。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
基线是从回报信号中减去的参考量，典型选择是状态价值；优势 Aπ(s,a)=Qπ(s,a)−Vπ(s) 表示动作相对当前策略平均的好坏。熵衡量动作分布的分散程度，作为奖励或正则鼓励保持多样性。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
考试总分由题目难度共同影响，比较“比该题平均水平高多少”比只比较原始分数更有针对性。熵则像避免班级所有人过早只押一种答题方式，与扣除平均分是两回事。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
理想条件下，减去不依赖当前动作的基线不改变 score-function 梯度期望，但可以改变方差。学习出来的基线不一定降低每一批方差；若错误地加入动作依赖或让 actor 路径穿过目标，需重新分析。

优势不是概率，也不要求每个采样批次均值恰好为零。理论上的策略加权优势期望为零；经验标准化是数值处理，会改变有限批次尺度，不等于真实优势被准确估计。

离散分布均匀时熵最大，确定策略熵为零。较大的熵系数会鼓励分散，也可能让策略持续执行低收益动作；熵更高不能直接解读为探索到了有价值的新区域。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 优势的策略平均为零，熵则描述分散程度
:::

:::field{path="numericalExample.given" type="list"}
- 动作概率为 0.25、0.75，Q 为 2、6。
- 状态价值按该策略计算为 5，使用自然对数。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 优势为 −3 与 1。
2. 策略加权均值为 0.25×(−3)+0.75×1=0。
3. 熵为 −0.25 ln0.25−0.75 ln0.75≈0.562335。
:::

:::field{path="numericalExample.result" type="text"}
优势为 −3、1，加权平均为零；该分布熵为 0.562335 nats。
:::

:::field{path="numericalExample.comparison" type="list"}
- 优势描述相对价值，熵只描述概率分布。
- 非均匀策略下，优势的简单算术均值未必为零。
:::

### 优势的策略平均为零，熵则描述分散程度
:::

:::field{path="codeExamples.0.language" type="text"}
Python
:::

:::field{path="codeExamples.0.purpose" type="text"}
优势为 −3、1，加权平均为零；该分布熵为 0.562335 nats。
:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
import math
probabilities, q = [0.25, 0.75], [2.0, 6.0]
value = sum(p * x for p, x in zip(probabilities, q))
advantage = [x - value for x in q]
weighted = sum(p * a for p, a in zip(probabilities, advantage))
entropy = -sum(p * math.log(p) for p in probabilities)
print(f"advantages={advantage}, weighted_mean={weighted:.6f}")
print(f"entropy={entropy:.6f}")
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- 优势为 −3 与 1。
- 策略加权均值为 0.25×(−3)+0.75×1=0。
- 熵为 −0.25 ln0.25−0.75 ln0.75≈0.562335。
:::

```text
entropy=0.562335
```

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 使用动作依赖基线却不考虑梯度偏差。
- 把标准化后的零均值当作 critic 已经准确。
- 把熵系数增大视为无条件的性能改进。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### 熵奖励和奖励塑形一样吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
两者都可能改变优化目标，但熵依赖策略分布，主要调节随机性；势函数塑形依赖状态势差，并在特定条件下保持原任务最优策略。
:::
