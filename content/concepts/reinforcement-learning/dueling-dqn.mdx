## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
驾驶游戏中，道路前方是否有障碍会影响所有动作的总体价值，左右轻微转向的差异可能很小。每个动作都单独学习这份共同信息效率不高，dueling 架构尝试共享状态层面的价值表示。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Dueling 网络在共享表示后分成状态价值 V 分支与动作优势 A 分支，再聚合得到各动作 Q。常见聚合为 V 加 A 减去动作优势均值。它改变网络参数化，不改变“采样转移、构造 TD 目标、拟合动作 Q”的基本训练任务。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
先判断“当前位置整体处境好不好”，再判断“各动作相对平均动作好多少”。减去均值让共同偏移不在两个分支之间任意搬动。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
如果仅写 Q=V+A，给 V 加常数并给所有 A 减同样常数，Q 完全不变，分解不可辨识。均值中心化把动作分支限制为零均值优势，使聚合有明确约定。

均值聚合下 V 等于各动作 Q 的算术平均，不必等于某个目标策略的 Vπ。网络优势分支是结构上的相对量，不能不加条件地称为已经准确估计的真实 Aπ。

Dueling 可以与 Double DQN、PER 等组合，但并不自动缓解离线分布外高估。动作差异很重要或表示本身不足时，结构改动也未必带来收益，应通过等预算消融判断。
:::

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 优势中心化和共同平移不变性
:::

:::field{path="numericalExample.given" type="list"}
- 状态分支 V=2，优势向量为 1、3。
- 聚合时减去优势均值 2。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. Q0=2+1−2=1，Q1=2+3−2=3。
2. 把两项优势各加 10，均值也加 10，Q 仍是 1、3。
3. 该结构只取优势间差异，不取共同偏移。
:::

:::field{path="numericalExample.result" type="text"}
原优势与平移后优势均聚合成 Q=[1.000,3.000]。
:::

:::field{path="numericalExample.comparison" type="list"}
- Dueling 改变表示结构，不是新的探索策略。
- Double DQN 改变目标中动作选择与评价的分工。
:::

:::

:::field{path="codeExamples.0.source" type="code" trailing="0"}
```Python
value = 2.0
for advantage in [[1.0, 3.0], [11.0, 13.0]]:
    average = sum(advantage) / len(advantage)
    q = [value + a - average for a in advantage]
    print("Q=" + ",".join(f"{x:.3f}" for x in q))
```
:::

:::field{path="codeExamples.0.explanation" type="list"}
- Q0=2+1−2=1，Q1=2+3−2=3。
- 把两项优势各加 10，均值也加 10，Q 仍是 1、3。
- 该结构只取优势间差异，不取共同偏移。
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 忘记减均值，使 V 与 A 的共同偏移任意。
- 把聚合的 V 分支一律解释为真实 Vπ。
- 将 dueling 架构与 Double DQN 的目标改动混为一谈。
:::

## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### Dueling 就是 Double DQN 吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是。Dueling 拆分网络表示，Double DQN 分离目标中的选择与评价；二者可以同时用于同一个 DQN 系统。
:::
