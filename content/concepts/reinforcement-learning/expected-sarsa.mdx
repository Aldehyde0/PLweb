:::field{path="learningObjectives" type="list"}

## 背景与问题 {#background}

:::field{path="background" type="paragraphs"}
SARSA 每次只用一个采样的下一动作，两个相同后继状态可能因探索抽样得到很不同的目标。当动作集合不大且策略概率已知时，可以直接平均这些可能的动作价值，保留策略含义并减少这部分随机性。
:::


## 概念定义 {#definition}

:::field{path="definition" type="paragraphs"}
Expected SARSA 使用目标策略在下一状态的动作价值期望作为 bootstrap。目标策略等于行为策略时是 on-policy；二者不同时可以构造 off-policy 形式，但仍需分析状态分布、支持和函数近似风险。
:::


## 直观理解 {#intuition}

:::field{path="intuition" type="paragraphs"}
与其掷一次骰子决定本次“未来评分”，不如把所有面按出现概率加权。环境下一状态的随机性仍存在，消掉的是给定后继后的下一动作抽样。
:::


## 核心原理 {#core-principle}

:::field{path="corePrinciple" type="paragraphs"}
实现时先获得目标策略概率向量，再与 Q(s′,·) 做内积。ε-greedy 的贪心动作也可能在随机分支被选中，概率必须包含这部分；并列最优动作的分配规则也会影响期望。

它既不等于对所有动作简单平均，也不总等于最大值。均匀策略才对应简单平均，确定贪心目标且唯一最优时才退化到最大值。

计算完整期望的成本随动作数量增加。连续动作常需解析期望或采样近似，此时所谓降低方差的优势要与近似成本一起衡量。终止后仍必须将后续价值清零。
:::

:::field{path="formulas.0.expression" type="math"}
$$
Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\sum_{a\prime}\pi(a\prime|s\prime)Q(s\prime,a\prime)-Q(s,a)]

## 完整数值示例 {#numerical-example}

:::field{path="numericalExample.title" type="text"}
### 按 ε-greedy 概率计算下一状态价值
:::

:::field{path="numericalExample.given" type="list"}
- 两个后继动作 Q 为 4 与 −2，ε=0.2。
- 唯一贪心动作概率 0.9，另一动作概率 0.1；奖励 0，折扣 0.9。
:::

:::field{path="numericalExample.steps" type="ordered"}
1. 下一状态的策略期望为 0.9×4+0.1×(−2)=3.4。
2. Expected SARSA 目标为 0.9×3.4=3.06。
3. 最大值目标是 3.6；单次抽中第二动作的 SARSA 目标是 −1.8。
:::

:::field{path="numericalExample.result" type="text"}
策略期望为 3.400，Expected SARSA 目标为 3.060。
:::

:::field{path="numericalExample.comparison" type="list"}
- 这是对下一动作的期望，不是对后继状态的完整模型期望。
- 确定贪心目标可与 Q-learning 的 max 目标一致。
:::

```Python
q_next = [4.0, -2.0]
probability = [0.9, 0.1]
expected_next = sum(p * q for p, q in zip(probability, q_next))
target = 0.0 + 0.9 * expected_next
print(f"expected_next={expected_next:.3f}, target={target:.3f}")
```
:::

## 常见错误 {#pitfalls}

:::field{path="pitfalls" type="list"}
- 把 ε-greedy 的动作概率写成 1−ε 和 ε。
- 将策略加权期望错写为动作简单平均。
- 声称求期望消除了环境和奖励的全部随机性。
:::

## 失败模式、风险与性能 {#failure-performance}

:::field{path="failureModes" type="list"}
- 把 ε-greedy 的动作概率写成 1−ε 和 ε。
- 将策略加权期望错写为动作简单平均。
- 声称求期望消除了环境和奖励的全部随机性。
:::

:::field{path="securityRisks" type="list"}
- 奖励函数与真实目标不一致会诱发奖励黑客。
- 部署策略的行动权限必须由环境和应用层约束。
:::

:::field{path="performanceNotes" type="list"}
- 样本效率、墙钟时间和显存占用需要分别报告。
- 应使用多个随机种子、置信区间和固定评测策略。
:::


## 常见问题 {#common-questions}

:::field{path="commonQuestions.0.question" type="text"}
### Expected SARSA 一定是 on-policy 吗？
:::

:::field{path="commonQuestions.0.answer" type="text"}
不是。是否 on-policy 取决于期望所用目标策略是否与数据行为策略一致；算法名称本身不能代替这一检查。
:::
