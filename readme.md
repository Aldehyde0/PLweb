# Layerwise · AI 学习知识库

从直觉、原理、代码到练习，系统学习人工智能、机器学习、深度学习与强化学习。

## 四大学习方向

- **人工智能**：搜索与知识表示、大模型、智能体、工具调用、MCP 与 AI Infra。
- **机器学习**：数学与数据基础、预处理、经典模型、评估与完整项目。
- **深度学习**：神经网络、训练优化、CNN、序列模型、注意力与 Transformer。
- **强化学习**：MDP、价值与策略方法、深度强化学习及算法比较。

知识库包含 265 篇概念文章，按学习路径串联前置知识与相关概念，结合原理讲解、公式、手算案例、代码示例和常见误区。

AI Infra 专题包含 18 篇文章，覆盖 GPU 与显存预算、训练数据、分布式训练与通信、检查点、编译优化、推理缓存与批处理、量化、服务部署、压测、调度和可观测性。配套提供 18 道练习、36 道阶段测试、13 项官方资料，以及无需 GPU 的容量规划实验；新内容沿用目录、搜索、笔记和学习计划功能。

## 知识阅读

- 按方向、主题、难度和学习状态筛选概念，支持全文搜索与排序。
- 阅读目录与页内导航联动，支持章节重点、收藏和概念学习标记。
- 文章包含数学公式、代码高亮、行号、复制和分步解析。
- 通过互动演示调整参数，观察图形和数值的变化。

## 学习计划

- 按学习目标、时间安排与知识范围创建计划。
- 将学习过程分为阶段、任务和子步骤，查看今日与本周安排。
- 跟踪进度，支持编辑、暂停、继续和删除计划。
- 通过阶段测试检查掌握情况，并回顾薄弱概念。

## 练习与资料

- 练习涵盖概念、计算、代码、诊断和项目，支持筛选、分页、答案展开及完成标记。
- 汇集课程、文档、书籍、论文和代码仓库，支持资料筛选、收藏、已读和笔记。
- 从练习和资料跳转到关联概念，连接阅读、实践与复习。

## 学习记录与个性化

- 保存学习进度、收藏、章节重点和个人笔记，通过知识关系图浏览概念联系。
- 支持学习提醒，以及学习记录的备份导出与恢复。
- 提供深色与浅色主题，代码框分别采用紫色与蓝色背景。
- 适配桌面与手机，支持键盘操作和减少动态效果偏好。

学习记录保存在当前浏览器，无需注册。跨设备使用时，可通过备份导出与导入迁移个人记录。
