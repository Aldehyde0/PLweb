# 思维导图验收

入口：主导航“思维导图”。电脑悬停展开四方向，触控设备点击展开。每个方向使用独立 `/mindmaps/<category>` 页面。

- 全量覆盖：机器学习 98、深度学习 54、人工智能 38、强化学习 57 个概念。
- 采用中心发散、左右分支、纵向滚动布局；窄屏改为纵向排列，保留全部概念。
- 彩色实线表示目录归属，不代表前置条件；箭头虚线表示前置知识到后续概念，点线表示相关概念。
- 默认只显示聚焦或悬停概念的关系，可勾选显示全部关系。所有关系来自现有元数据；未解析的名称不生成虚假链接。跨方向关系显示在确认窗口中。
- 中心主题、关联较多的概念、普通概念使用不同样式。目录标题用于组织结构，真实知识节点点击后需要确认才会跳转。
- 支持搜索定位、回到中心、已学习标记，以及返回时恢复浏览位置。

验证：模型单元测试、全量测试、类型检查、静态检查、生产构建；隔离 Chrome 检查四方向概念数量、关系、确认/取消、返回位置、悬停和触控菜单、390px 窄屏及深浅主题。

特别说明：现有强化学习数据将前置项记录在其他学习方向，因此本方向图内不虚构前置箭头；已有相关概念连接正常展示。

## 紧凑布局与缩放

- 节点高度从 64 降至 48 像素、行距从 76 降至 60 像素；大分支在宽画布中分成两列。
- Ctrl + 鼠标滚轮在鼠标位置缩放导图（20%–250%），普通滚轮仍滚动画布，画布外不拦截浏览器行为。
- 工具栏支持放大、缩小、恢复 100% 与适应全图。缩放后搜索定位、回到中心及确认跳转继续可用。
- 返回时恢复水平/垂直位置和缩放比例。浏览器验证确认锚点误差小于 1 像素，普通滚轮不会改变缩放。
