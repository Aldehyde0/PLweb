# 目录与学习计划

- 四个板块均展示分层目录。分组来自现有长文主题；机器学习按基础、预处理、模型、评估、项目分组。
- 新计划按板块默认目录顺序生成，完整保留所有概念，不再额外插入其他板块前置内容，也不因预算或 24 条上限截断。
- 每个概念一张学习卡，阅读、原理、代码和复习放在卡内。每张卡预计时间最多 10 分钟，子步骤分配之和与卡片时间一致。
- 额外参考资料仅在开启选项后生成任务，同一链接在整个计划中只出现一次。预算不足时提示调整日期或每周时间。
- 无实际练习内容的练习/项目模板不再生成；已有计划首次加载时合并重复卡、清除空练习模板并保留有效步骤状态与笔记。布局版本标记避免后续重复迁移影响新加的薄弱概念复习任务。
- 卡片手动编辑与新增任务同样限制为 1–10 分钟。复习日期显示在卡内步骤中。

验证：计划引擎回归、全量单元测试、类型检查、静态检查、生产构建及隔离 Chrome 页面交互。
